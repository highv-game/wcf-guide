# 약초채집 지도와 시세

> 최종 수정: 2026-11-11

!!! abstract "한눈에 보기"
    - **지도**: 약초를 누르면 그 약초가 나는 지역이 칠해지고, 색이 진할수록 노드가 많습니다. 지역을 누르면 몹 레벨과 거기서 나는 약초가 보입니다.
    - **팔 곳**: 약초는 상점에 팔지 말고 경매장에 올립니다. 상점가는 20개 한 묶음에 2~20실버 수준입니다.
    - **먼저 챙길 약초**: 찔레가시, 생채기풀, 마법초, 토끼엉겅퀴풀, 물속 갈래물풀.
    - **연금술이 있으면**: 치유 물약과 신속의 물약만 만들어 팝니다.
    - **숙련도 동선(얼라이언스)**: 시작 지역 → 모단 호수·서부 몰락지대·어둠의 해안 → 붉은마루 산맥 → 그늘숲 → 저습지.

!!! warning "미확인"
    약초 분포, 노드 수, 재료 조합은 클래식 기준입니다. 포에버에서 분포나 제작법이 달라진 곳이 있을 수 있습니다. 불모의 땅 등 칼림도어 일부 지역은 초반 약초의 노드 수가 빠져 있을 수 있습니다.

## 약초 지도 { #map }

약초 버튼을 누르면 지도와 오른쪽 설명이 바뀝니다. 지도는 위치를 알아보기 쉽게 단순화한 개략도이고, 정확한 노드 좌표는 설명 칸의 와우헤드 링크에서 봅니다.

## 돈 되는 약초와 물약 { #money }

!!! tip "파는 요령"
    - **상점에 팔지 않습니다.** 연금술을 올리는 사람들이 경매장에서 사 갑니다.
    - **물약보다 약초 그대로.** 치유 물약 상점가(75코퍼)가 재료인 생채기풀+찔레가시(50코퍼)와 거의 같습니다. 레벨업용 재료 수요가 커서 원재료가 물약보다 비싸게 팔리는 경우가 많습니다.
    - 올리기 전에 경매장에서 같은 물건 가격을 확인합니다. 경매장 수요는 클래식 경제 기준 추정입니다.

| 갈래물풀 | 높음 | 1실버 / 20실버 | 물속에서만 캐서 공급이 적음. 하급 마나 물약, 방어의 비약, 수중 호흡의 비약 |
