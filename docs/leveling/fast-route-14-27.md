# 빠른 레벨링 14~27 (얼라이언스)

> 최종 수정: 2026-10-04

던 모로에서 시작해 영주의 전당, 서부 몰락지대, 로데론 폐허, 죽음의 폐광, 통곡의 동굴, 검은 심연의 나락, 스톰윈드 지하감옥 순서로 27레벨까지 올리는 동선입니다. 던전 퀘스트를 미리 전부 받아 두고 한 판에 몰아서 깨는 것이 핵심입니다. 포에버는 던전 몹 경험치가 줄고 첫 클리어 던전 퀘스트 경험치가 늘었기 때문입니다.

| [4](#step-4) | 서부 몰락지대 | 감시의 언덕 퀘 받기, 민병대 1차 | 16 후반 |

!!! tip "웨이포인트 쓰는 법"
    좌표는 **TomTom** 애드온 명령어입니다. 회색 상자 오른쪽 위 복사 버튼을 누른 뒤 채팅창에 붙여 넣으면 됩니다.

    - 상자에 여러 줄이 있으면 **새 매크로에 통째로 붙여 넣고** 한 번 누르면 그 단계 좌표가 한꺼번에 등록됩니다.
    - 지역 이름이 인식되지 않으면 그 지역 안에서 `/way 56.2 47.5`처럼 숫자만 입력하세요.
    - 좌표는 클래식 기준입니다. 포에버에서 바뀐 지도는 조금 어긋날 수 있습니다.

## 그리핀 체크리스트

도착하면 퀘스트보다 그리핀 관리인부터 말을 거세요. 아이언포지는 열려 있다고 가정합니다.

| 순서 | 비행 지점 | 단계 | 그리핀 관리인 |
| :-: | --- | :-: | --- |
| 1 | 모단 호수 · 텔사마 | 1 | 토르그룸 보렐슨 |
| 2 | 스톰윈드 · 무역 지구 | 3 | 던가 롱드링크 |
| 3 | 서부 몰락지대 · 감시의 언덕 | 3 | 토르 |
| 4 | 붉은마루 산맥 · 레이크샤이어 | 5 | 아리에나 스톰페더 |
| 5 | 가시덤불 숲 · 무법항 | 8 | 길 |
| 6 | 잿빛 골짜기 · 아스트라나르 | 9 | 데일리샤 |

```text
/way 모단 호수 33.8 50.8

```

!!! note "톱니항"
    톱니항 비행 지점은 호드 전용입니다. 얼라이언스는 무법항 ↔ 톱니항 배를 탑니다.

## 1단계 · 던 모로 동쪽 { #step-1 }

**레벨 14 → 14 후반** · 아이언포지에서 던전 퀘스트 2개를 받고 던 모로 동쪽을 한 바퀴 돕니다.

- [ ] 아이언포지 [아파드라 던월](https://www.wowhead.com/forever/ko/search?q=Afadra%20Dunwall)에게 **끊임없는 망자** 받기
- [ ] [대지예언자 파르센](https://www.wowhead.com/forever/ko/search?q=Earthseer%20Farsen)에게 **지하 지도** 받기. 검은무쇠 첩자를 잡아 지도를 얻어 반납하면 던전 퀘스트 **옛 아이언포지 침공**이 열립니다.
- [ ] 앰버스틸 목장 [루드라 앰버스틸](https://www.wowhead.com/classic/ko/search?q=Rudra%20Amberstill)의 **가축 보호**: 11레벨 정예 웬디고 바가쉬 처치
- [ ] 골볼라 채석장 [감독관 스톤브로](https://www.wowhead.com/classic/ko/search?q=Foreman%20Stonebrow)의 **망할 트로그!**, [의원 메르 스톤홀로](https://www.wowhead.com/classic/ko/search?q=Senator%20Mehr%20Stonehallow)의 **공복**: 채석장 트로그 처치로 둘 다 완료
- [ ] 북동쪽 [조종사 해머풋](https://www.wowhead.com/classic/ko/search?q=Pilot%20Hammerfoot)의 **실종된 조종사** → 추락지 시체의 **조종사의 복수**: 근처 곰 처치

- [ ] 모단 호수 퀘스트는 하지 않고 귀환석으로 아이언포지 복귀

## 2단계 · 영주의 전당 { #step-2 }

**레벨 14 → 16** · 아이언포지 지하의 포에버 신규 던전(13~18)입니다. 다섯 개를 모두 들고 들어갑니다.

| 퀘스트 | 받는 곳 | 목표 |
| --- | --- | --- |
| 중요한 가보 | 아이언포지 톰 필치 | 던전 곳곳의 드워프 가보 8개 |
| 끊임없는 망자 | 아이언포지 아파드라 던월 | 격노한 허깨비 15, 고통받는 영혼 10 |
| 옛 아이언포지 침공 | 던 모로 대지예언자 파르센 | 마지막 보스 두르겐 더지해머의 머리 |
| 오래된 원한 | 던전 안 유령 시종 | 첫 보스 팔드림 앤빌마르 |
| 화해의 조약 | 마지막 방 석판 | 석판 반납 (파티 공유 안 됨) |

## 3단계 · 스톰윈드 → 엘윈 숲 → 서부 몰락지대 { #step-3 }

**레벨 16 → 16 중반** · 깊은굴 지하철로 스톰윈드에 가서 폐광 퀘스트를 미리 받고 서쪽으로 내려갑니다.

- [ ] 스톰윈드 그리핀 관리인과 대화해 **비행경로 열기**
- [ ] 대성당 광장 [바로스 알렉스턴](https://www.wowhead.com/classic/ko/npc=1646)에게 **초라한 시작** 받기 (나침반 퀘)
- [ ] 드워프 지구 [와일더 시슬네틀](https://www.wowhead.com/classic/ko/npc=656)에게 **형제여...**, **기억을 더듬어...** 받기
- [ ] [소리없는 쇼니](https://www.wowhead.com/classic/ko/npc=6579)에게 **지하 공격** 받기
- [ ] 엘윈 숲 서부감시병 주둔지 게시판에서 **현상수배: 들창코** 받기
- [ ] 엘윈 남서쪽 11레벨 정예 [들창코](https://www.wowhead.com/classic/ko/npc=448) 처치 → 골드샤이어 [치안대장 더글런](https://www.wowhead.com/classic/ko/npc=240)에게 반납
- [ ] 서부 몰락지대 알렉스턴 농장 불탄 집의 상자에서 **단순한 나침반** 줍기 (반납은 다음에 스톰윈드 갈 때)
- [ ] 살딘 농장 [농부 살딘](https://www.wowhead.com/classic/ko/npc=233)에게 **죽음의 땅** 받기: [허수아비골렘 보초](https://www.wowhead.com/classic/ko/npc=114) 20마리, 남쪽으로 이동하며 처치
- [ ] 감시의 언덕 도착, [토르](https://www.wowhead.com/classic/ko/npc=523)에게서 **비행경로 열기**

!!! success "그리핀: 스톰윈드, 감시의 언덕"

```text
/way 스톰윈드 66.2 62.4
/way 스톰윈드 49.0 30.2
/way 스톰윈드 65.2 21.2
/way 스톰윈드 55.5 12.5
/way 엘윈 숲 24.4 74.7
/way 엘윈 숲 26.0 90.0
```

```text
/way 엘윈 숲 42.2 65.8
/way 서부 몰락지대 36.0 54.0

/way 서부 몰락지대 56.5 52.5
```

!!! info "들창코"
    엘윈 남서쪽 숲 가장자리(24~29, 81~96)를 돌아다닙니다. 16레벨이면 대부분 직업이 혼자 잡을 수 있습니다. 나침반 상자와 농부 살딘 좌표는 추정치입니다.

## 4단계 · 감시의 언덕 { #step-4 }

**레벨 16 → 16 후반** · 아래 네 개만 받고 나머지 감시의 언덕 퀘스트는 나중에 받습니다.

- [ ] [그리안 스타우트맨틀](https://www.wowhead.com/classic/ko/npc=234): **백성의 민병대**, **데피아즈 단**
- [ ] [다누빈 대장](https://www.wowhead.com/classic/ko/npc=821): **서부 몰락지대 순찰** (놀 앞발 8개)
- [ ] [정찰병 갈리아안](https://www.wowhead.com/classic/ko/npc=878): **붉은 가죽 두건** 15개
- [ ] 민병대 1차(데피아즈 덫사냥꾼·밀수업자)만 끝내고 반납. 두건은 데피아즈를 잡으며 저절로 모입니다.

```text

/way 서부 몰락지대 56.4 47.5

```

## 5단계 · 데피아즈 단 연계 { #step-5 }

**레벨 16 → 17** · 데피아즈 단 첫 단계는 레이크샤이어 심부름입니다.

- [ ] 감시의 언덕 → 스톰윈드 비행, 엘윈 숲을 가로질러 레이크샤이어까지 이동
- [ ] 레이크샤이어 [그리핀 관리인](https://www.wowhead.com/classic/ko/npc=931)에게서 **비행경로 열기**
- [ ] 레이크샤이어 여관 2층 [와일리](https://www.wowhead.com/classic/ko/npc=266)와 대화
- [ ] 감시의 언덕 그리안에게 복귀

!!! success "그리핀: 레이크샤이어"

```text
/way 붉은마루 산맥 30.6 59.4
/way 붉은마루 산맥 26.5 45.2
/way 서부 몰락지대 56.2 47.5
```

## 6단계 · 서부 몰락지대 정리 { #step-6 }

**레벨 17 → 17 중반** · 북쪽 광산에서 남쪽 해안까지 한 번에 훑습니다.

- [ ] **백성의 민병대** 2차·3차 완료 (3차 보상은 무기)
- [ ] [농부 퍼브로우](https://www.wowhead.com/classic/ko/npc=237)의 **잊혀진 가보**: 장골로드 광산 안에서 회중시계 찾기
- [ ] **붉은 가죽 두건** 15개 마무리
- [ ] 광산과 달빛마을 사이 길을 오가는 [데피아즈 전령](https://www.wowhead.com/classic/ko/npc=550) 처치, 쪽지를 그리안에게
- [ ] 감시탑 앞 [데피아즈 배신자](https://www.wowhead.com/classic/ko/npc=467) 호위 (달빛마을까지). 폐광 최종 퀘스트와 **붉은 비단 두건**이 열립니다.
- [ ] 등대 [그레이슨 선장](https://www.wowhead.com/classic/ko/npc=392)의 **불꽃의 수호자**: 해안 멀록에게서 기름 모아 반납
- [ ] 해안 정예 멀록 [늙은 거먹눈](https://www.wowhead.com/classic/ko/npc=391) 처치 (파티 권장)
- [ ] 달빛마을 가는 길의 강발놀을 잡으며 **놀 앞발** 8개
- [ ] 스톰윈드에 들를 때 바로스 알렉스턴에게 **초라한 시작** 반납

```text
/way 서부 몰락지대 60.0 19.4
/way 서부 몰락지대 45.0 67.0
/way 서부 몰락지대 55.6 47.5
/way 서부 몰락지대 42.5 71.5
/way 서부 몰락지대 30.0 86.0
/way 서부 몰락지대 30.0 75.0
```

!!! info "돌아다니는 대상"
    데피아즈 전령은 달빛마을 북쪽 길(44~46, 65~70) 부근, 늙은 거먹눈은 서쪽 해안(26,65 ~ 35,85)을 순찰합니다.

## 7단계 · 로데론 폐허 { #step-7 }

**레벨 17 중반 → 19** · 언더시티 입구 왼쪽의 포에버 신규 던전(15~20)입니다. 얼라이언스 퀘스트는 모두 던전 안에서 시작하므로 미리 받을 것이 없습니다.

| 퀘스트 | 시작 | 메모 |
| --- | --- | --- |
| 로데론의 문장 | 던전 안 아이템 | 스톰윈드 레이디 디나 케네디에게 반납 |
| 흉악한 괴물들 | 던전 안 트루먼 대장 | |
| 피 묻은 휘장 | 던전 안 아이템 | |
| 사랑했다고 기억해 줘 | 묘지 근처 피 묻은 편지 | 2단계, 파티 공유 안 됨 |

!!! warning "가는 길"
    호드 영역이라 얼라이언스는 걸어가기 위험합니다. 포에버는 자동 던전 찾기가 없고 소환은 흑마법사만 가능하니 흑마법사가 있는 파티를 구하세요.

## 8단계 · 폐광 → 무법항 → 통곡의 동굴 { #step-8 }

**레벨 19 → 23~24** · 폐광 파티를 그대로 유지한 채 바다를 건넙니다.

- [ ] **죽음의 폐광**: 스톰윈드 퀘스트 3개 + 데피아즈 단 최종(밴클리프) + 붉은 비단 두건 한 번에 완료, 감시의 언덕·스톰윈드에 반납
- [ ] 서부 몰락지대 남쪽 해안에서 바다로 들어가 해안선을 따라 **무법항까지 수영**
- [ ] 무법항 [길](https://www.wowhead.com/classic/ko/npc=2859)에게서 **비행경로 열기**
