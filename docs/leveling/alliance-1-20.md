# 얼라이언스 시작 지역 1~20

> 최종 수정: 2026-11-11

!!! abstract "한눈에 보기"
    종족별 시작 지역에서 언제 어디로 옮기는지, 수많은 퀘스트 중 무엇을 하고 무엇을 버리는지를 정리했습니다. 먼저 [퀘스트 고르는 기준](#criteria)을 읽으면 아래 종족별 목록이 왜 그렇게 나뉘었는지 이해가 됩니다.

    - 경험치 곡선은 클래식과 같고, 퀘스트 목록은 40칸입니다.
    - 던전 몹 경험치는 줄었고, 던전 퀘스트는 일반 퀘스트 값 위로 절반만큼 경험치를 더 줍니다. 던전은 퀘스트를 들고 한 번씩만 갑니다.
    - 14레벨부터는 [빠른 레벨링 14~27](fast-route-14-27.md)(던전 포함) 또는 [필드 퀘스트 1~30](field-route-alliance.md)으로 이어 갑니다.

!!! warning "미확인"
    시작 지역에 추가된 포에버 신규 퀘스트의 구체적 목록은 확인하지 못했습니다. 아래 **지역 순서와 퀘스트 목록은 클래식 기준**입니다. 같은 마을에서 처음 보는 퀘스트가 나오면 [퀘스트 고르는 기준](#criteria)으로 판단하세요. 퀘스트 이름은 영문을 같이 적었습니다.

## 종족별 동선 { #overview }

| 종족 | 1~5 | 6~11 | 12~20 |
| --- | --- | --- | --- |
| **인간** | 노스셔 수도원 | 엘윈 숲, 골드셔 | 서부 몰락지대 → 붉은마루 산맥 |
| **드워프·노움** | 콜드릿지 계곡 | 던 모로, 카라노스 | 모단 호수 → 붉은마루 산맥(또는 서부 몰락지대) |
| **나이트 엘프** | 샤도우글렌 | 텔드랏실, 돌라나르 | 어둠의 해안(거의 20까지) → 잿빛 골짜기 |
| **스카이본** | 제프라스 섬(Zephras Isle, 한글 미확인) 1~12 | | [아래 참고](#skyborne) |

던전 끼워 넣기: 13~18 영주의 전당, 17~20 죽음의 폐광.

## 퀘스트 고르는 기준 { #criteria }

레벨업 속도는 **분당 경험치**로 결정됩니다. 퀘스트 하나의 보상이 커도 이동에 10분이 걸리면 그동안 몬스터를 잡는 편이 낫습니다. 자기 레벨의 퀘스트 1개 보상이 대략 같은 레벨 몬스터 10~15마리 분량이라, **이 퀘스트에 드는 추가 시간이 몬스터 10여 마리 잡는 시간보다 짧은가**가 기본 판단선입니다.

| # | 기준 | 판단 | 설명 |
| :-: | --- | :-: | --- |
| 1 | 동선이 겹치면 한다 | 한다 | 같은 사냥터의 처치·수집은 한 번 가서 둘 다 끝냅니다. 마을에서 **한꺼번에 받고**, 한 방향으로 돌고, 한꺼번에 반납합니다. |
| 2 | 색으로 거른다 | 버림 | 주황·노랑은 보상 최대, 녹색은 줄기 시작, 회색은 거의 0. 회색이 된 퀘스트는 지웁니다. |
| 3 | 다음 지역으로 데려가는 퀘스트 | 한다 | "○○에게 보고하라" 같은 연결 퀘스트는 갈 길에 공짜 경험치. **안 갈 지역**으로 보내는 배달은 버립니다. |
| 4 | 드랍률 낮은 수집 | 조건부 | 일부러 파밍하지 않고, 받아 두었다가 다른 퀘스트 하다 모이면 반납합니다. |
| 5 | 정예(Elite) | 버림 | 혼자면 시간과 수리비만 듭니다. 같은 퀘스트 하는 사람이 보이면 그때 합니다. |
| 6 | 긴 호위 | 버림 | NPC 속도에 묶이고 실패하면 처음부터. 짧고 가까운 것만 합니다. |
| 7 | 보상이 무기 | 한다 | 저레벨 최대 전투력 상승은 무기 교체. 전사·도적·성기사·사냥꾼은 특히 우선합니다. |
| 8 | 직업 퀘스트 | 한다 | 보상이 새 기술 같은 영구 성능이라 무조건 합니다. 10레벨 전후로 수도의 직업 상급자를 들릅니다. |

아래 목록의 **한다**는 동선에 들어가거나 보상이 큰 것, **조건부**는 겸사겸사 또는 상황에 따라, **버림**은 시간 대비 손해인 것입니다.

## 인간 { #human }

스톰윈드를 중심으로 서쪽(서부 몰락지대)과 동쪽(붉은마루 산맥)을 차례로 갑니다.

### 1~5 노스셔 수도원

계곡 안 퀘스트는 전부 가깝고 짧아서 **모두 합니다**. 코볼트·늑대·데피아스 처치 퀘스트를 한 번에 받고 계곡을 한 바퀴 돕니다.

**이동 시점**: 5레벨 전후. 골드셔 방면 연결 퀘스트를 들고 남쪽 길로 골드셔에 갑니다.

### 6~10 엘윈 숲 · 골드셔

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 골드셔 근처 코볼트 광산 줄기 (Fargodeep Mine, Kobold Candles, Gold Dust Exchange) | 광산 하나에서 처치·수집이 겹침 |
| 한다 | 동쪽 벌목장·재스퍼로드 광산 (Eastvale Logging Camp, The Jasperlode Mine) | 동쪽으로 한 번 가서 몰아서 |
| 한다 | 서쪽 농장 멀록·늑대·멧돼지, 프린세스 (Princess Must Die!) | 서부 몰락지대 가는 길목 |
| 조건부 | 강가 멀록 지느러미·노상강도 두건 수집 | 지나가며 모이면 반납 |
| 버림 | 호거 처치 (Hogger) | 정예. 파티가 보이면 |
| 버림 | 그늘숲 배달 (Deliveries to Sven) | 20 전에는 갈 일이 없음 |

**이동 시점**: 10레벨에 스톰윈드에서 주문 훈련과 직업 퀘스트를 받고 서부 몰락지대로. 도착하면 **감시의 언덕 비행 경로**부터 켭니다.

### 11~15 서부 몰락지대

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 살데안 농장 요리 재료 (Westfall Stew, Goretusk Liver Pie, Poor Old Blanchy) | 농장 주변 짐승만 잡으면 됨 |
| 한다 | 감시의 언덕 민병대 (The People's Militia, Patrolling Westfall) | 필드 데피아스 잡는 김에 |
| 한다 | 데피아스 단 줄기 (The Defias Brotherhood) | 죽음의 폐광으로 이어짐. 던전 전 단계까지만 |
| 한다 | 붉은 가죽 두건 수집 (Red Leather Bandanas) | 데피아스 처치와 겹침 |
| 조건부 | 해안 멀록 퀘스트 | 해안 쪽 동선일 때만 |
| 버림 | 놀 현상금 (Riverpaw Gnoll Bounty) | 드랍률이 낮음 |
| 버림 | 샌더 선장의 보물 (Captain Sander's Hidden Treasure) | 걷기만 하는 긴 줄기 |

**이동 시점**: 15~16레벨. 남은 퀘스트가 녹색이 되면 스톰윈드로 날아간 뒤 붉은마루 산맥으로. 레이크샤이어 비행 경로를 켭니다.

### 16~20 붉은마루 산맥

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 레이크샤이어 다리·호수 주변 (The Everstill Bridge, Redridge Goulash) | 마을 코앞의 놀과 짐승 |
| 한다 | 검은바위 오크 첫 단계 (Blackrock Menace) | 산 중턱 오크 처치 |
| 조건부 | 솔로몬의 법 줄기 (Solomon's Law) 등 검은바위 요새 깊은 곳 | 20 넘어서, 레이크샤이어에 다시 올 때 |

17~20 사이에 파티가 모이면 서부 몰락지대의 **죽음의 폐광**을 한 번 돌아 데피아스 줄기를 마무리합니다.

## 드워프 · 노움 { #dwarf }

콜드릿지 계곡에서 시작합니다. 포에버 신규 던전 **영주의 전당**이 아이언포지 바로 아래에 있어서 13~18 구간이 편합니다.

### 1~5 콜드릿지 계곡

계곡 안 퀘스트는 **모두 합니다**. 트롤·곰·늑대 처치와 수집이 한 계곡에 모여 있습니다.

**이동 시점**: 5~6레벨. 계곡 북쪽 터널을 지나 카라노스로 가는 연결 퀘스트를 들고 이동합니다.

### 6~11 던 모로 · 카라노스

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 서리갈기 트롤 줄기 (Frostmane Hold, The Troll Cave) | 동굴 하나에 몰려 있음 |
| 한다 | 카라노스 도난품·멧돼지 갈비 (Tundra MacGrann's Stolen Stash, Beer Basted Boar Ribs) | 마을 근처에서 짧게 |
| 한다 | 떠돌이 노움 처치 (Operation Recombobulation) | 놈리건 입구 근처 |
| 한다 | 웬디고 동굴 (The Grizzled Den) | |
| 버림 | 바가쉬 처치 (Protecting the Herd) | 동쪽 끝 강한 설인. 솔로면 위험 |

**이동 시점**: 10~11레벨. 아이언포지에서 훈련·직업 퀘스트를 받고 동쪽 터널로 모단 호수에. 텔사마에서 **비행 경로**를 켭니다.

### 12~17 모단 호수 + 영주의 전당

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 텔사마 수비대 트로그 처치 (In Defense of the King's Lands), 광산 쥐 (Filthy Paws) | 광산 하나에서 겹침 |
| 한다 | 텔사마 핏빛 소시지 (Thelsamar Blood Sausages) | 호수 주변 짐승과 겹침 |
| 한다 | 아이언밴드 발굴지 줄기 (Ironband's Excavation) | 아이언포지 보고는 훈련 갈 때 |
| 조건부 | 빙글스의 잃어버린 도구 (Bingles' Missing Supplies) | 동선이 맞을 때만 |
| 버림 | 정예 곰 (Ol' Sooty) | 정예 |
| 버림 | 알가즈 관문 (The Algaz Gauntlet) | 저습지 입구 20레벨대 구역 |

**영주의 전당(13~18)**은 아이언포지 아래라 텔사마에서 비행기로 금방입니다. 13~15레벨에 파티를 구해 **한 번** 돌고 다시 필드로 돌아옵니다.

**이동 시점**: 17~18레벨. 깊은굴 지하철로 스톰윈드에 가서 붉은마루 산맥으로(인간 16~20과 같음). 서부 몰락지대 퀘스트가 아직 노랑이면 그쪽을 먼저 해도 됩니다.

## 나이트 엘프 { #nelf }

칼림도어에 따로 떨어져 있어서 **어둠의 해안에서 거의 20까지** 끝내는 편이 이동 시간이 짧습니다.

### 1~5 샤도우글렌

나무 주변 퀘스트는 **모두 합니다**. 거미 동굴 퀘스트는 처치·수집이 한 동굴에서 겹칩니다.

**이동 시점**: 5~6레벨. 돌라나르로 보내는 연결 퀘스트를 들고 남쪽으로.

### 6~11 텔드랏실 · 돌라나르

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 자연의 균형 줄기 (The Balance of Nature), 나무정령 줄기 (Denalan's Earth) | 돌라나르 가까이에 모여 있음 |
| 한다 | 마법에 걸린 숲 (The Enchanted Glade) | 하피 처치와 겹침 |
| 조건부 | 대지의 왕관 줄기 (Crown of the Earth) | 가까운 단계만. 뒷단계는 동선이 맞을 때 |
| 버림 | 다르나서스 안 배달 줄기 | 도시 이동이 길고 보상이 작음. 훈련 갈 때 받을 수 있는 것만 |

**이동 시점**: 10~11레벨. 다르나서스에서 훈련·직업 퀘스트를 받고 루테란 마을 선착장에서 배로 어둠의 해안 **아우버다인**에. 도착하면 비행 경로부터 켭니다.

### 12~19 어둠의 해안

| 판단 | 퀘스트 | 메모 |
| :-: | --- | --- |
| 한다 | 해변에 밀려온 것 (Washed Ashore), 해안 짐승 (Beached Sea Creature) | 해변 따라 걷는 김에 |
| 한다 | 알살락스 탑 줄기 (The Tower of Althalaxx) | 여러 단계, 경험치가 큼 |
| 한다 | 배쉬알아란 (Bashal'Aran), 버즈박스 (Buzzbox) | 북쪽 해안 처치와 겹침 |
| 한다 | 역병 걸린 땅 (Plagued Lands) | 곰 포획, 짧음 |
| 버림 | 탐광자 호위 (The Absent Minded Prospector) | 느리고 긴 호위 |
| 버림 | 머크딥 (Murkdeep!) | 정예 멀록 무리 |

**이동 시점**: 18~19레벨. 남쪽 끝에서 잿빛 골짜기로 넘어가 **아스트라나르** 비행 경로를 켜고 20레벨 초반 퀘스트로 마무리합니다. 이후는 [필드 퀘스트 1~30 (얼라이언스)](field-route-alliance.md)의 칼림도어 길을 이어 갑니다.

## 스카이본 { #skyborne }

1~12레벨을 전용 지역 제프라스 섬(Zephras Isle, 한글 미확인)에서 보냅니다. 섬을 나온 뒤 도착한 곳에서 가까운 경로를 고릅니다: 동부 왕국이면 [서부 몰락지대 → 붉은마루](#human), 칼림도어면 [어둠의 해안](#nelf) 구간과 같습니다.

## 던전은 한 번씩만 { #dungeons }

포에버는 던전 몹 경험치가 적어서 **퀘스트를 들고 한 번 돌고, 다시 필드로**가 기본입니다.

| 던전 | 레벨 | 위치 | 판단 |
| --- | :-: | --- | --- |
| 영주의 전당 (포에버 신규) | 13~18 | 아이언포지 아래 | **한다**. 가깝고 레벨대가 맞음. 13~15에 한 번 |
| 로데론의 폐허 (포에버 신규) | 15~20 | 티리스팔 숲 | **조건부**. 호드 영토 깊숙이 있어 파티가 이미 모였을 때만 |
| 죽음의 폐광 | 17~ | 서부 몰락지대 | **조건부**. 데피아스 줄기 마무리용 |

## 모든 종족 공통 습관 { #habits }

- **새 마을에 도착하면 비행 경로부터.** 이후 반납·훈련 이동이 크게 줄어듭니다.
- **짝수 레벨마다 주문 훈련.** 수도 갈 일이 있을 때 몰아서 배우되, 너무 오래 미루지는 않습니다.
- **여관에서 로그아웃.** 휴식 경험치가 쌓여 다음 접속 때 몬스터 경험치가 두 배로 들어옵니다.
- **퀘스트는 한 번에 다 받기.** 반납하러 왔을 때 새로 뜬 퀘스트도 바로 받아서 같은 방향으로 나갑니다.
- **던전 퀘스트는 필드에서 미리 받아 두기.** 퀘스트 없이 도는 던전은 손해입니다.
