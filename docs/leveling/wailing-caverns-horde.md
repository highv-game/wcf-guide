# 통곡의 동굴 사전 퀘스트 (호드)

> 최종 수정: 2026-11-11

!!! abstract "한눈에 보기"
    통곡의 동굴(19~22 권장, 불모의 땅)에 들어가기 전에 받아 둘 호드 퀘스트 7개와, 그중 선행이 있는 2개 연계를 어디까지 해 둘지 정리했습니다.

    - 던전 안에서 하는 퀘스트는 **7개**: 송곳니의 드루이드 우두머리, 불뱀꽃, 영리해지는 음료, 99년 묵은 와인, 돌연변이 통가죽, 돌연변이 짐승 섬멸, 빛나는 조각(던전 안 드롭).
    - 미리 손봐야 하는 것은 둘입니다. **송곳니의 드루이드 우두머리**는 통가 룬토템 연계 3개를 끝내고 썬더 블러프까지 가야 받을 수 있고, **영리해지는 음료**는 톱니항 **랩터 뿔**을 반납해야 열립니다.
    - 포에버는 던전 몹 경험치가 적고, 던전 퀘스트는 일반 퀘스트 값 위로 붙는 추가 경험치가 절반입니다. 그래도 일반 퀘스트보다 많이 주니, 첫 판에 7개를 모두 들고 들어갑니다.
    - 방문 순서를 지도로 보려면 [통곡의 동굴 퀘스트 지도](../tools/wailing-caverns-horde.html)를 여세요. 크로스로드 → 잊혀진 웅덩이 → 톱니항 → 죽은 오아시스·랩터 → 톱니항 → 큰 오아시스 → 썬더 블러프 → 동굴 입구 순서입니다.

## 1. 송곳니의 드루이드 우두머리 연계 { #leaders-of-the-fang }

통곡의 동굴 퀘스트 중 가장 길고 보상도 가장 좋은 줄기입니다. 크로스로드에서 시작해 불모의 땅 오아시스 세 곳을 돈 뒤 썬더 블러프에서 던전 퀘스트를 받습니다.

- [ ] (선택) 썬더 블러프 장로의 봉우리 [대드루이드 하뮬 룬토템](https://www.wowhead.com/forever/ko/npc=5769) `/way 썬더 블러프 78.6 28.6` · **불모의 땅 오아시스**(10): 크로스로드 통가에게 가라는 안내 퀘스트. 멀고어에서 올라오는 타우렌이면 받아 가고, 이미 크로스로드에 있으면 건너뛰어도 됩니다.
- [ ] 크로스로드 [통가 룬토템](https://www.wowhead.com/forever/ko/npc=3448) `/way 불모의 땅 52.3 31.9` · **잊혀진 웅덩이**(13): 북서쪽 잊혀진 웅덩이 물가 `/way 불모의 땅 45.1 22.5`까지 가면 완료. 통가에게 반납합니다.
- [ ] 통가 룬토템 · **죽은 오아시스**(16): 크로스로드 남동쪽 죽은 오아시스 물속의 **거품이 이는 균열** `/way 불모의 땅 55.6 42.8`을 조사. 통가에게 반납합니다.
- [ ] 통가 룬토템 · **변화된 생물**(16): **오아시스 무쇠턱거북**(15~16)을 잡아 **변형된 무쇠턱거북 등껍질** 8개. 거북은 동굴 위쪽 큰 오아시스 `/way 불모의 땅 45.0 40.0` 주변에 가장 많고, 죽은 오아시스에도 있습니다. 통가에게 반납합니다.
- [ ] 통가 룬토템 · **하뮬 룬토템**(16): 반납하자마자 이어서 받습니다. 썬더 블러프 [대드루이드 하뮬 룬토템](https://www.wowhead.com/forever/ko/npc=5769) `/way 썬더 블러프 78.6 28.6`에게 대화로 완료.
- [ ] 하뮬 룬토템 · **나라 와일드메인**(16): 바로 옆 [나라 와일드메인](https://www.wowhead.com/forever/ko/npc=5770) `/way 썬더 블러프 75.7 31.6`에게 대화로 완료.
- [ ] 나라 와일드메인 · **송곳니의 드루이드 우두머리**(22) **받기**. 던전 안 송곳니 군주 넷(군주 코브란, 여군주 아나콘드라, 군주 피타스, 군주 서펜티스)이 떨구는 보석 4개를 모아 나라에게 반납합니다.

!!! tip "변화된 생물을 하는 김에"
    큰 오아시스와 죽은 오아시스에는 **버섯 포자**(크로스로드 [연금술사 헬브림](https://www.wowhead.com/forever/ko/npc=3390) `/way 불모의 땅 51.4 30.2`)에 필요한 버섯도 같이 있습니다. 반납하면 이어지는 **연금술사 자마**는 썬더 블러프로 가는 퀘스트인데 제한 시간이 있습니다. 버섯 포자는 썬더 블러프로 출발하기 직전에 반납하고, 자마에게 전달한 자리에서 **불뱀꽃**을 받으면 됩니다.

## 2. 불뱀꽃 { #serpentbloom }

- [ ] 썬더 블러프 정기의 봉우리 [연금술사 자마](https://www.wowhead.com/forever/ko/npc=3419) `/way 썬더 블러프 22.8 20.9` · **불뱀꽃**(18) 받기. 선행 없음.
- [ ] 불뱀꽃 10개. 던전 안에도 있지만 동굴 입구 협곡 `/way 불모의 땅 46.0 35.0` 주변에 많이 피어 있어 들어가기 전에 다 캐도 됩니다. 약초 채집 기술이 없어도 캘 수 있습니다.

## 3. 영리해지는 음료 { #smart-drinks }

- [ ] 톱니항 [메보크 미지릭스](https://www.wowhead.com/forever/ko/npc=3446) `/way 불모의 땅 62.4 37.6` · **랩터 뿔**(18): **갈퀴발톱 열대초원랩터**(16~18)에게서 **온전한 랩터 뿔** 5개. 크로스로드 남쪽~남동쪽 평원에 넓게 퍼져 있습니다. 메보크에게 **반납**합니다.
- [ ] 메보크 미지릭스 · **영리해지는 음료**(18) 받기. 던전 안 세포괴물(포식성·진화된·악몽의 세포괴물)에게서 **통곡의 정수** 6개.

## 4. 99년 묵은 와인 { #trouble-at-the-docks }

- [ ] 톱니항 [기중기 기사 비글퍼즈](https://www.wowhead.com/forever/ko/npc=3665) `/way 불모의 땅 63.1 37.6` · **99년 묵은 와인**(18) 받기. 선행 없음.
- [ ] 던전 안에 숨어 있는 고블린 **광기의 매글리시**를 잡고 99년 숙성된 포트 와인을 회수합니다. 은신 상태라 입구에서 첫 갈림길 사이 바위 근처를 잘 살펴야 합니다.

## 5. 입구에서 받는 퀘스트 { #entrance }

동굴 입구는 크로스로드 남서쪽 오아시스 옆 협곡 안입니다 `/way 불모의 땅 46.0 36.5`. 입구 바로 위 동굴 방에 나랄렉스의 신도 두 명이 있습니다.

- [ ] [날팍](https://www.wowhead.com/forever/ko/npc=5767) `/way 불모의 땅 46.0 35.7` · **돌연변이 통가죽**(17): 던전 안 돌연변이 몹에게서 돌연변이 통가죽 20개.
- [ ] 옆의 [에브루](https://www.wowhead.com/forever/ko/npc=5768) · **돌연변이 짐승 섬멸**(21): 돌연변이 약탈자랩터·돌연변이 독사·돌연변이 늪괴물·돌연변이 송곳니천둥매 각 7마리.
- [ ] 두 퀘스트는 끝나면 같은 자리에서 반납합니다.

## 6. 던전 안에서 시작: 빛나는 조각 { #glowing-shard }

- [ ] 마지막 보스 **걸신들린 무타누스**가 떨구는 **빛나는 조각**을 오른쪽 클릭하면 **빛나는 조각**(26)이 시작됩니다.
- [ ] 동굴 위 언덕 꼭대기 [팔라 세이지윈드](https://www.wowhead.com/forever/ko/npc=8418) `/way 불모의 땅 48.2 32.8`에게 반납합니다. 퀘스트 설명은 톱니항으로 가라고 하지만 반납 NPC는 팔라라서 바로 언덕으로 가면 됩니다.
- [ ] 팔라 세이지윈드 · **악몽**(25): 악몽의 조각을 썬더 블러프 [대드루이드 하뮬 룬토템](https://www.wowhead.com/forever/ko/npc=5769) `/way 썬더 블러프 78.6 28.6`에게 가져갑니다. 다음에 썬더 블러프에 갈 때 반납해도 됩니다.

!!! tip "드루이드라면"
    송곳니 세트(독사의 포옹)를 노리고 여러 번 돌게 됩니다. 퀘스트는 첫 판에 모두 끝내고, 이후 판은 세트만 노립니다. 송곳니 군주 보석은 한 번만 필요하니 다음 판부터는 파티원에게 양보합니다.

!!! warning "미확인"
    송곳니의 드루이드 우두머리 보상(지팡이 Crescent Staff 등)과 각 퀘스트의 경험치·보상은 클래식 기준입니다. 포에버에서 바뀌었는지는 확인하지 못했습니다.
