# 레벨링

진영을 고르고, 던전을 섞을지 필드 퀘스트만 할지 고르면 됩니다.

=== "호드"

    | 페이지 | 레벨 | 방식 | 동선 |
    | --- | :-: | --- | --- |
    | [빠른 레벨링](fast-route-horde.md) | 12~30 | 퀘스트 + 던전 6곳 | 크로스로드 → 성난불길 협곡 → 로데론의 폐허 → 통곡의 동굴 → 그림자송곳니 성채 → 힐스브래드 → 검은심연의 나락 → 가시덩굴 우리 |
    | [필드 퀘스트](field-route-horde.md) | 1~30 | 던전 없이 | 불모의 땅 → 돌발톱 산맥 → 불모의 땅 → 잿빛 골짜기 → 힐스브래드 → 버섯구름 봉우리 |

=== "얼라이언스"

    | 페이지 | 레벨 | 방식 | 동선 |
    | --- | :-: | --- | --- |
    | [시작 지역 1~20](../tools/alliance-leveling.html) | 1~20 | 종족별 시작 지역 | 시작 지역 루트, 퀘스트 할지 말지 기준 |
    | [빠른 레벨링](fast-route-14-27.md) | 14~27 | 퀘스트 + 던전 | 던 모로 → 영주의 전당 → 서부 몰락지대 → 로데론의 폐허 → 죽음의 폐광 → 통곡의 동굴 → 검은 심연의 나락 → 스톰윈드 지하감옥 |
    | [필드 퀘스트](field-route-alliance.md) | 1~30 | 던전 없이 | 모단 호수·서부 몰락지대·붉은마루 또는 어둠의 해안·잿빛 골짜기 → 저습지 → 붉은마루 → 그늘숲 |

!!! tip "던전에 들어가기 전에"
    던전별로 미리 받아 둘 퀘스트와 동선은 [던전·퀘스트](../dungeons/index.md)에 있습니다.
