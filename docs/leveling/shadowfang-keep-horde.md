# 그림자송곳니 성채 (호드)

> 최종 수정: 2026-11-12

!!! abstract "한눈에 보기"
    그림자송곳니 성채(23~26 권장, 은빛소나무 숲 남쪽)에 들어가기 전에 받을 호드 퀘스트 3개, 성채 안 우두머리 순서, 챙길 만한 드랍을 정리했습니다.

    - 호드 던전 퀘스트는 **3개**이고 **셋 다 선행이 없습니다**. 언더시티 **우르의 책**, 공동묘지 **그림자송곳니 성채의 죽음추적자**와 **아루갈의 최후**를 받고 들어가면 됩니다. 셋을 합치면 퀘스트 경험치 7,400입니다.
    - 우두머리는 8명입니다. 레실고어 → 도살자 칼날발톱 → 남작 실버레인 → 사령관 스프링베일 → 눈먼감시자 오도 → 파멸의 펜루스 → 늑대왕 난도스 → 대마법사 아루갈 순서로 만납니다.
    - 첫 우두머리 레실고어를 잡고 **감옥의 암흑추적자 아다만트를 풀어 줘야 안뜰 문이 열립니다**.
    - 저주와 독을 거는 몹이 많습니다. 드루이드는 저주 해제와 독 치료를 둘 다 맡을 수 있습니다.
    - 방문 순서와 성채 안 진행 순서는 [아래 지도](#map)에 있습니다.

## 1. 언더시티: 우르의 책 { #book-of-ur }

- [ ] 언더시티 연금술 실험실 [관리인 벨두거](https://www.wowhead.com/forever/ko/npc=2934) `/way 언더시티 53.7 54.5` · **우르의 책**(26) 받기. 16레벨부터 받을 수 있으니 언더시티를 지날 때 미리 받아 둡니다.
- [ ] 비행 조련사 [마이클 가레트](https://www.wowhead.com/forever/ko/npc=4551) `/way 언더시티 63.3 48.6`에게서 은빛소나무 숲 공동묘지로 날아갑니다. 공동묘지 비행 지점이 아직 없으면 브릴 남쪽 길을 따라 걸어 내려갑니다.

## 2. 공동묘지: 두 퀘스트 받기 { #sepulcher }

- [ ] 공동묘지 비행 조련사 [카로스 라조크](https://www.wowhead.com/forever/ko/npc=2226) `/way 은빛소나무 숲 45.6 42.6` · 비행 경로 열기
- [ ] [고위집행관 하드렉](https://www.wowhead.com/forever/ko/npc=1952) `/way 은빛소나무 숲 43.4 40.9` · **그림자송곳니 성채의 죽음추적자**(25) 받기
- [ ] [달라 던위버](https://www.wowhead.com/forever/ko/npc=1938) `/way 은빛소나무 숲 44.2 39.8` · **아루갈의 최후**(27) 받기
- [ ] 공동묘지에서 남쪽 길을 따라 내려가면 장작나무 마을 서쪽 언덕 위에 성채 입구 `/way 은빛소나무 숲 44.8 67.8`가 있습니다.

!!! tip "공동묘지에서 같이 할 것"
    20레벨 안팎이면 [달라 던위버](https://www.wowhead.com/forever/ko/npc=1938)의 **확산 저지**, [어둠의사제 알리스터](https://www.wowhead.com/forever/ko/npc=2121) `/way 은빛소나무 숲 44.0 40.9`의 **길목의 파수꾼**·**베렌의 동굴**도 같은 자리에서 받습니다. 순서는 [빠른 레벨링 12~30 6단계](fast-route-horde.md#step-6)에 있습니다.

## 3. 성채 안 진행 { #inside }

| 순서 | 우두머리 (레벨) | 위치 | 할 일 |
| :-: | --- | --- | --- |
| 1 | **레실고어** (20) | 입구 안 감옥 | 잡고 감옥의 **암흑추적자 아다만트**를 풀어 줌 → 안뜰 문 열림 |
| 2 | **도살자 칼날발톱** (22) | 연회장 | 체력 흡수. 탱커 체력 관리 |
| 3 | **남작 실버레인** (24) | 연회장 | **암흑의 장막**(받는 치유 감소) 저주 해제 |
| 4 | **사령관 스프링베일** (24) | 안뜰 | 자가 치유를 기절·차단으로 끊기 |
| 5 | **눈먼감시자 오도** (24) | 성벽 통로 | 주변 늑대인간이 죽을 때마다 강해짐. 늑대인간을 먼저 정리 |
| 6 | **파멸의 펜루스** (25) | 텅 빈 굴 → 관측소 하층 | 독 해제. 같은 층에 **우르의 책** |
| 7 | **늑대왕 난도스** (25) | 관측소 상층 | 늑대를 차례로 불러냄. 하나씩 정리 |
| 8 | **대마법사 아루갈** (26) | 고드프리 경의 방 | 방 안을 순간이동하며 공격. 원거리 딜러가 따라가며 공격 → **아루갈의 머리카락** |

- [ ] 레실고어를 잡고 감옥의 **암흑추적자 아다만트**와 대화해 풀어 줍니다. 죽음추적자 퀘스트의 첫 목표이고, 안뜰로 가는 문도 이때 열립니다.
- [ ] 안뜰에 쓰러져 있는 **죽음의추적자 빈센트**에게 말을 걸면 **그림자송곳니 성채의 죽음추적자**가 완료되고 그 자리에서 반납합니다.
- [ ] (선택) 안뜰 마구간의 정예 **지옥마·암흑마**. 아래 [마구간 드랍](#loot)을 노릴 때만 잡습니다.
- [ ] 파멸의 펜루스 방에서 **우르의 책**을 줍습니다. 퀘스트를 가진 파티원은 각자 눌러야 합니다.
- [ ] 대마법사 아루갈에게서 **아루갈의 머리카락**을 챙깁니다.

!!! tip "드루이드라면"
    실버레인의 저주는 저주 해제, 펜루스의 독은 독 치료로 풀 수 있습니다. 곰 탱커일 때는 치유사에게 해제를 맡기고, 표범일 때는 우두머리전마다 한 번씩 형상을 풀고 해제합니다.

## 5. 흑마법사: 소랜루크 수정구 { #soranruk }

흑마법사만 받는 퀘스트입니다. 다른 직업은 건너뜁니다.

- [ ] 불모의 땅 남쪽 [도안 카르한](https://www.wowhead.com/forever/ko/npc=6247) `/way 불모의 땅 49.3 57.2` · **소랜루크 수정구**(25, 20부터) 받기
- [ ] **소랜루크 조각** 3개와 **큰 소랜루크 조각** 1개를 모아 도안 카르한에게 반납합니다.

!!! warning "미확인"
    조각이 나오는 곳(작은 조각은 검은심연의 나락, 큰 조각은 그림자송곳니 성채)은 클래식 기준입니다. 포에버에서 그대로인지는 확인하지 못했습니다.
