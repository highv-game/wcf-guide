# 아늑한 침낭 + 죽음의 폐광 (호드)

> 최종 수정: 2026-11-11

!!! abstract "한눈에 보기"
    "침낭퀘"는 **아늑한 침낭**을 주는 숨은 연계 퀘스트 6개입니다. 퀘스트 NPC 없이 두 대륙에 흩어진 물건을 눌러 가며 진행하고, 14레벨부터 받을 수 있습니다. 서부 몰락지대가 두 번째 장소라서 죽음의 폐광과 한 번에 묶었습니다.

    - 호드 순서: 불모의 땅 → **서부 몰락지대(+ 죽음의 폐광)** → 돌발톱 산맥 → 모단 호수 → 소라딘의 성벽.
    - **죽음의 폐광에는 호드 퀘스트가 없습니다**(포에버도 같음). 폐광은 장비와 몹 경험치만 보고 들어갑니다. 서부 몰락지대에 갈 이유는 침낭 2단계라서, 파티를 구해 둘을 같은 날 처리하면 이동이 한 번으로 끝납니다.
    - 침낭 효과: 펼친 침낭 위에서 1분 쉬면 경험치 +1%가 한 번 쌓이고 최대 3번(+3%)까지 쌓입니다. 재사용 대기시간 1시간.
    - 4~6단계는 퀘스트 레벨 32이고, 모단 호수·아라시 고원은 얼라이언스 지역이라 20레벨 안팎이면 위험합니다. 3단계(돌발톱 산맥)까지만 먼저 해 두고, 나머지는 힐스브래드에 갈 때 이어서 해도 됩니다.
    - 방문 순서를 지도로 보려면 [침낭퀘·죽음의 폐광 지도](../tools/sleeping-bag-horde.html)를 여세요.

!!! warning "파티 공유 안 됨"
    물건을 눌러 받는 퀘스트라 파티원에게 공유되지 않습니다. 같이 하려면 각자 물건을 눌러야 합니다.

## 1. 불모의 땅: 시작 { #step-1 }

- [ ] 타우라조 야영지 남쪽 거인의 들판, 불탄 탑 옆 **불타버린 잔해** `/way 불모의 땅 46.4 73.9` · **…그때 찾은 그 기록** 받기. 쪽지에는 "쌍둥이 땅을 찾아라"라고만 적혀 있고, 목적지는 서부 몰락지대입니다.

## 2. 서부 몰락지대: 죽음의 폐광 + 2단계 { #step-2 }

호드는 서부 몰락지대에 비행 경로가 없습니다. 오그리마 비행선으로 가시덤불 골짜기 그롬골 주둔지에 내린 뒤, 서쪽 바다로 나가 해안을 따라 북쪽으로 헤엄치면 서부 몰락지대 남쪽 해안에 닿습니다. 달빛시내 마을이 바로 해안 위쪽이라 폐광부터 들르는 순서가 편합니다.

- [ ] 오그리마 비행선 → **그롬골 주둔지**. 내리면 그롬골 비행 경로를 열어 둡니다.
- [ ] 해안을 따라 북쪽으로 헤엄쳐 서부 몰락지대 남쪽 해안으로.
- [ ] 달빛시내 마을 광산 입구 `/way 서부 몰락지대 42.6 71.8` · **죽음의 폐광** 클리어. 던전 포털은 광산 안쪽 `/way 서부 몰락지대 38.2 77.5`에 있습니다. 권장 18~21레벨.
- [ ] 북쪽 알렉스턴 농장 **불타버린 잔해** `/way 서부 몰락지대 37.4 50.7` · **…그때 찾은 그 기록** 반납.
- [ ] 바로 옆 땅에 박힌 **못으로 고정한 판자** `/way 서부 몰락지대 37.4 50.9` · **디딤돌** 받기.
- [ ] 귀환석으로 돌아가거나, 해안을 따라 그롬골로 내려가 비행선으로 오그리마.

### 죽음의 폐광 보스

라크조르 → 스니드의 벌목기·스니드 → 길니드 → 미스터 스마이트 → 선장 그린스킨 → 에드윈 밴클리프, 배 근처에 요리사 쿠키.

!!! warning "서부 몰락지대는 얼라이언스 지역"
    감시의 언덕(지역 가운데 동쪽)에는 얼라이언스 경비병이 있으니 가까이 가지 마세요. 달빛시내 마을과 알렉스턴 농장은 서쪽 해안 쪽이라 감시의 언덕을 지나지 않고 오갈 수 있습니다. 죽으면 얼라이언스 쪽 무덤에서 살아나니, 시체까지 걸어가서 부활하는 편이 안전합니다.

!!! tip "폐광에 퀘스트가 없는 대신"
    호드는 폐광 퀘스트 경험치를 받지 못합니다. 포에버는 던전 몹 경험치도 줄어서 경험치만 보면 통곡의 동굴이 낫습니다. 폐광은 원하는 장비가 있을 때, 그리고 침낭 2단계를 하러 서부 몰락지대에 온 김에 도는 던전으로 생각하세요.

## 3. 돌발톱 산맥: 3·4단계 { #step-3 }

- [ ] 크로스로드에서 서쪽으로 돌발톱 산맥에 들어가 **해바위 야영지** 비행 경로를 엽니다.
- [ ] 해바위 야영지 북동쪽 산길 입구 `/way 돌발톱 산맥 54.6 52.4`에서 서쪽으로 산을 넘어 끝까지 가면 버려진 야영지가 나옵니다.
- [ ] 버려진 야영지 상자 위 **휴대용 쓰레기통** `/way 돌발톱 산맥 40.7 52.4` · **디딤돌** 반납, **허겁지겁** 받기.
- [ ] (선택) 받은 장작나무와 부싯돌과 불쏘시개를 옆 모닥불에 쓰면 모닥불 퀘스트(Rekindle, 한글 미확인)가 끝납니다. 침낭과는 상관없습니다.
- [ ] 북쪽 가파른 절벽 아래 **흙무더기** `/way 돌발톱 산맥 39.6 49.9` · **허겁지겁** 반납, **손 더럽히는 일** 받기. 가는 길에 틈을 뛰어 건너야 하고, 너무 높은 데서 떨어지면 죽으니 조금씩 내려가세요.

## 4. 모단 호수: 5단계 { #step-4 }

호드에게 가장 어려운 구간입니다. 오그리마 비행선으로 언더시티에 간 뒤 은빛소나무 숲 → 힐스브래드 구릉지 → 아라시 고원 → 탄돌 교각 → 저습지 → 모단 호수 순서로 달립니다. 아라시 고원과 저습지는 30레벨대 지역이니 길을 벗어나지 마세요.

- [ ] 모단 호수 북쪽 끝 **돌다지 댐** 위를 걸어가다 댐 가운데의 드워프 얼굴 조각 쪽 턱으로 내려가면 **조각상** `/way 모단 호수 49.4 12.9` · **손 더럽히는 일** 반납, **독수리의 주먹** 받기.

!!! warning "댐 위 경비병"
    돌다지 댐 위에는 높은 레벨 얼라이언스 경비병이 돌아다닙니다. 경비병이 지나간 직후 가운데까지 뛰어가 바로 턱 아래로 내려가세요.

## 5. 소라딘의 성벽: 6단계와 침낭 { #step-5 }

- [ ] 저습지 → 아라시 고원으로 돌아와 힐스브래드 구릉지 쪽 **소라딘의 성벽**으로. 힐스브래드 구릉지 던홀드 요새 남동쪽, 성벽 틈에 기대 놓은 **수레** `/way 힐스브래드 구릉지 87.3 49.6`를 밟고 성벽 위로 올라갑니다.
- [ ] 성벽 위를 따라가 안쪽 방을 지나면 오른쪽 벽에 걸린 **배낭** `/way 아라시 고원 22.4 24.2` · **독수리의 주먹** 반납, **여기가 분명해** 받기.
- [ ] 배낭 바로 아래 **황급히 만 주머니** · **여기가 분명해** 반납 → **아늑한 침낭**.

!!! tip "레벨링 동선에 끼우기"
    [빠른 레벨링 (호드)](fast-route-horde.md)는 5단계에서 돌발톱 산맥, 7단계에서 힐스브래드에 갑니다. 서부 몰락지대를 다녀왔다면 침낭 3·4단계는 돌발톱 산맥 단계에서 끝내고, 힐스브래드 단계에서 모단 호수와 소라딘의 성벽을 한 번에 다녀오면 따로 가는 길이 줄어듭니다.

## 아늑한 침낭 쓰는 법

- 여관·도시처럼 휴식 지역이 아닌 곳에서 펼칩니다. 펼치는 데 10초가 걸리고 맞으면 끊깁니다.
- 침낭 위에서 1분마다 경험치 +1%가 한 번 쌓이고, 3분이면 최대치(+3%)입니다. 재사용 대기시간은 1시간입니다.
- 침낭에서 멀리 떨어지면 사라지니 3번 다 쌓고 움직입니다.
- 사냥터에서 휴식 경험치가 떨어졌을 때 침낭 위에서 접속을 끊으면 여관처럼 휴식 경험치가 쌓입니다.
- 버프는 요리 음식 경험치 버프·야영과 함께 적용됩니다.

!!! warning "미확인"
    - 침낭 버프 지속시간(1시간인지 2시간인지)과 파티원도 같은 침낭을 쓸 수 있는지는 자료마다 다릅니다.
    - 2단계 택1 보상 전체 목록, 모닥불 퀘스트의 한글 이름은 확인하지 못했습니다.
    - 해바위 야영지 북동쪽 산길 입구 좌표는 대략적인 위치입니다.
