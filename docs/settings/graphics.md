# 4K 120프레임 그래픽 설정

> 최종 수정: 2026-10-22

!!! abstract "한눈에 보기"
    - **기준 PC**: i7-12700K, RTX 3060 Ti 8GB, 메모리 32GB, 4K 120Hz G-Sync 모니터.
    - **가장 큰 변수는 Secondary Lighting**(포에버 신규 전역 조명, 한글 이름 미확인). 높이면 GPU가 100%에 붙고 프레임이 40% 넘게 떨어집니다. **끄기 또는 Fair**로 둡니다.
    - **3060 Ti로 네이티브 4K 120은 무리**입니다. 포에버 권장 사양이 RTX 40 계열 8GB라서, **렌더 스케일 75%**(내부 2880×1620)로 시작합니다.
    - **멀리 보기**: 시야 거리는 높게, 지면 밀집도는 낮게, 적 이름표 거리를 최대로 늘립니다. 몹이 화면에 나타나는 거리 자체는 서버가 정해서 설정으로 늘릴 수 없습니다.
    - **프레임 고정**: G-Sync 켜고 전면 최대 FPS **116**. 대상 FPS는 끕니다.
    - **도시**: 스톰윈드·썬더 블러프 같은 큰 도시는 CPU가 먼저 막혀서 120 아래로 내려갈 수 있습니다. 필드 기준으로 맞춥니다.

!!! note "메뉴 이름"
    한글 메뉴 이름은 본섭 한국 클라이언트 기준입니다. 포에버에서 새로 생긴 항목(Secondary Lighting, Optional GPU Features, 레이 트레이싱 관련)은 한글 이름을 확인하지 못해 영문으로 적었습니다.

## 먼저 할 것: 엔비디아 제어판

| 항목 | 값 |
|---|---|
| G-SYNC 설정 | 전체 화면 및 창 모드에 사용 |
| 수직 동기 (WoW 프로그램 설정) | 켜기 |
| 낮은 지연 시간 모드 | 끄기 (게임 안 Reflex를 씀) |
| 전원 관리 모드 | 최대 성능 선호 |

게임 안 수직 동기화는 끄고, G-Sync가 화면 찢김을 막게 합니다. 드라이버는 최신으로 올립니다.

## 게임 설정: 시스템 › 그래픽

### 디스플레이

| 항목 | 값 | 이유 |
|---|---|---|
| 디스플레이 모드 | 전체 화면 | G-Sync가 가장 안정적으로 붙습니다 |
| 해상도 | 3840×2160 | |
| 렌더 스케일 | 75% | 4K에서 75%면 글자는 선명하고 GPU 부담은 약 44% 줄어듭니다 |
| 수직 동기화 | 끄기 | 제어판 쪽에서 켭니다 |
| 저지연 모드 | NVIDIA Reflex | 메뉴 이름·선택지 미확인 |

!!! tip "렌더 스케일 고르기"
    필드에서 120이 넉넉하면 85%, 모자라면 67%까지 내립니다. 67% 아래는 4K라도 흐려지기 시작합니다. 리소스 크기 조정(FidelityFX/CAS 선명도) 항목이 보이면 켜고 선명도를 중간쯤 둡니다. 포에버에 이 항목이 있는지는 미확인입니다.

!!! warning "대상 FPS"
    켜 두면 프레임이 낮을 때 게임이 알아서 품질을 흔드는데, 포에버 베타에서는 이걸 끄자 프레임이 두 배 넘게 올랐다는 경우가 있습니다. 끄고 위 표대로 고정합니다.

## 멀리 있는 몹 보기

- **적 이름표 켜기**: `V` 로 적 이름표를 켜 둡니다. 체력바가 몹 모델보다 먼저 눈에 들어옵니다.
- **이름표 거리 늘리기**: 아래 명령을 채팅창에 한 번 입력하면 저장됩니다.

    `/console nameplateMaxDistance 41`

    클래식 클라이언트 최대값은 41미터입니다. 포에버 최대값은 미확인이라, `/console nameplateMaxDistance 60` 을 넣은 뒤 `/run print(GetCVar("nameplateMaxDistance"))` 로 실제로 몇이 들어갔는지 확인합니다.

- **시야 거리·지면 밀집도**: 위 표대로 시야 거리는 높게, 지면 밀집도는 낮게 둡니다. 풀이 낮으면 바닥에 붙은 작은 몹(거미·전갈)도 멀리서 보입니다.
- **깊이 효과 끄기**: 켜 두면 먼 곳이 흐려져 몹 윤곽이 뭉개집니다.

!!! info "늘릴 수 없는 것"
    몹·플레이어가 화면에 그려지기 시작하는 거리는 서버가 정합니다. 이름표 거리를 늘려도 서버가 보내 주지 않은 몹은 보이지 않습니다.

## 120이 안 나올 때 내리는 순서

1. Secondary Lighting 끄기
2. SSAO·Optional GPU Features·레이 트레이싱 끄기 확인
3. 렌더 스케일 75% → 67%
4. 그림자 품질 보통 → 낮음
5. 액체 세부 효과·입자 밀도 낮음

시야 거리·지면 밀집도·이름표 거리는 멀리 보는 데 필요해서 마지막까지 그대로 둡니다. 도시에서만 떨어지면 CPU 한계라 그래픽을 내려도 거의 안 오릅니다.

!!! tip "갑자기 프레임이 떨어지면"
    오래 켜 둔 뒤 큰 도시에서 프레임이 무너지면 캐릭터 선택 화면으로 나갔다 들어오거나 게임을 다시 켭니다. 그래도 그대로면 배틀넷 앱에서 게임 복구를 돌립니다.

## 게임에서 확인할 것

- [ ] Secondary Lighting·Optional GPU Features·레이 트레이싱 항목의 한글 이름과 선택지
- [ ] 리소스 크기 조정(FSR/CAS) 항목이 포에버에 있는지
- [ ] 저지연 모드에 NVIDIA Reflex가 있는지
- [ ] `nameplateMaxDistance` 최대값이 41인지 60인지
- [ ] 바렌·서부 몰락지대 같은 넓은 필드에서 렌더 스케일 75%로 116 고정이 되는지
- [ ] 스톰윈드·오그리마에서 최저 프레임
