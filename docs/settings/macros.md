# 매크로 교본

> 최종 수정: 2026-11-11

!!! abstract "한눈에 보기"
    매크로 창 여는 법부터 조건문이 읽히는 순서, 9개 직업별 실전 매크로까지 한 단계도 건너뛰지 않고 설명합니다. 처음이라면 위에서부터 순서대로 읽으세요. 각 장은 앞 장의 내용을 전제로 합니다.

    - 포에버는 최신 클라이언트 위에서 돌아가서 매크로 문법은 클래식 에라와 같은 현대식 문법입니다.
    - 핵심은 [10장의 패턴 세 가지](#patterns)(마우스오버 공격, 마우스오버 치유 + 자기 시전, 주시 대상 차단)입니다. 직업별 매크로는 거의 다 이 셋의 변형입니다.
    - 내 직업 공략의 실제 매크로와 키 배치는 각 직업 페이지의 **단축키와 매크로**와 [공통 단축키 규칙](keybinds.md)에 있습니다.

!!! warning "주문 이름은 Shift+클릭으로"
    예제의 한글 주문 이름은 클래식 한국어판 기준입니다. 포에버는 전 직업이 개편되어 이름이 바뀌었을 수 있습니다. 매크로 창을 열어 둔 채 **주문서에서 주문을 Shift+클릭**하면 정확한 이름이 커서 위치에 들어갑니다.

## 1. 매크로 창 사용법

매크로는 게임 안의 매크로 창에서 만들고, 만든 뒤 행동 단축바에 올려서 씁니다. 처음 한 번만 순서대로 따라 해 보세요.

1.  **창 열기.** 채팅창에 `/macro`를 입력하고 Enter. 또는 Esc → **매크로**.
2.  **탭 고르기.** 창 위쪽에 탭이 두 개 있습니다. **일반 매크로**는 계정의 모든 캐릭터가 같이 쓰고, **(캐릭터 이름) 전용 매크로**는 그 캐릭터만 씁니다. 직업 주문이 들어가는 매크로는 전용 탭에 만드세요. 다른 직업 캐릭터에서 보이지 않아 헷갈리지 않습니다.
3.  **새로 만들기** 버튼 → 이름 입력 → 아이콘 선택. 아이콘 목록 맨 앞의 **빨간 물음표(?)**를 고르세요. 물음표 아이콘은 “매크로가 알아서 아이콘을 정하라”는 뜻이라, 뒤에서 배울 `#showtooltip`과 함께 쓰면 지금 쓸 주문의 아이콘이 자동으로 표시됩니다.
4.  **본문 입력.** 창 아래쪽 큰 입력칸에 매크로를 적습니다. 한 줄에 명령 하나, 줄바꿈은 Enter.
5.  **주문 이름 넣기.** 입력칸에 커서를 둔 채 주문서(P)를 열고 주문을 **Shift+클릭**하면 정확한 이름이 들어갑니다. 가방 속 아이템도 Shift+클릭으로 이름을 넣을 수 있습니다.
6.  **저장.** 창을 닫거나 다른 매크로를 누르면 자동 저장됩니다.
7.  **단축바에 올리기.** 창 위쪽의 매크로 아이콘을 끌어서 행동 단축바 칸에 놓습니다. 이제 그 칸의 단축키로 매크로가 실행됩니다.
8.  **수정·삭제.** 창에서 매크로를 고르고 본문을 고치면 단축바에 올린 버튼에도 바로 반영됩니다. 삭제는 **삭제** 버튼.

!!! tip "글자 수 제한"

    매크로 하나는 **최대 255자**입니다. 창 아래에 남은 글자 수가 표시돼요. 한글은 영어보다 많은 공간을 차지하므로(한글 한 글자가 여러 바이트) 긴 조건을 여러 개 넣으면 금방 찹니다. 줄바꿈과 띄어쓰기도 글자 수에 포함됩니다.

## 2. 매크로의 기본 구조

매크로는 **여러 줄로 된 채팅 입력의 묶음**입니다. 버튼을 한 번 누르면 맨 윗줄부터 맨 아랫줄까지 **순식간에 한꺼번에** 실행됩니다. 줄 사이에 기다리는 시간은 없습니다.

줄은 첫 글자로 종류가 나뉩니다.

| 첫 글자 | 종류    | 예시           | 설명                                                                         |
|---------|---------|----------------|------------------------------------------------------------------------------|
| `#`     | 설정 줄 | `#showtooltip` | 실행되는 명령이 아니라 버튼 모양(아이콘·툴팁)을 정합니다. 맨 첫 줄에 둡니다. |
| `/`     | 명령 줄 | `/cast 화염구` | 실제로 무언가를 합니다. 채팅창에 직접 쳐도 똑같이 동작합니다.                |

### “한 번 누를 때 주문은 하나”라는 규칙

대부분의 주문은 쓰고 나면 **전역 재사용 대기시간**(보통 1.5초, 화면의 모든 버튼이 잠깐 어두워지는 것)이 돌아갑니다. 매크로 안에 이런 주문을 두 줄 적으면 첫 번째 주문이 전역 대기를 걸어 버려서 **두 번째 줄은 실패**합니다. 그래서 한 매크로에 전역 대기가 있는 주문은 사실상 하나만 넣을 수 있습니다.

반대로 전역 대기가 없는 것들은 한 번에 같이 쓸 수 있습니다: `/startattack`, `/stopcasting`, `/petattack`, `/cancelform`, `/cancelaura`, 장신구 사용(`/use 13`), 사냥꾼 **자동 사격**, 전사 **영웅의 일격**(다음 공격에 예약) 등. 이 교본의 매크로가 여러 줄인 이유가 이것입니다.

## 3. 명령 한 줄 해부하기

명령 줄은 **명령어 → 조건 → 대상(주문 이름)** 순서로 이루어집니다. 아래 한 줄이 이 교본에서 가장 많이 나오는 형태입니다.

    /cast [@mouseover,harm,nodead][] 얼음 화살

- **명령어** `/cast`: 주문을 시전하라.
- **조건 묶음 ①** `[@mouseover,harm,nodead]`: 대괄호 하나가 “조건 묶음” 하나입니다. 안의 뜻은 “마우스 커서가 가리키는 대상(`@mouseover`)이 적이고(`harm`) 죽지 않았으면(`nodead`), 그 대상에게”.
- **조건 묶음 ②** `[]`: 비어 있는 묶음은 **언제나 참**입니다. 대상 지정이 없으니 평소처럼 현재 대상에게 씁니다.
- **주문** `얼음 화살`: 조건이 맞았을 때 쓸 주문.

### 게임이 이 줄을 읽는 순서

버튼을 누르면 게임은 조건 묶음을 **왼쪽부터 하나씩** 검사하고, **처음으로 전부 맞는 묶음**을 찾으면 거기서 멈추고 주문을 씁니다. 나머지 묶음은 보지도 않습니다.

| 상황                               | ① 검사             | ② 검사       | 결과                                              |
|------------------------------------|--------------------|--------------|---------------------------------------------------|
| 살아 있는 적 위에 마우스를 올려 둠 | 맞음               | (검사 안 함) | 마우스 올린 적에게 얼음 화살. 현재 대상은 그대로. |
| 마우스가 빈 땅 위에 있음           | 틀림 (대상 없음)   | 맞음         | 현재 대상에게 얼음 화살                           |
| 마우스가 아군 위에 있음            | 틀림 (harm 아님)   | 맞음         | 현재 대상에게 얼음 화살                           |
| 마우스가 적 시체 위에 있음         | 틀림 (nodead 아님) | 맞음         | 현재 대상에게 얼음 화살                           |

만약 `[]`를 빼고 `/cast [@mouseover,harm,nodead] 얼음 화살`만 쓰면, 마우스오버 대상이 없을 때 **아무 일도 일어나지 않습니다.** 맞는 묶음이 하나도 없으면 그 줄은 통째로 건너뛰기 때문입니다. 조건을 하나도 안 쓴 `/cast 얼음 화살`은 `[]`만 있는 것과 같습니다.

## 4. 조건을 조합하는 규칙 여섯 가지

조건문의 기호는 여섯 개뿐입니다. 각각 예시와 풀이를 같이 보세요.

**① 쉼표 `,` = 그리고**

`[harm,nodead]`  
“적이다” **그리고** “죽지 않았다”. 묶음 안의 조건이 **전부** 맞아야 그 묶음이 참입니다.

**② 묶음 나열 = 또는 (순서 있음)**

`[@mouseover,help][@player]`  
앞 묶음이 틀리면 뒤 묶음으로. 왼쪽이 우선순위가 높습니다.

**③ 세미콜론 `;` = 아니면 다른 주문**

`[mod:shift] 곰 변신; 표범 변신`  
세미콜론은 “조건 + 주문” 덩어리를 나눕니다. Shift를 누르면 곰, 아니면 표범. 마지막 덩어리에 조건이 없으면 “나머지 모든 경우”입니다.

**④ 슬래시 `/` = 값 중 하나**

`[mod:shift/ctrl]`  
한 조건 안에서 “Shift **또는** Ctrl”. `[stance:1/2]`는 “1번이나 2번 태세”.

**⑤ `no` 접두사 = 반대**

`[nocombat]` 전투 중이 아님, `[nodead]` 죽지 않음, `[nomod]` 아무 보조키도 안 누름, `[nostealth]` 은신 아님.

**⑥ `@` = 누구에게**

`[@focus]`처럼 묶음 안에 넣으면, 그 묶음이 맞을 때 **대상을 바꾸지 않고** 그 유닛에게 씁니다. 같은 묶음의 다른 조건(harm, dead 등)도 그 유닛을 기준으로 검사합니다.

### 세미콜론과 묶음 나열의 차이

둘 다 “아니면”처럼 보여서 헷갈리기 쉽습니다. 차이는 **주문이 바뀌느냐**입니다.

| 쓰는 법                | 의미                                                                      |
|------------------------|---------------------------------------------------------------------------|
| `[A][B] 주문X`         | A가 맞으면 X, 아니면 B가 맞을 때 X. **주문은 같고 대상이나 조건만 다름.** |
| `[A] 주문X; [B] 주문Y` | A가 맞으면 X, 아니면 B가 맞을 때 Y. **조건마다 다른 주문.**               |

## 5. 대상 지정 `@`에 쓸 수 있는 이름

| 이름              | 누구인가                                                                                                     |
|-------------------|--------------------------------------------------------------------------------------------------------------|
| @player           | 나 자신                                                                                                      |
| @target           | 현재 대상(아무 것도 안 쓰면 기본값)                                                                          |
| @mouseover        | 마우스 커서가 가리키는 유닛. 게임 화면 속 캐릭터와 **파티·공격대 창, 대상 창 같은 프레임** 둘 다 해당합니다. |
| @focus            | 주시 대상(6장 참고)                                                                                          |
| @targettarget     | 내 대상의 대상. 예: 보스를 잡고 있으면 보스가 때리는 사람(보통 탱커).                                        |
| @pet              | 내 소환수                                                                                                    |
| @party1 ~ @party4 | 파티원(파티 창 위에서부터 순서)                                                                              |
| @raid1 ~ @raid40  | 공격대원(공격대 번호 순)                                                                                     |

!!! tip "자기 시전 키"

    게임 설정(인터페이스 → 전투)에는 **자기 시전 키**(기본값 Alt)가 있어서, 그 키를 누르고 치유 주문을 쓰면 조건 없이도 나에게 시전됩니다. 이 교본의 매크로는 설정이 바뀌어도 똑같이 동작하도록 `[mod:alt,@player]`를 직접 적었습니다.

## 6. 주시 대상(focus) 쓰는 법

주시 대상은 **현재 대상과 별개로 한 명을 더 기억해 두는 칸**입니다. 예를 들어 탱커를 때리면서 뒤쪽 치유사를 주시 대상으로 잡아 두면, 대상을 바꾸지 않고 치유사에게 차단을 날릴 수 있습니다.

1.  주시할 적을 대상으로 잡고 채팅창에 `/focus`. 화면에 주시 대상 창이 따로 생깁니다.
2.  해제는 `/clearfocus`.
3.  매번 입력하기 번거로우니 아래 매크로를 단축키에 올려 두세요.

**주시 대상 지정 버튼** · 마우스오버 우선, Shift로 해제

```
/clearfocus [mod:shift]
/focus [nomod,@mouseover,exists][nomod]
```

**줄별 해설**

1.  Shift를 누른 채 누르면 주시 대상을 지웁니다. Shift를 안 눌렀으면 조건이 틀려서 이 줄은 건너뜁니다.
2.  Shift를 안 눌렀을 때: 마우스를 올린 유닛이 있으면(`exists`) 그 유닛을, 없으면 현재 대상을 주시 대상으로 지정합니다. 두 묶음 모두에 `nomod`를 넣은 이유는, Shift를 눌렀을 때 1번 줄에서 지운 직후 2번 줄이 다시 지정해 버리지 않게 하기 위해서입니다.

**알아둘 점**

`#showtooltip`이 없는 매크로라 아이콘은 직접 고르세요(예: 눈 모양 아이콘).

## 7. 자주 쓰는 명령어

| 명령어                  | 하는 일과 예시                                                                                                                                |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| /cast 주문              | 주문 시전. 조건을 붙일 수 있습니다. `/cast [@focus] 변이`                                                                                     |
| /cast !주문             | 느낌표를 붙이면 **이미 켜져 있는 토글 주문을 끄지 않습니다.** 자동 사격, 변신, 은신처럼 두 번 누르면 꺼지는 주문에 씁니다. `/cast !자동 사격` |
| /use 아이템             | 아이템 사용. 이름이나 장비 칸 번호를 씁니다. `/use 13`(장신구 윗칸), `/use 14`(장신구 아랫칸)                                                 |
| /castsequence           | 누를 때마다 목록의 다음 주문. 9장에서 자세히.                                                                                                 |
| /stopcasting            | 지금 시전 중인 주문을 즉시 끊습니다. 차단기나 긴급 주문 앞에 둡니다.                                                                          |
| /startattack            | 자동 공격을 켭니다. 이미 켜져 있으면 그대로 둡니다(끄지 않음).                                                                                |
| /stopattack             | 자동 공격을 끕니다. 변이·실명 걸린 적을 실수로 때리지 않게 할 때.                                                                             |
| /target 이름            | 이름으로 대상 지정. `/target 호거`                                                                                                            |
| /targetenemy            | 가까운 적을 차례로 대상 지정(Tab 키와 같음).                                                                                                  |
| /assist 이름            | 그 사람의 대상을 내 대상으로. 공격대에서 탱커 대상 따라가기. `/assist [@focus]`                                                               |
| /focus, /clearfocus     | 주시 대상 지정·해제(6장).                                                                                                                     |
| /cleartarget            | 대상 해제.                                                                                                                                    |
| /petattack              | 소환수가 내 대상을 공격.                                                                                                                      |
| /petfollow, /petpassive | 소환수 따라오기, 수동 태세(스스로 공격 안 함).                                                                                                |
| /cancelaura 효과        | 나에게 걸린 이로운 효과를 끕니다. `/cancelaura 얼음 방패`                                                                                     |
| /cancelform             | 드루이드 변신 해제. 조건을 붙일 수 있습니다. `/cancelform [form]`                                                                             |
| /equip 아이템           | 장비 착용. 무기·방패 교체에 씁니다.                                                                                                           |
| /party, /raid, /say     | 파티·공격대·일반 대화. `/party 변이 → %t`에서 `%t`는 현재 대상의 이름으로 바뀝니다.                                                           |
| /run 코드               | 간단한 스크립트 실행. 처음 쓸 때 “스크립트를 허용하겠습니까” 창이 뜰 수 있습니다. 드루이드 장에서 변신 번호를 확인할 때 씁니다.               |

## 8. 자주 쓰는 조건

모든 조건은 앞에 `no`를 붙여 반대로 쓸 수 있습니다(`combat` ↔ `nocombat`).

| 조건                                    | 참이 되는 경우                                                                      |
|-----------------------------------------|-------------------------------------------------------------------------------------|
| harm / help                             | 그 유닛이 공격 가능한 적 / 도울 수 있는 아군                                        |
| dead                                    | 그 유닛이 죽어 있음                                                                 |
| exists                                  | 그 유닛이 존재함. `[@focus,exists]` = 주시 대상이 지정돼 있음                       |
| combat                                  | **내가** 전투 중(대상이 아니라 나 기준)                                             |
| mod                                     | 아무 보조키(Shift·Ctrl·Alt)나 누르고 있음                                           |
| mod:shift / ctrl / alt                  | 그 키를 누른 채 버튼을 누름                                                         |
| btn:1 / btn:2                           | 버튼을 마우스 왼쪽 / 오른쪽으로 클릭(단축키로 누르면 btn:1)                         |
| stance:n                                | 전사 태세 번호. 1 전투 태세 · 2 방어 태세 · 3 광폭 태세. `stance:0`은 태세 없음     |
| form:n                                  | 드루이드 변신 번호(드루이드 장 참고). `form`만 쓰면 “아무 변신이든 하고 있음”       |
| stealth                                 | 은신 중(도적 은신, 드루이드 숨기)                                                   |
| pet                                     | 소환수가 나와 있음. 소환수가 죽었거나 소환 해제면 `nopet`                           |
| group / group:raid                      | 파티에 있음 / 공격대에 있음                                                         |
| channeling                              | 정신 집중 주문(생명력 흡수, 눈보라 등)을 쓰는 중                                    |
| equipped:방패                           | 그 종류의 장비를 착용 중. 종류 이름은 아이템 툴팁 오른쪽에 적힌 대로(방패, 단검 등) |
| mounted / indoors / outdoors / swimming | 탈것 탑승 / 실내 / 실외 / 수영 중                                                   |

## 9. 특수 문법

### \#showtooltip

매크로 첫 줄에 쓰면 버튼이 진짜 주문 버튼처럼 보입니다: 아이콘, 마우스를 올렸을 때 툴팁, 재사용 대기시간, 사거리 밖일 때 빨간색 표시. 아이콘은 반드시 물음표(?)로 골라야 적용됩니다.

- `#showtooltip`만 쓰면: 지금 조건에서 실제로 나갈 주문을 자동으로 보여 줍니다. Shift를 누르면 아이콘이 바뀌는 식.
- `#showtooltip 사냥꾼의 징표`처럼 이름을 쓰면: 항상 그 주문의 아이콘으로 고정합니다. 첫 명령 줄이 주문이 아닐 때(예: `/petattack`) 쓰면 좋습니다.

### 느낌표 `!`

변신, 자동 사격, 은신 같은 주문은 한 번 더 누르면 꺼집니다. 매크로를 연타하다 보면 의도치 않게 꺼지는 사고가 생기므로 `/cast !표범 변신`처럼 느낌표를 붙여 “이미 켜져 있으면 그대로 둬라”라고 알려 줍니다.

### /castsequence

쉼표로 나열한 주문을 누를 때마다 하나씩 차례로 씁니다.

```
/castsequence reset=target 부패, 고통의 저주, 제물
```

**다음으로 넘어가는 조건:** 주문이 **성공적으로 시전되었을 때만** 다음 주문으로 넘어갑니다. 사거리 밖, 마나 부족, 재사용 대기 중, 시전 중 끊김이면 넘어가지 않고 다음에 누를 때 **같은 주문을 다시 시도**합니다. 그래서 목록 중간에 재사용 대기시간이 긴 주문이 있으면 그 자리에서 버튼이 막혀 버립니다. 재사용 대기가 없는 주문끼리 묶으세요.

**처음으로 돌아가는 조건(reset):**

| 쓰는 법           | 처음으로 돌아가는 때                                                                                                                             |
|-------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|
| `reset=target`    | 대상을 바꿨을 때                                                                                                                                 |
| `reset=combat`    | 전투에 **들어가거나** 전투가 **끝났을 때**(둘 다). 전투 밖에서 첫 주문으로 선공을 걸면 그 순간 전투가 시작되면서 처음으로 돌아갈 수 있으니 주의. |
| `reset=15`        | 마지막으로 누른 뒤 15초 동안 안 눌렀을 때(숫자는 초)                                                                                             |
| `reset=shift`     | Shift를 누른 채 눌렀을 때(ctrl, alt도 가능)                                                                                                      |
| `reset=target/15` | 슬래시로 여러 조건을 묶으면 그중 하나라도 일어났을 때                                                                                            |

조건문도 붙일 수 있습니다: `/castsequence [@mouseover,harm][] reset=target 부패, 고통의 저주`.

### /stopcasting

시전 중인 주문(시전바가 차오르는 중인 주문)을 즉시 취소합니다. 차단 주문 앞에 두면 “얼음 화살을 쓰는 중이라 차단이 안 나감” 같은 상황이 없어집니다. 시전 중이 아닐 때는 아무 일도 하지 않으니 항상 넣어 둬도 됩니다.

### 주문 계급(랭크)

클래식 계열은 같은 주문에 1레벨, 2레벨… 여러 계급이 있습니다. 이름만 쓰면 **배운 것 중 가장 높은 계급**이 나갑니다. 마나를 아끼려고 낮은 계급을 쓰고 싶다면, 주문서에서 그 계급의 주문을 Shift+클릭하세요. 계급 표기까지 붙은 이름이 들어갑니다. 포에버 개편으로 계급 구조가 달라졌을 수도 있습니다.

## 10. 모든 직업에 통하는 핵심 패턴 3가지 { #patterns }

직업별 매크로는 거의 다 아래 세 가지의 변형입니다. **주문 이름 자리만 바꾸면** 어느 직업에서든 그대로 쓸 수 있습니다.

**패턴 A. 마우스오버 공격** · 대상을 바꾸지 않고 마우스를 올린 적에게

```
#showtooltip
/cast [@mouseover,harm,nodead][] 주문 이름
```

**줄별 해설**

1.  아이콘·툴팁·대기시간 표시.
2.  마우스를 올린 적이 살아 있으면 그 적에게, 아니면 현재 대상에게. (3장의 표와 같은 흐름)

**어디에 쓰나**

도트 돌리기, 차단, 군중 제어. 대상을 탱커가 잡은 적에 고정해 두고 다른 적은 마우스로 처리합니다.

**패턴 B. 마우스오버 치유 + 자기 시전** · 힐러의 기본기

```
#showtooltip
/cast [mod:alt,@player][@mouseover,help,nodead][help,nodead][@player] 주문 이름
```

**줄별 해설**

1.  아이콘·툴팁·대기시간 표시.
2.  네 묶음을 왼쪽부터 검사합니다. 아래 표를 보세요.

**상황별 동작**

| 상황                                     | 누구에게           |
|------------------------------------------|--------------------|
| Alt를 누른 채 누름                       | 나 (묶음 1)        |
| 살아 있는 아군 위에 마우스(파티 창 포함) | 그 아군 (묶음 2)   |
| 마우스 없음, 현재 대상이 살아 있는 아군  | 현재 대상 (묶음 3) |
| 마우스 없음, 현재 대상이 적이거나 없음   | 나 (묶음 4)        |

**어디에 쓰나**

파티 창 위에 마우스를 올리고 단축키만 누르는 방식으로 힐을 합니다. 적을 대상으로 잡은 채로도 힐이 되므로 딜과 힐을 오가는 하이브리드 직업에 특히 좋습니다.

**패턴 C. 주시 대상 차단** · 탱커를 치면서 뒤쪽 치유사 끊기

```
#showtooltip
/stopcasting
/cast [@focus,harm,nodead][] 차단 주문
```

**줄별 해설**

1.  아이콘·툴팁·대기시간 표시.
2.  내가 시전 중이면 즉시 끊어서 차단이 늦지 않게 합니다.
3.  주시 대상(6장)이 살아 있는 적이면 그 적에게, 주시 대상이 없거나 죽었으면 현재 대상에게.

## 직업별 매크로 { #classes }

### 전사 { #warrior }

태세 번호: 1 전투 태세 · 2 방어 태세 · 3 광폭 태세. 전사 기술은 태세마다 쓸 수 있는 게 정해져 있어서 `stance` 조건이 핵심입니다. 태세를 바꾸면 분노가 일정량만 남고 줄어드니 태세 전환이 들어가는 매크로는 분노 낭비를 감안하세요.

**돌진 / 봉쇄 한 버튼** · 태세와 전투 여부에 따라 알아서 선택

```
#showtooltip
/cast [nocombat,stance:1] 돌진; [combat,stance:3] 봉쇄; [nocombat] 전투 태세; 광폭 태세
```

*돌진: 전투 태세, 전투 중 사용 불가 · 봉쇄: 30레벨 광폭 태세 퀘스트, 광폭 태세 전용*

**줄별 해설**

1.  아이콘 자동 표시. 지금 누르면 나갈 주문(돌진/봉쇄/태세)이 보입니다.
2.  세미콜론으로 나뉜 네 덩어리를 왼쪽부터 검사합니다.

**상황별 동작**

| 상황                     | 결과                                   |
|--------------------------|----------------------------------------|
| 전투 밖 + 전투 태세      | 돌진                                   |
| 전투 중 + 광폭 태세      | 봉쇄                                   |
| 전투 밖 + 방어·광폭 태세 | 전투 태세로 전환. 한 번 더 누르면 돌진 |
| 전투 중 + 전투·방어 태세 | 광폭 태세로 전환. 한 번 더 누르면 봉쇄 |

**알아둘 점**

30레벨 전이라 광폭 태세가 없으면 `/cast [nocombat,stance:1] 돌진; [nocombat] 전투 태세`로 줄여 쓰세요. 배우지 않은 주문 이름이 들어 있으면 그 부분은 실패합니다.

**차단 한 버튼** · 광폭이면 자루 공격, 방패가 있으면 방패 가격

```
#showtooltip
/cast [stance:3] 자루 공격; [equipped:방패] 방패 가격
```

*자루 공격: 38레벨, 광폭 태세 전용 · 방패 가격: 12레벨, 전투·방어 태세 + 방패 착용*

**상황별 동작**

| 상황                                  | 결과                                |
|---------------------------------------|-------------------------------------|
| 광폭 태세                             | 자루 공격                           |
| 전투·방어 태세 + 방패 착용            | 방패 가격                           |
| 전투·방어 태세 + 방패 없음(양손 무기) | 아무 일도 안 함(맞는 덩어리가 없음) |

**알아둘 점**

마우스오버로 쓰고 싶으면 두 덩어리 모두에 대상을 넣으세요: `[stance:3,@mouseover,harm,nodead][stance:3] 자루 공격; [equipped:방패,@mouseover,harm,nodead][equipped:방패] 방패 가격`.

**영웅의 일격 + 자동 공격** · 자동 공격이 꺼져 있어도 켜 줌

```
#showtooltip
/startattack
/cast 영웅의 일격
```

**줄별 해설**

1.  아이콘 자동 표시.
2.  자동 공격을 켭니다. 이미 켜져 있으면 그대로(꺼지지 않음). 전역 대기가 없어서 다음 줄과 같이 실행됩니다.
3.  영웅의 일격은 즉시 나가는 게 아니라 **다음 근접 공격을 대체**하도록 예약됩니다. 예약 중에는 버튼이 빛납니다.

**알아둘 점**

같은 방식으로 `/cast 영웅의 일격` 자리에 다른 기술(제압, 방어구 가르기 등)을 넣은 “자동 공격 보장” 버튼을 만들 수 있습니다.

### 도적 { #rogue }

도적의 핵심 조건은 `stealth`입니다. 같은 버튼이 은신 중에는 오프너, 은신 밖에서는 기본기가 되게 만들면 단축키를 절약할 수 있습니다.

**은신 여부로 기술 전환** · 한 버튼으로 오프너와 기본기

```
#showtooltip
/cast [stealth] 비열한 습격; 사악한 일격
```

*비열한 습격: 은신 중, 에너지 60, 기절 4초 · 사악한 일격: 에너지 45*

**상황별 동작**

| 상황      | 결과                                 |
|-----------|--------------------------------------|
| 은신 중   | 비열한 습격(은신이 풀리고 전투 시작) |
| 은신 아님 | 사악한 일격                          |

**단검 도적용**

`/cast [stealth] 매복; 기습`. 매복과 기습은 둘 다 **주무기가 단검**이고 **대상 뒤**에 있어야 합니다.

**마우스오버 발차기** · 패턴 A 응용

```
#showtooltip
/cast [@mouseover,harm,nodead][] 발차기
```

*12레벨, 에너지 25, 재사용 10초, 근접 사거리*

**줄별 해설**

1.  아이콘 자동 표시.
2.  마우스 올린 적에게 차단, 없으면 현재 대상에게. 도적은 시전하는 주문이 없어서 `/stopcasting`이 필요 없습니다.

**주시 대상 실명** · 때리던 대상을 놓치지 않고 다른 적 제어

```
#showtooltip
/cast [@focus,harm,nodead][] 실명
```

*34레벨, 에너지 30, 재사용 5분, 사거리 10미터, 실명 가루 필요*

**줄별 해설**

1.  아이콘 자동 표시.
2.  주시 대상이 살아 있는 적이면 그 적에게, 아니면 현재 대상에게.

**알아둘 점**

실명은 피해를 받으면 풀립니다. 파티라면 `/party 실명 → %t` 같은 줄을 추가해 알리는 것도 방법입니다(주시 대상에 걸었을 때 %t는 현재 대상 이름이라는 점은 주의).

### 마법사 { #mage }

마법사는 시전 주문이 많아서 `/stopcasting`과 주시 대상 활용이 특히 중요합니다.

**변이: 마우스오버 → 주시 → 현재 대상** · 군중 제어 대상을 세 단계로 선택

```
#showtooltip
/cast [@mouseover,harm,nodead][@focus,harm,nodead][] 변이
```

*8레벨, 시전 1.5초, 사거리 30미터, 야수·인간형만*

**상황별 동작**

| 상황                        | 누구에게  |
|-----------------------------|-----------|
| 살아 있는 적 위에 마우스    | 그 적     |
| 마우스 없음, 주시 대상 있음 | 주시 대상 |
| 둘 다 없음                  | 현재 대상 |

**알아둘 점**

변이는 한 번에 한 대상에게만 유지됩니다. 풀린 양을 다시 변이하려면 전투 시작 전에 그 적을 `/focus`로 잡아 두면 편합니다.

**시전 끊고 마법 차단** · 패턴 C 그대로

```
#showtooltip
/stopcasting
/cast [@focus,harm,nodead][] 마법 차단
```

*재사용 30초, 사거리 30미터, 같은 계열 주문 10초 봉쇄*

**줄별 해설**

1.  아이콘 자동 표시.
2.  얼음 화살 시전 중이라도 즉시 끊습니다.
3.  주시 대상 또는 현재 대상 차단.

**얼음 방패 켜고 끄기** · 한 번 누르면 사용, 다시 누르면 해제

```
#showtooltip
/cancelaura 얼음 방패
/cast 얼음 방패
```

*재사용 5분, 10초간 모든 피해 면역, 그동안 이동·공격·시전 불가*

**상황별 동작**

| 상황                | 2번 줄                        | 3번 줄                        |
|---------------------|-------------------------------|-------------------------------|
| 얼음 방패 없음      | 지울 효과가 없어 아무 일 없음 | 얼음 방패 시전                |
| 얼음 방패 안에 있음 | 얼음 방패 해제                | 재사용 대기 중이라 실패(무해) |

**알아둘 점**

클래식 계열에서 얼음 방패는 냉기 특성으로 배우는 주문이었습니다. 포에버 개편 이후 습득 방식은 주문서에서 확인하세요.

### 흑마법사 { #warlock }

흑마법사는 도트 여러 개와 소환수 기술을 다룹니다. 소환수의 기술도 `/cast 기술 이름`으로 매크로에서 쓸 수 있습니다.

**도트 세 개 순서대로** · castsequence의 좋은 예

```
#showtooltip
/castsequence reset=target 부패, 고통의 저주, 제물
```

*부패: 시전 2초(특성으로 단축) · 고통의 저주: 즉시, 24초 · 제물: 시전 2초*

**줄별 해설**

1.  아이콘 자동 표시. **다음에 나갈 주문**의 아이콘이 보입니다.
2.  누를 때마다 부패 → 고통의 저주 → 제물. 세 번째 이후 또 누르면 다시 부패부터. 대상을 바꾸면 부패부터.

**상황별 동작**

| 상황                              | 결과                                       |
|-----------------------------------|--------------------------------------------|
| 부패 시전 중에 움직여서 끊김      | 넘어가지 않음. 다음에 누르면 다시 부패     |
| 고통의 저주까지 쓰고 대상 변경    | 새 대상에게 부패부터                       |
| 같은 적이 오래 살아서 도트가 끝남 | 순서대로 계속 누르면 다시 부패부터 한 바퀴 |

**왜 reset=combat이 아닌가**

`reset=combat`은 전투에 **들어갈 때도** 초기화됩니다. 전투 밖에서 부패로 선공하면 그 순간 전투가 시작되면서 다시 부패로 돌아갈 수 있어 뺐습니다.

**소환수 주문 잠금 (지옥사냥개)** · 소환수 기술도 /cast로 씁니다

```
#showtooltip
/cast [@focus,harm,nodead][] 주문 잠금
```

*지옥사냥개 소환 필요, 재사용 30초, 사거리 30미터*

**줄별 해설**

1.  아이콘 자동 표시.
2.  지옥사냥개가 주시 대상 또는 현재 대상에게 주문 잠금. 흑마법사 본인은 시전을 끊을 필요가 없어서 `/stopcasting`은 넣지 않았습니다.

**서큐버스용**

주문 이름을 **현혹**으로 바꾸세요: `/cast [@focus,harm,nodead][] 현혹`. 현혹은 인간형에게만 걸립니다.

**마우스오버 공포** · 패턴 A

```
#showtooltip
/cast [@mouseover,harm,nodead][] 공포
```

*시전 1.5초, 사거리 20미터, 한 번에 한 대상*

**알아둘 점**

공포에 걸린 적은 도망치다 다른 몬스터를 끌어올 수 있어서 인스턴스에서는 조심해서 쓰세요.

### 사냥꾼 { #hunter }

사냥꾼 매크로의 핵심은 두 가지입니다. 전역 대기가 없는 **자동 사격**과 **소환수 명령**을 주문과 한 버튼에 묶는 것.

**징표 + 소환수 공격** · 전투 시작 버튼

```
#showtooltip 사냥꾼의 징표
/petattack
/cast 사냥꾼의 징표
```

*징표: 6레벨, 즉시, 사거리 100미터*

**줄별 해설**

1.  첫 명령 줄이 주문이 아니라서 징표 아이콘으로 고정했습니다.
2.  소환수에게 현재 대상을 공격하라고 명령(전역 대기 없음).
3.  사냥꾼의 징표 시전.

**자동 사격을 끄지 않는 신비한 사격** · 느낌표(!)의 쓰임새

```
#showtooltip 신비한 사격
/cast !자동 사격
/cast 신비한 사격
```

*신비한 사격: 재사용 6초, 사거리 8~35미터*

**줄별 해설**

1.  신비한 사격 아이콘으로 고정(대기시간 확인용).
2.  자동 사격을 켭니다. **느낌표** 덕분에 이미 켜져 있으면 끄지 않습니다. 느낌표가 없으면 연타할 때마다 자동 사격이 꺼졌다 켜졌다 합니다.
3.  신비한 사격. 자동 사격은 전역 대기가 없어서 같은 누름에 함께 나갑니다.

**같은 틀로 만들 수 있는 것**

3번 줄만 바꾸세요: 독사 쐐기, 일제 사격, 충격포 등.

**소환수 관리 한 버튼** · 부르기, 치료, 되살리기

```
#showtooltip
/cast [mod:shift] 야수 되살리기; [nopet] 야수 부르기; 동물 치료
```

*야수 부르기·되살리기: 10레벨 · 동물 치료: 12레벨, 정신 집중 5초, 사거리 20미터*

**상황별 동작**

| 상황                           | 결과                                                                          |
|--------------------------------|-------------------------------------------------------------------------------|
| Shift를 누름                   | 야수 되살리기(시전 10초)                                                      |
| 소환수가 나와 있지 않음        | 야수 부르기                                                                   |
| 소환수가 죽어 있음(Shift 없이) | 야수 부르기가 시도되지만 “소환수가 죽었다”는 오류. Shift+누름으로 되살리세요. |
| 소환수가 살아서 옆에 있음      | 동물 치료                                                                     |

### 드루이드 { #druid }

변신 번호는 태세 바(단축바 위 작은 버튼들)의 **왼쪽부터 순서**입니다. 클래식 계열에서 모두 배웠다면 1 곰(광포한 곰) · 2 바다표범 · 3 표범 · 4 치타 · 5 조화 특성 변신. **아직 못 배운 변신이 있으면 번호가 앞으로 당겨집니다**(예: 바다표범 변신 퀘스트를 안 했으면 표범이 2번). 확실히 하려면 변신한 상태에서 채팅창에 `/run print(GetShapeshiftForm())`을 입력하세요. 지금 변신의 번호가 출력됩니다.

**변신 풀고 바로 회복** · 표범·곰 상태에서 한 번에 힐

```
#showtooltip
/cancelform [form]
/cast [mod:alt,@player][@mouseover,help,nodead][help,nodead][@player] 회복
```

*회복: 4레벨, 즉시, 12초 지속 치유*

**줄별 해설**

1.  아이콘 자동 표시.
2.  무엇이든 변신 중이면 풀기. 변신 해제는 전역 대기가 없어서 다음 줄이 같은 누름에 나갑니다.
3.  패턴 B로 회복 시전.

**같은 틀로 만들 수 있는 것**

재생, 치유의 손길 등 시전 주문도 가능합니다. 단, 변신 해제 후 마나가 충분해야 합니다.

**곰 / 표범 전환** · Shift 하나로 역할 전환

```
#showtooltip
/cancelform [mod:shift,noform:1][nomod,noform:3]
/cast [mod:shift] !곰 변신; !표범 변신
```

*곰 변신: 10레벨 퀘스트 · 표범 변신: 20레벨 · 변신 번호 곰=1, 표범=3 기준*

**줄별 해설**

1.  아이콘 자동 표시.
2.  Shift를 눌렀는데 곰(1번)이 아니면, 또는 Shift 없이 눌렀는데 표범(3번)이 아니면 지금 변신을 먼저 풉니다. 변신 상태에서 다른 변신으로 바로 넘어가지 못하는 경우를 대비한 줄입니다. 변신하지 않은 상태면 풀 게 없으니 아무 일도 없습니다.
3.  Shift면 곰, 아니면 표범. **느낌표**로 이미 그 변신 중일 때 눌러도 풀리지 않게 합니다.

**상황별 동작**

| 지금 상태         | 그냥 누름           | Shift+누름          |
|-------------------|---------------------|---------------------|
| 인간형(변신 없음) | 표범 변신           | 곰 변신             |
| 표범              | 그대로 표범         | 표범 해제 → 곰 변신 |
| 곰                | 곰 해제 → 표범 변신 | 그대로 곰           |

**꼭 고칠 부분**

- 40레벨에 광포한 곰 변신을 배우면 `곰 변신`을 `광포한 곰 변신`으로 바꾸세요.
- 표범 번호가 3이 아니라면(위 설명 참고) `noform:3`의 숫자를 바꾸세요.

**정신 자극 (마우스오버 치유사)** · 파티 힐러에게 마나 주기

```
#showtooltip
/cancelform [form]
/cast [@mouseover,help,nodead][help,nodead][@player] 정신 자극
```

*40레벨, 재사용 6분, 사거리 30미터, 변신 중 사용 불가*

**줄별 해설**

1.  아이콘 자동 표시.
2.  정신 자극은 변신 중에 쓸 수 없어서 먼저 변신을 풉니다.
3.  마우스 올린 아군 → 아군 대상 → 나.

**마우스오버 연쇄 치유** · 패턴 B

## 11. 매크로가 안 될 때 확인 순서

| 증상                             | 원인과 해결                                                                                                                                        |
|----------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| 버튼 아이콘이 빨간 물음표로 남음 | `#showtooltip`이 주문을 찾지 못함. 주문 이름 오타가 가장 흔합니다. Shift+클릭으로 다시 넣으세요. 띄어쓰기와 콜론(`:`) 뒤 공백까지 정확해야 합니다. |
| 눌러도 아무 반응 없음            | 맞는 조건 묶음이 하나도 없음. 마지막에 `[]`나 조건 없는 덩어리를 넣었는지 확인. 조건 철자(`nodead`, `@mouseover`) 확인.                            |
| 두 번째 주문이 안 나감           | 전역 대기 규칙(2장). 두 주문 모두 전역 대기가 있으면 첫 번째만 나갑니다.                                                                           |
| castsequence가 한 주문에서 멈춤  | 그 주문이 재사용 대기 중이거나 배우지 않은 주문. 목록에서 빼거나 reset을 추가하세요.                                                               |
| 인터넷에서 복사한 매크로가 안 됨 | 영어 주문 이름이 들어 있음. 한글 클라이언트는 한글 이름이어야 합니다. 조건(`[harm]` 등)과 명령(`/cast`)은 영어 그대로 둡니다.                      |
| 저장이 안 되거나 끝이 잘림       | 255자 초과. 조건을 줄이거나 매크로를 나누세요.                                                                                                     |

## 12. 매크로로 할 수 없는 것

- **자동 로테이션.** 매크로는 재사용 대기시간, 대상의 체력, 디버프 남은 시간, 내 마나를 보고 판단하지 못합니다. “버튼 하나로 딜 사이클”은 만들 수 없게 막혀 있습니다.
- **기다리기.** 몇 초 기다렸다가 다음 줄을 실행하는 기능은 없습니다.
- **한 번에 전역 대기 주문 두 개.** 2장 참고.
- **/equipset.** 클래식 계열에는 장비 관리자가 없었으므로 장비 교체는 `/equip 아이템 이름`으로 하세요. 포에버에서 장비 관리자가 추가되었는지는 확인하지 못했습니다.
- **리테일 전문화 조건.** 리테일의 `[spec]`, `[talent]` 조건은 클래식 특성 구조와 맞지 않습니다. 포에버 개편 이후 달라질 수 있으니 필요하면 직접 시험해 보세요.
- **애드온 제한.** 포에버는 최신 리테일과 같은 애드온 제한(전투 수치 비공개 등)을 일부 쓴다고 알려져 있습니다. 매크로 명령 자체의 제한은 공식 발표를 찾지 못했습니다.

## 13. 연습 문제

먼저 직접 써 본 다음 펼쳐서 답을 확인하세요. 답과 모양이 달라도 동작이 같으면 정답입니다.

??? question "① 마법사: 마우스 올린 적이 있으면 얼음 화살, 없으면 현재 대상. Shift를 누르면 같은 규칙으로 화염구."

    ```
    #showtooltip
    /cast [mod:shift,@mouseover,harm,nodead][mod:shift] 화염구; [@mouseover,harm,nodead][] 얼음 화살
    ```

    세미콜론 앞 덩어리는 Shift일 때(마우스오버 → 현재 대상), 뒤 덩어리는 나머지 경우입니다. `mod:shift`를 앞 덩어리의 **두 묶음 모두**에 적어야 합니다. 두 번째 묶음을 그냥 `[]`로 쓰면 Shift 없이도 항상 참이 되어 얼음 화살까지 가지 못합니다.

??? question "② 사제: 오른쪽 클릭하면 나에게, 왼쪽 클릭하면 현재 대상에게 소생."

    ```
    #showtooltip
    /cast [btn:2,@player][help,nodead][@player] 소생
    ```

    `btn:2`는 오른쪽 클릭. 현재 대상이 아군이 아니면 마지막 `[@player]`가 받아 줍니다.

??? question "③ 전사: 전투 태세일 때만 제압, 아니면 전투 태세로 바꾸기."

    ```
    #showtooltip
    /cast [stance:1] 제압; 전투 태세
    ```

    세미콜론 뒤에 조건이 없으면 “나머지 전부”라는 뜻입니다. 제압은 적이 회피한 직후에만 쓸 수 있습니다.

??? question "④ 도적: 은신이 아니면 은신, 은신 중이면 매복."

    ```
    #showtooltip
    /cast [nostealth] 은신; 매복
    ```

    은신은 전투 중에 쓸 수 없고, 다시 누르면 은신이 풀리는 토글이라는 점이 핵심입니다. 은신 중에는 첫 덩어리가 틀리므로 은신이 풀리지 않고 매복이 나갑니다.

??? question "⑤ 흑마법사: 주시 대상이 있으면 거기에 공포, 없으면 마우스오버, 그것도 없으면 현재 대상."

    ```
    #showtooltip
    /cast [@focus,harm,nodead][@mouseover,harm,nodead][] 공포
    ```

    묶음의 순서가 곧 우선순위입니다. 마법사 변이 매크로와 앞 두 묶음의 순서만 다릅니다.

- [ ] 주문 계급(랭크) 구조가 클래식과 같은지
