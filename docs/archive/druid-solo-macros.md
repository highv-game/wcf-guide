# 야성 드루이드 솔플 가이드 (포에버)

> 최종 수정: 2026-10-01

## 솔플 전투 방식

솔플 야성 드루이드는 "천벌로 당기고, 안전하면 표범, 위험하면 곰"이 기본이다. 10\~19레벨은 표범이 없어서 곰으로 사냥하고, 20레벨 표범 변신 퀘스트를 끝낸 뒤부터 한 마리씩은 표범, 여러 마리나 강한 몹은 곰으로 잡는다. Forever에서는 무기 DPS가 곰·표범 피해에 들어가므로 무기부터 챙긴다.

### 레벨별 기술 (Forever)

| 레벨 | 배우는 기술 | 솔플에서의 의미 |
| --- | --- | --- |
| 1\~8 | 천벌, 치유의 손길, 달빛 섬광(4), 회복(4), 가시(6), 휘감는 뿌리(8) | 캐스터로 사냥 |
| 10 | 곰 변신, 포효, 후려치기, 위협의 포효, 자연의 손아귀 | 곰 사냥 시작 |
| 12\~16 | 분노(12), 강타(14), 휘둘러치기(16) | 분노 시작, 도주·시전 끊기, 여러 마리 |
| 20 | 표범 변신, 할퀴기, 도려내기, 숨기, 청명의 전조 | 표범 사냥 시작 |
| 22 | 칼날 발톱 | 뒤에서 쓰는 강한 연계 기술, 숨기 오프너 |
| 24 | 갈퀴 발톱, 맹공격 | 출혈 오프너, 피해 버프 |
| 26\~28 | 질주(26), 웅크리기(28) | 도주·이동, 위협 감소(솔플에서는 거의 안 씀) |
| 30 | 치타 변신 | 이동속도 +40% |

흉포한 이빨(32), 암습(36), 광포한 재생력(36)은 30레벨 이후다. 레벨은 ForeverChanges 주문서 기준이다.

### 1\~9레벨: 캐스터

1. 천벌 2번으로 당긴다. 몹이 붙으면 달빛 섬광을 한 번 넣는다.
2. 나머지는 지팡이 평타로 마무리해 마나를 아낀다.
3. 8레벨부터는 위험하면 휘감는 뿌리로 묶고 물러서서 천벌을 더 쏜다.
4. 전투 후에는 회복을 걸고 다음 몹으로 간다. 가시와 야생의 징표는 항상 유지한다.

### 10\~19레벨: 곰

1. 자연의 손아귀를 켜둔다(때린 몹이 뿌리에 묶인다).
2. 천벌 1\~2번으로 당기고, 몹이 다가오는 동안 곰으로 변신한다.
3. 12레벨부터는 변신 직후 분노로 분노를 채운다.
4. 위협의 포효를 한 번 걸고, 후려치기를 분노가 차는 대로 누른다.
5. 2마리 이상이면 휘둘러치기, 도망치거나 주문을 쓰는 몹은 강타로 끊는다.
6. 전투가 끝나면 변신을 풀고 회복 한 번, 마나가 남으면 다음 몹을 천벌로 당긴다.

### 20레벨 이후: 표범

1. 숨기로 접근해 몹 뒤로 돈다.
2. 오프너: 20\~21은 할퀴기, 22부터 칼날 발톱, 24부터는 출혈이 들어가는 갈퀴 발톱.
3. 연계 점수 쌓기: 뒤에 있으면 칼날 발톱, 정면이면 할퀴기.
4. 마무리: 연계 점수 4\~5개에 몹이 6초 이상 버틸 것 같으면 도려내기, 아니면 할퀴기를 계속 누른다(Wowhead).
5. 청명의 전조가 켜지면 다음 기술이 무료다. 가장 비싼 칼날 발톱에 쓴다.
6. 24부터 맹공격은 전투 시작 직전에 켜둔다.

### 상황별 대처

| 상황 | 대처 |
| --- | --- |
| 2마리 이상이 붙음 | 곰으로 바꾸고 위협의 포효 + 휘둘러치기 |
| 체력 30% 이하 | 곰으로 버티거나, 한 마리만 남았으면 변신 풀고 재생 → 다시 변신 |
| 주문 시전 몹 | 강타나 야성의 돌진(곰)으로 끊는다 |
| 도망치는 몹 | 표범이면 질주로 따라가고, 곰이면 야성의 돌진 |
| 내가 도망쳐야 함 | 휘감는 뿌리로 묶고 표범 + 질주. 나이트 엘프는 그림자 숨기로 전투를 끊는다 |
| 마나 부족 | 변신을 자주 바꾸지 않는다. 곰으로 싸우는 동안 마나가 찬다. 스카이본은 지맥 읽기로 쉬는 시간을 줄인다 |
| 채집 동선 | 표범 + 숨기로 몹을 피해 약초까지 간다 |

- 변신은 매번 마나를 쓴다. 전투 중 힐은 한 번만 하고, 완전히 회복하는 건 전투 뒤에 한다.
- 통곡의 동굴 송곳니 세트 5부위를 모두 입으면 표범이 뱀 모습이 된다. 근접 공격 시 기절 효과(Dream Venom)가 붙는다는 주장은 한 곳에서만 확인됐다.
- Forever에서는 변신 재변신으로 기력을 얻는 파워시프팅이 사라졌다.

출처: [ForeverChanges 드루이드 주문서](https://foreverchanges.pro/spellbook/druid), [Wowhead 20레벨 야성 딜러](https://www.wowhead.com/forever/guide/classes/druid/feral/level-20-dps-overview), [Wowhead 20레벨 곰 탱커](https://www.wowhead.com/forever/guide/classes/druid/feral/level-20-tank-overview), [Icy Veins 야성](https://www.icy-veins.com/wow-forever/feral-druid-melee-dps-and-tank-pve-guide)

## 매크로 구성

핵심은 "같은 키가 폼마다 같은 역할을 하도록" 만드는 것이다. 드루이드의 태세 번호는 배운 변신 순서대로 붙어서, 세 형태를 다 배우면 1 곰, 2 바다표범, 3 표범, 30레벨 이후 4 치타다. 바다표범을 안 배웠다면 아래 매크로의 stance:3을 2로 바꾼다. 명령어와 조건은 영어, 주문 이름만 한글이다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

### 1. 만능 공격 버튼 (키 1)

추천하는 가장 중요한 매크로다. 캐스터면 천벌, 곰이면 후려치기, 표범이면 할퀴기가 나가고, 표범 숨기 중에는 칼날 발톱으로 기습한다.

```
#showtooltip
/startattack [nostealth,stance:1/3]
/cast [stance:1] 후려치기; [stance:3,stealth] 칼날 발톱; [stance:3] 할퀴기; 천벌
```

22레벨 전에는 칼날 발톱이 없으니 그 부분을 할퀴기로 바꾼다. 24레벨부터는 갈퀴 발톱으로 바꿔 출혈로 시작해도 된다.

### 2. 보조 공격 버튼 (키 2)

곰이면 휘둘러치기, 표범이면 마무리 기술 도려내기, 캐스터면 달빛 섬광이다.

```
#showtooltip
/startattack [stance:1/3]
/cast [stance:1] 휘둘러치기; [stance:3] 도려내기; 달빛 섬광
```

### 3. 폼 변신 (키 R, F)

같은 변신을 다시 눌러도 풀리지 않게 막는다. 표범 키는 두 번째 누르면 숨기다.

곰 (R):

```
#showtooltip 곰 변신
/cast [nostance:1] 곰 변신
```

표범 + 숨기 (F):

```
#showtooltip
/cast [nostance:3] 표범 변신; [nostealth,nocombat] 숨기
```

### 4. 변신 풀고 힐·해제 (Ctrl+1\~4)

어느 폼에서든 누르면 변신을 풀고 바로 시전한다. 대상은 마우스를 올린 아군, 없으면 내 대상이 아군일 때 대상, 둘 다 아니면 나다. 솔플에서는 적을 잡은 채 눌러도 나에게 걸리고, 던전에서는 파티 프레임에 마우스를 올리고 누른다. 기본 단축바 바로 위 추가 단축바의 1\~4번 칸에 줄을 맞춰 둔다(추가 바는 변신해도 안 바뀐다).

Ctrl+1 재생:

```
#showtooltip 재생
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 재생
```

Ctrl+2 회복:

```
#showtooltip 회복
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 회복
```

Ctrl+3 해독 (26레벨부터 독 해제로 바꾼다):

```
#showtooltip 해독
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 해독
```

Ctrl+4 저주 해제 (24레벨):

```
#showtooltip 저주 해제
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 저주 해제
```

### 5. 돌진·이동 (키 E)

곰이면 야성의 돌진, 표범이면 질주(26레벨)다.

```
#showtooltip
/cast [stance:1,@mouseover,harm,nodead][stance:1] 야성의 돌진; [stance:3] 질주
```

### 6. 차단·묶기 (키 4, Alt+4 겨울잠)

곰이면 강타, 그 외에는 휘감는 뿌리다. 마우스오버한 몹이 있으면 그 몹에 쓴다. Alt를 누른 채 누르면 변신을 풀고 겨울잠(18)을 건다. 묶기·재우기를 한 키에 모았다.

```
#showtooltip
/cancelform [mod:alt]
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 겨울잠; [stance:1,@mouseover,harm,nodead][stance:1] 강타; [nostance,@mouseover,harm,nodead][nostance] 휘감는 뿌리
```

### 7. 도망치기 (키 Shift+E)

표범이 아니면 표범으로, 표범이면 질주. 두 번 누르면 된다.

```
#showtooltip
/cast [nostance:3] 표범 변신; 질주
```

### 8. 버프 한 번에 (전투 밖)

Shift를 누르면 가시, 그냥 누르면 야생의 징표를 나에게 건다.

```
#showtooltip
/cast [mod:shift,@player] 가시; [@player] 야생의 징표
```

- 여러 주문을 한 번에 나가게 하는 매크로는 안 된다(전역 재사용 대기). 위 매크로들은 "상황에 따라 하나를 고르는" 방식이다.
- /startattack 조건에 nostealth를 넣어서 숨기 작 매크로를 눌러도 자동 공격으로 은신이 깨지지 않는다.
- 스카이본도 변신 모습만 다르고 주문 이름과 태세 번호는 같다.
- 주문 이름은 Wowhead 한글판(클래식)으로 대조했다. 매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다.

## 단축키 설정

드루이드는 곰이나 표범으로 변신하면 기본 단축바(1\~=)가 폼 전용 바로 자동으로 바뀐다. 그래서 폼마다 같은 키에 같은 역할의 기술을 두면, 변신해도 손가락을 옮길 필요가 없다. WASD로 움직이는 것을 기준으로 한 배치다.

### 폼별 키 배치

| 키 | 역할 | 캐스터 | 곰 | 표범 |
| --- | --- | --- | --- | --- |
| 1 | 주력 공격 | 만능 공격(천벌) | 만능 공격(후려치기) | 만능 공격(할퀴기·칼날 발톱) |
| 2 | 보조 공격 | 달빛 섬광 | 휘둘러치기 | 도려내기 |
| 3 | 약화·출혈 | 요정의 불꽃 | 위협의 포효 | 갈퀴 발톱(24) |
| 4 | 차단·묶기 | 휘감는 뿌리 | 강타 | - |
| Alt+4 | 재우기 | 겨울잠(18) | 변신 풀고 겨울잠 | 변신 풀고 겨울잠 |
| 5 | 재사용 대기 기술 | 자연의 손아귀 | 분노 | 맹공격(24) |
| Ctrl+1 | 힐 | 재생 | 변신 풀고 재생 | 변신 풀고 재생 |
| Ctrl+2 | 힐 | 회복 | 변신 풀고 회복 | 변신 풀고 회복 |
| Ctrl+3 | 해제 | 해독(14, 26부터 독 해제) | 변신 풀고 해독 | 변신 풀고 해독 |
| Ctrl+4 | 해제 | 저주 해제(24) | 변신 풀고 저주 해제 | 변신 풀고 저주 해제 |
| Q | 위협 조절 | - | 포효 | 웅크리기(28) |
| E | 돌진·이동 | - | 야성의 돌진 | 질주(26) |
| R | 곰 변신 | 곰 변신 | (안 풀림) | 곰 변신 |
| F | 표범·숨기 | 표범 변신 | 표범 변신 | 숨기 |
| G | 치유의 손길 | 치유의 손길 | - | - |
| Shift+E | 도망치기 | 표범 변신 | 표범 변신 | 질주 |
| Shift+F | 치타 변신(30) | 치타 변신 | 치타 변신 | 치타 변신 |
| Z | 버프 | 야생의 징표(Shift 가시) | - | - |
| 종족 | 종족 기술 | 나이트 엘프: 엘룬의 빛, 그림자 숨기 / 스카이본: 지맥 읽기, 공중 걷기 |  |  |

T는 비웠다(힐을 Ctrl+1\~4로 옮김). 던전 가이드에서는 T에 환생을 둔다. 수정키 규칙은 손에 맞춘 것이다. Ctrl+1\~4(손바닥)에는 힐·해제, Alt+숫자에는 같은 키의 변형, Shift는 알파벳에만 쓰고 Shift+숫자는 쓰지 않는다.

만능 공격·보조 공격처럼 폼을 알아서 고르는 매크로는 캐스터·곰·표범 바의 같은 칸에 모두 넣는다. 그러면 1번 키는 언제나 "지금 폼의 주력 공격"이 된다.

### 설정 방법

1. ESC → 단축키 설정에서 Q·E에 배정된 기본 키(옆걸음)를 지우고 단축바 키로 바꾼다. 옆걸음은 A·D + 마우스 오른쪽 버튼으로 대신한다.
2. ESC → 설정 → 액션바에서 추가 단축바를 1\~2개 켜고, 버프·이동 기술처럼 폼과 상관없는 것을 거기에 둔다(추가 바는 변신해도 바뀌지 않는다).
3. 각 폼으로 변신한 상태에서 주문서의 기술과 매크로를 위 표대로 끌어다 놓는다. 폼마다 한 번씩 해야 한다.
4. 자동 자기 시전을 켜면 대상이 없을 때 힐이 나에게 간다.
5. 마우스 옆 버튼이 있으면 도망치기·치타 변신처럼 급할 때 쓰는 키를 옮겨두면 편하다.

추가로, 추가 단축바 하나를 기본 바 바로 위로 옮기고 버튼 1\~4에 Ctrl+1\~4를 지정한 뒤, 힐·해제 매크로 4개를 기본 바 1\~4번과 세로로 줄을 맞춰 놓는다. WoW는 기본으로 Ctrl+1\~0을 소환수 바에 쓰지만 드루이드는 소환수가 없어서 덮어써도 된다.

- Forever는 현대 클라이언트라 표범 숨기 상태에서도 단축바가 한 번 더 바뀔 수 있다. 숨기를 켰을 때 1번 칸이 비어 있으면 그 상태에서도 만능 공격 매크로를 넣는다. 이 부분은 게임에서 확인이 필요하다.
- 치타 변신은 30레벨에 배운다. 그 전에는 Shift+F를 비워둔다.
