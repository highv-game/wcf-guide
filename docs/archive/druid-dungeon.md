# 야성 드루이드 던전 가이드 (포에버)

> 최종 수정: 2026-10-01

## 던전 전투 방식

솔플과 가장 큰 차이는 "내가 몹을 잡는 것"보다 "몹이 누구를 때리게 할지"가 중요하다는 점이다. 지금 레벨대(20\~30)에서 야성 드루이드가 파티에 가장 쉽게 들어가는 역할은 곰 탱커다. 표범 딜러는 20레벨에 할퀴기와 도려내기뿐이라 22레벨 칼날 발톱, 24레벨 갈퀴 발톱부터 제 몫을 한다. 기술 이름과 레벨은 [솔플 가이드](druid-solo-macros.md)의 표와 같다.

### 역할별 정리

| 항목 | 곰 탱커 | 표범 딜러 |
| --- | --- | --- |
| 가능 레벨 | 10부터 | 20(표범 퀘스트)부터 |
| 목표 | 모든 몹이 나만 때리게 한다 | 탱커보다 위협을 낮게 유지하며 딜 |
| 핵심 기술 | 위협의 포효, 휘둘러치기, 후려치기, 포효, 강타 | 할퀴기, 칼날 발톱, 갈퀴 발톱, 도려내기, 웅크리기 |
| 무기 | 무기 DPS가 위협과 피해를 같이 올린다 | 무기 DPS가 가장 중요 |
| 특성 | 야생의 본능, 야성의 돌진 | 야수의 습격, 살쾡이의 기민함 |

### 곰 탱커: 풀링에서 마무리까지

1. **표시부터.** 해골(먼저 잡을 몹)과 X(두 번째)를 찍어 둔다. 파티가 같은 몹을 때리면 위협 관리가 훨씬 쉽다.
2. **풀링.** 캐스터 상태에서 천벌로 당기고, 몹이 오는 동안 곰으로 변신한다. 주문을 쓰는 몹이 섞여 있으면 천벌을 쏘고 모퉁이 뒤로 숨어 몹들이 한곳으로 오게 한다.
3. **첫 3초.** 위협의 포효를 먼저 건다. 범위 안의 모든 몹에 위협이 조금씩 쌓여 힐러에게 가는 몹이 줄어든다.
4. **여러 마리.** 분노가 차는 대로 휘둘러치기를 누른다. 해골 몹은 Tab으로 바꾸지 말고 계속 후려치기로 때린다.
5. **한 마리.** 후려치기를 분노가 15 이상일 때마다 누른다. 위협의 포효는 꺼질 때만 다시 건다.
6. **몹이 떨어져 나감.** 힐러나 딜러에게 간 몹에 포효(도발)를 쓴다. 28레벨부터 위급하면 도전의 포효로 주변 몹을 모두 6초 동안 끌어온다(재사용 10분).
7. **시전 몹.** 강타로 주문을 끊는다. 야성의 돌진도 시전을 끊는다.

- 분노는 전투 전에 켜 두면 첫 위협이 빨라진다. 대신 방어도가 내려가므로 큰 무리를 당길 때는 아껴 둔다.
- 광포한 재생력은 36레벨이라 이 구간 곰에게는 자기 회복 기술이 없다. 체력이 낮으면 변신을 풀지 말고 힐러에게 맡긴다. 탱커가 변신을 풀면 몹이 바로 흩어진다.
- 분노가 모자라면 후려치기만 계속 누르지 말고 평타로 분노를 모은다. 후려치기는 다음 평타를 바꾸는 기술이라 연타해도 한 번만 나간다.

### 표범 딜러: 위협 넘지 않기

1. 탱커가 위협의 포효와 공격 2\~3번을 넣을 때까지 기다린 뒤 들어간다.
2. 몹 뒤에서 칼날 발톱(22부터), 정면이면 할퀴기. 갈퀴 발톱은 오래 사는 정예 몹에만 건다.
3. 연계 점수 4\~5개에서 몹이 오래 버틸 것 같으면 도려내기, 금방 죽으면 할퀴기를 계속 누른다.
4. 몹이 나를 보기 시작하면 28레벨부터 웅크리기로 위협을 줄인다. 그 전에는 공격을 잠깐 멈춘다.
5. Forever에는 야성 요정의 불꽃(변신 상태에서 쓰는 요정의 불꽃)이 없다(ForeverChanges). 요정의 불꽃이 필요하면 변신 전에 캐스터로 건다.

- 숨기는 파티에서 몹 무리를 피해 지나갈 때만 쓴다. 탱커보다 먼저 들어가 기습하지 않는다.
- 탱커가 죽으면 곰으로 바꿔 대신 버틴다. 드루이드 딜러의 가장 큰 장점이다.

### 보조 역할

드루이드는 파티에서 딜이나 탱 외에도 맡을 수 있는 일이 많다. 이걸 챙기면 같은 딜러라도 훨씬 환영받는다.

| 기술 | 레벨 | 쓰는 때 |
| --- | --- | --- |
| 환생 | 20 | 전투 중 쓰러진 힐러나 탱커를 바로 살린다. 재사용 대기 30분이라 힐러부터. |
| 되살리기 | 12 | Forever 신규 전투 밖 부활. |
| 해독 / 독 해제 | 14 / 26 | 통곡의 동굴·데드마인 독. |
| 저주 해제 | 24 | 그림자송곳니 성채 저주. |
| 겨울잠 | 18 | 야수·용족 하나를 20초 재운다. 피해를 받으면 깬다. |
| 동물 달래기 | 22 | 야수 몹의 인식 범위를 줄여 원하지 않는 몹이 끌려오지 않게 한다. |
| 재생·치유의 손길 | 1\~ | 힐러 마나가 바닥날 때 변신을 풀고 보조 힐. |

레벨은 ForeverChanges 주문서, 한글 이름은 Wowhead 한글판(클래식) 기준이다.

### 30레벨까지 던전별 메모

| 던전 | 레벨 | 드루이드가 챙길 것 |
| --- | --- | --- |
| 영주의 전당 (아이언포지 지하, 신규) | 13\~18 | 새 던전이라 공략이 적다. 곰 탱으로 휘둘러치기를 연습하기 좋은 레벨 |
| 로데론의 폐허 (티리스팔, 신규) | 15\~20 | 새 던전. 언데드 위주라면 겨울잠은 쓸 데가 없다 |
| 통곡의 동굴 | 17\~24 | 독 해제, 송곳니 군주들의 수면 주문 끊기(강타), 야수에게 겨울잠. 송곳니 세트 파밍 |
| 데드마인 | 클래식 17\~26 | 몹이 촘촘해 풀링 표시가 중요. 독 |
| 그림자송곳니 성채 | 클래식 22\~30 | 저주 해제(24) 필수, 늑대인간 무리에 휘둘러치기 |
| 검은심연 나락 | 24\~32 | 물속 구간에서 바다표범 변신. 나가로 몹 시전 끊기 |

데드마인과 그림자송곳니 성채의 레벨, 각 던전의 몹 특징은 클래식 기준이고 Forever에서 바뀌었을 수 있다. Forever에는 자동 파티 찾기가 없고 파티 찾기 목록만 있으며, 소환은 흑마법사만 할 수 있다.

## 매크로 구성

솔플 가이드의 만능 공격(1)·보조 공격(2)·폼 변신(R, F)·돌진(E)·차단(4, Alt+4 겨울잠)·힐과 해제(Ctrl+1\~4) 매크로는 던전에서도 그대로 쓴다. 힐·해제는 이미 마우스오버 방식이다. 여기서는 파티에서만 필요한 매크로를 더한다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같고, 태세 번호는 1 곰, 2 바다표범, 3 표범이다.

던전 매크로의 핵심은 **마우스오버**다. 대상(해골 몹)을 바꾸지 않고, 마우스만 올려서 다른 몹을 도발하거나 파티원을 해제·힐한다. 탱커가 Tab으로 대상을 바꾸지 않아도 되니 위협이 흔들리지 않는다.

### 1. 도발 · 위협 조절 (키 Q)

곰이면 마우스오버한 몹에 포효, Shift를 누르면 도전의 포효(28)다. 표범이면 웅크리기(28)로 위협을 줄인다.

```
#showtooltip
/cast [stance:1,mod:shift] 도전의 포효; [stance:1,@mouseover,harm,nodead][stance:1] 포효; [stance:3] 웅크리기
```

28레벨 전에는 `도전의 포효`와 `웅크리기` 부분이 비어 있어도 매크로는 동작한다.

### 2. 해골 표시 (키 Shift+X)

마우스오버한 몹, 없으면 대상에 해골을 찍는다. 같은 몹에 한 번 더 누르면 표시가 지워진다. Shift+C에 같은 매크로를 숫자만 7(X)로 바꿔 넣는다. 표시는 전투 중에 거의 안 누르니 Shift+알파벳에 둔다.

```
/tm [@mouseover,exists][] 8
```

### 3. 힐·해제 (Ctrl+1\~4)

솔플 가이드의 Ctrl+1\~4 매크로(재생, 회복, 해독, 저주 해제)를 그대로 쓴다. 파티 프레임에 마우스를 올리고 누르면 변신을 풀고 그 파티원에게 걸린다. 26레벨부터는 Ctrl+3의 해독을 독 해제로 바꾼다. 예전의 V(해제)와 T(보조 힐) 매크로는 이 네 개로 합쳤다.

### 4. 전투 부활 (키 T)

죽은 파티원 프레임에 마우스를 올리고 누른다. 변신을 풀고 환생(20)을 시전한다.

```
#showtooltip 환생
/cancelform
/cast [@mouseover,help,dead][] 환생
```

### 5. 마우스오버 겨울잠 (Alt+4)

두 번째 야수·용족 몹을 대상 변경 없이 재운다. 따로 칸을 쓰지 않고 4번 차단 매크로 안에 Alt 조건으로 넣었다. Alt를 누른 채 4를 누르면 변신을 풀고 겨울잠, 그냥 누르면 원래대로 강타·휘감는 뿌리다. 솔플 가이드의 4번 매크로와 같다.

```
#showtooltip
/cancelform [mod:alt]
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 겨울잠; [stance:1,@mouseover,harm,nodead][stance:1] 강타; [nostance,@mouseover,harm,nodead][nostance] 휘감는 뿌리
```

### 6. 탱커 따라 때리기 (표범 딜러용)

탱커 캐릭터를 대상으로 잡고 주시 대상 지정 매크로를 한 번 누른다. 그 뒤로는 따라 때리기 매크로가 탱커의 대상을 내 대상으로 가져온다.

주시 대상 지정(던전 입장 후 한 번):

```
/focus [@mouseover,help,exists][]
```

따라 때리기(키 \`):

```
/assist [@focus,exists]
/startattack [nostealth,harm]
```

- 여러 주문을 한 번에 시전하는 매크로는 여전히 안 된다. 위 매크로들은 상황에 맞는 기술 하나를 고르거나, 변신을 풀고 하나를 쓰는 방식이다.
- `/cancelform`은 전역 재사용 대기를 쓰지 않아서 한 줄 위에 넣어도 된다.
- 마우스오버는 파티 프레임이나 몹 이름표 위에서도 동작한다. ESC → 설정 → 인터페이스 → 이름표에서 적 이름표를 켜 두면 몹 위로 마우스를 옮기기 쉽다.
- 28레벨 전에 Shift+Q를 누르면 도전의 포효를 모른다는 오류만 뜨고 아무 일도 일어나지 않는다.

## 단축키 설정

솔플 배치를 그대로 두고, 빈 자리와 Shift 조합에 파티용 기술만 더한다. 솔플과 던전에서 같은 키가 같은 일을 해야 손이 헷갈리지 않는다. 표에서 **굵게** 표시한 것이 던전에서 새로 추가하거나 바꾸는 키다.

### 던전용 키 배치

| 키 | 역할 | 곰 탱커 | 표범 딜러 |
| --- | --- | --- | --- |
| 1 | 주력 공격 | 후려치기 | 할퀴기·칼날 발톱 |
| 2 | 보조 공격 | 휘둘러치기 | 도려내기 |
| 3 | 약화·출혈 | 위협의 포효 | 갈퀴 발톱(24) |
| 4 | 차단 | 강타 | - |
| **Alt+4** | 군중 제어 | **변신 풀고 겨울잠** | 같음 |
| 5 | 재사용 대기 기술 | 분노 | 맹공격(24) |
| **Ctrl+1 / Ctrl+2** | 보조 힐 | **마우스오버 재생 / 회복** | 같음 |
| **Ctrl+3 / Ctrl+4** | 해제 | **마우스오버 해독 / 저주 해제** | 같음 |
| Q | 위협 조절 | **마우스오버 포효** | 웅크리기(28) |
| **Shift+Q** | 긴급 도발 | **도전의 포효(28)** | - |
| E | 돌진 | 야성의 돌진 | 질주(26) |
| R / F | 변신 | 곰 / 표범 | 곰 / 숨기 |
| **T** | 전투 부활 | **환생** | 같음 |
| **Shift+X / Shift+C** | 표시 | **해골 / X** | - |
| **숫자 1 왼쪽 키** | 따라 때리기 | - | **탱커 대상 가져오기** |
| Z | 버프 | 야생의 징표(Shift 가시) | 같음 |

솔플에서 Shift+E(도망치기)와 G(치유의 손길)는 그대로 둔다. 던전에서 치유의 손길을 쓸 때는 대상을 파티원으로 잡고 누른다.

### 역할별 손 움직임

- **곰 탱커.** 왼손은 1·2·3을 돌리고, 마우스는 파티 프레임과 몹 이름표를 오간다. 힐러를 때리는 몹이 보이면 마우스를 올리고 Q. 대상은 해골에서 바꾸지 않는다.
- **표범 딜러.** \` 로 탱커 대상을 받아오고 1·2만 누른다. 위협 미터기가 빨간색에 가까워지면 Q(웅크리기)나 공격 멈춤. 탱커가 쓰러지면 R로 곰, 그 뒤로는 탱커와 같은 손 움직임이다.
- **위급 상황.** 힐러가 쓰러지면 프레임에 마우스를 올리고 T(환생). 탱커라면 환생을 쓰는 동안 몹이 흩어지므로, 먼저 Shift+Q(도전의 포효)로 몹을 모으고 살린다.

### 설정 방법

1. 솔플 가이드대로 Q·E의 옆걸음을 지웠다면 숫자 1 왼쪽 키도 같은 방법으로 비운다. Shift+숫자는 쓰지 않으니 WoW 기본 단축바 넘기기(Shift+1\~6)는 그대로 두어도 된다.
2. 여러 폼에서 같이 쓰는 매크로(환생, 해제, 표시, 따라 때리기)는 추가 단축바에 둔다. 추가 바는 변신해도 바뀌지 않아서 한 번만 놓으면 된다.
3. 힐·해제(Ctrl+1\~4)는 기본 바 바로 위 추가 단축바의 1\~4번 칸에 세로로 줄을 맞춰 둔다. 폼마다 바뀌는 기술(Q 등)은 솔플 가이드처럼 각 폼으로 변신한 뒤 기본 바에 놓는다.
