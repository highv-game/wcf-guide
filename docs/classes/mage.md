# 노움 냉기 마법사 1~30 공략 (포에버)

> 최종 수정: 2026-10-06

!!! abstract "한눈에 보기"
    - **플레이 방식**: 얼음 화살로 느리게 만들고, 얼려서, 얼음창으로 깨는 원거리 캐스터. 몹이 붙으면 얼음 회오리로 묶고 거리를 벌린다.
    - **역할**: 레벨업은 냉기 특성. 파티에서는 광역 딜, 변이(군중 제어), 물·음식, 저주 해제, 마법 차단을 맡는다.
    - **대상 레벨**: 베타 만렙인 1~30. 기술 레벨은 클래식 주문서 기준이고 Forever에서 달라진 것은 따로 적었다.
    - **왜 노움인가**: 최대 마나 +5%(영리함)로 쉬기 전에 더 잡고, 유레카(Eureka!)로 다음 주문 3개를 싸고 강하게 쓴다. 탈출의 명수는 얼음 회오리가 없는 순간의 탈출기다. 얼라이언스 마법사 종족 1순위로 꼽힌다.
    - **전환점**: 4(얼음 화살) · 10(얼음 회오리, 특성 시작) · 17~19(동상, 몹이 저절로 얼기 시작) · 20(점멸, 눈보라, 환기, 순간이동: 아이언포지) · 25(얼음창 특성) · 26(냉기 돌풍) · 28(마나 마노) · 30(얼음 갑옷).
    - **단축키 틀**: 흑마법사·사제 공략과 같다(1 주력, 4 마우스오버 군중 제어, Z 버프). 법사는 부활이 없어서 T에 얼음 방패를 둔다. Ctrl+1~4에는 마우스오버 지원 주문(저주 해제, 지능 버프, 저속 낙하)을 모았다. Shift+숫자는 쓰지 않는다.

!!! info "Forever 핵심 변경"
    - **얼음창 (Ice Lance)**: 냉기 트리 신규 특성. 즉시 시전 냉기 피해, 얼어 있는 대상에게는 피해 +300%. 얼린 몹을 깨는 마무리 기술이다.
    - **서리의 손가락 (Fingers of Frost)**: 신규 특성. 냉기 감속 효과가 걸릴 때 15% 확률로 다음 주문 1~2개가 대상이 얼어 있는 것처럼 계산된다. 얼음창·산산조각과 바로 이어진다.
    - **산산조각**: 얼어 있는 대상 치명타 확률 증가가 17/33/50%로 커졌다.
    - **혹한의 추위**: 대상 약화가 아니라 내 얼음 화살·얼음창 치명타 +2%씩 쌓이는 효과로 바뀌었다.
    - **원소 정밀**: 저항 감소 대신 화염·냉기 적중 +1%씩, 5랭크로 늘었다.
    - **얼음 보호막**: 보호막이 남아 있는 동안 주문 시전이 끊기지 않는다.
    - **눈보라 연마**: 감속이 최대 65%에서 40%로 줄었다. 클래식식 눈보라 광역 사냥은 더 어려워졌다.
    - **냉기불꽃 화살 (Frostfire Bolt)**: 모든 마법사의 신규 기본 주문. 배우는 레벨은 미확인.

## 특성

30레벨까지 21포인트를 전부 냉기에 넣는 **0/0/21** 빌드를 추천한다. 얼음 화살을 빠르게 만들고, 동상으로 몹을 얼린 뒤, 얼음창과 산산조각으로 얼린 몹을 치명타로 깨는 것이 목표다. 특성 포인트는 10레벨부터 레벨당 1개씩 받는다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10~14 | 얼음 화살 연마 5/5 | 얼음 화살 시전 시간 -0.1초씩(5/5면 -0.5초) |
| 15~16 | 원소 정밀 2/5 | 화염·냉기 주문 적중 +1%씩. Forever에서 효과가 바뀌었다 |
| 17~19 | 동상 3/3 | 냉기 감속 효과가 5/10/15% 확률로 대상을 5초 동안 얼린다 |
| 20~24 | 얼음 파편 5/5 | 냉기 주문 치명타 피해 +20%씩(5/5면 +100%) |
| 25 | 얼음창 1/1 (신규) | 즉시 시전. 얼어 있는 대상에게 피해 +300% |
| 26~28 | 산산조각 3/3 | 얼어 있는 대상 치명타 확률 +17/33/50% |
| 29 | 얼음 방패 1/1 | 10초 동안 모든 공격·주문 면역(그동안 나도 공격 못 함) |
| 30 | 서리의 손가락 1/2 (신규) | 냉기 감속 시 15% 확률로 다음 주문 1개가 "얼어 있는 대상"으로 계산 |

- 순서는 냉기 레벨업 빌드의 특성 순서를 레벨에 맞춰 놓은 것이다. 얼음창은 트리 아래쪽이라 25레벨 전에는 찍을 수 없다.
- 20레벨부터는 얼음 화살 연마보다 원소 정밀이 낫다는 의견도 있다. 동레벨 몹에게 자주 빗나가면 31레벨 이후 원소 정밀을 5/5까지 채운다.
- 레거시의 Talented 특전을 찍으면 9레벨부터 특성을 받아 최대 3~5점을 더 쓴다. 남는 점수는 Piercing Ice(냉기 피해 +2%씩), 매서운 한파, 혹한의 추위 순서로 넣는다.
- 나중에 찍을 특성: 서리의 손가락 2/2, 혹한의 추위 5/5, 냉기 돌풍 연마, 얼음 보호막. 냉기 트리는 전부 찍으면 53점이라 51점 안에 다 안 들어간다. 만렙에서는 Frost Warding 2점을 뺀다.

### 특성별 메모

| 특성 | 효과 (Forever) |
| --- | --- |
| Frost Warding | 서리·얼음 갑옷 방어도·저항 +15/30%, 냉기계 수호가 냉기 효과를 10/20% 반사 |
| Permafrost (영구 동결) | 냉기 감속 지속 시간 +11~33%, 이동 속도 추가 감소 |
| 얼음 회오리 연마 | 얼음 회오리 재사용 대기 -2/4초 |
| Piercing Ice | 냉기 주문 피해 +2/4/6% |
| Frost Channeling | 냉기 주문 마나 -5~15%, 위협 -10~30% |
| Arctic Reach | 냉기 주문 사거리·범위 +10/20% |
| 눈보라 연마 | 눈보라에 감속 15/28/40% 추가(클래식 65%에서 줄었다) |
| 냉기 돌풍 연마 | 냉기 돌풍 피해 +12/23/35% |
| 매서운 한파 | 다른 냉기 주문 재사용 대기를 모두 끝낸다 |
| 혹한의 추위 | 얼음 화살·얼음창 치명타 +2%씩 쌓이는 효과(최대 5중첩) |
| 얼음 보호막 | 즉시 보호막(448 흡수). 보호막이 있는 동안 시전이 끊기지 않는다 |

!!! info "특성 이름"
    한글 이름은 클래식 한글 클라이언트 기준이다. 얼음창·서리의 손가락·냉기불꽃 화살은 리치왕의 분노 한글판 이름을 따랐다(Forever 한글판 미확인). 영문으로 적은 특성은 한글 이름 미확인이다.

## 단축키와 매크로

솔플·던전 모두 이 배치를 그대로 쓴다. 마법사는 변신 바가 없어서 한 번 놓으면 끝이다. 수정키 규칙은 다른 직업 공략과 같다.

- **Ctrl + 1~4** (손바닥 새끼 쪽으로 누름): 파티원에게 쓰는 마우스오버 지원 주문. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다.
- **Alt + 숫자**: 같은 키의 변형(화염구, 화염 작렬, 신비한 화살, 마법 차단, 유레카). 매크로 안에 `[mod:alt]`로 넣어 칸을 따로 쓰지 않는다.
- **Shift + 알파벳** (새끼손가락): 전투 밖 주문(물·음식 창조, 버프)과 변형, 표시.
- **Shift + 숫자는 쓰지 않는다.** WoW 기본 단축바 넘기기(Shift+1~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

| 키 | 역할 | 기본 | 수정키 |
| --- | --- | --- | --- |
| 1 | 주력 공격 | 얼음 화살(4) | Alt: 화염구 / Ctrl: 마우스오버 하급 저주 해제(18) |
| 2 | 깨기·이동 중 | 얼음창(25 특성), 그 전에는 화염 작렬 | Alt: 화염 작렬(6) / Ctrl: 마우스오버 신비한 지능 |
| 3 | 마무리·마나 절약 | 마법봉 발사 | Alt: 신비한 화살(8) / Ctrl: 마우스오버 마법 감쇠(12) |
| 4 | 군중 제어 | 마우스오버 변이(8) | Alt: 마우스오버 마법 차단(24) / Ctrl: 마우스오버 저속 낙하(12) |
| 5 | 종족 | 탈출의 명수(노움) | Alt: 유레카(Eureka!) |
| Q | 묶기 | 얼음 회오리(10) | Shift: 물 창조 |
| E | 이동 | 점멸(20) | Shift: 음식 창조 |
| R | 광역 | 눈보라(20) | Shift: 불기둥(16) |
| F | 근접 광역 | 냉기 돌풍(26), 그 전에는 신비한 폭발(14) | Shift: 신비한 폭발 |
| G | 마나 | 마나 마노 사용(28) | Shift: 환기(20) |
| Z | 버프 | 서리 갑옷 / 얼음 갑옷(30) | Shift: 냉기계 수호(22) |
| T | 긴급 생존 | 얼음 방패(29 특성) | Shift: 마나 마노 창조(28) |
| X / C / V | 표시 | - | Shift: 해골 / X / 달 |

괄호 숫자는 배우는 레벨이다. 아직 안 배운 칸은 비워 두면 된다.

### 1. 주력 공격 (키 1)

얼음 화살을 쏜다. Alt를 누른 채 누르면 화염구다. 냉기 면역 몹(물 정령 등)이나 이미 감속이 필요 없는 몹에 쓴다. 냉기불꽃 화살을 배우면 Alt 쪽을 그것으로 바꿔도 된다.

```
#showtooltip
/cast [mod:alt] 화염구; 얼음 화살
```

### 2. 얼음창과 화염 작렬 (키 2)

둘 다 즉시 시전이라 이동 중에 쓴다. 몹이 얼어 있거나(동상·얼음 회오리) 서리의 손가락이 켜졌을 때 얼음창을 누른다. 25레벨 전에는 기본 칸에도 화염 작렬을 둔다.

```
#showtooltip
/cast [mod:alt] 화염 작렬; 얼음창
```

### 3. 마법봉과 신비한 화살 (키 3)

그냥 누르면 마법봉 자동 사격을 켠다. 느낌표(!) 덕분에 연타해도 꺼지지 않는다. 몹 체력이 조금 남았을 때 마나를 아끼는 마무리용이다.

```
#showtooltip
/cast [mod:alt] 신비한 화살; !마법봉 발사
```

### 4. 마우스오버 변이·마법 차단 (키 4)

대상을 바꾸지 않고 마우스를 올린 몹에 변이를 건다. Alt를 누른 채 누르면 마우스오버한 몹(없으면 내 대상)의 시전을 마법 차단으로 끊는다.

```
#showtooltip
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 마법 차단; [@mouseover,harm,nodead][] 변이
```

### 5. 마우스오버 지원 주문 (Ctrl+1~4)

마우스를 올린 파티원에게 쓰고, 마우스오버가 없으면 내 대상, 그것도 아니면 나에게 쓴다.

!!! tip "배치"
    기본 단축바 바로 위 추가 단축바의 1~4번 칸에 둔다. 1번 위에 Ctrl+1처럼 세로 줄을 맞추면 "같은 숫자의 한 칸 위 = Ctrl"로 눈에 바로 들어온다.

**Ctrl+1 하급 저주 해제**

```
#showtooltip
/cast [@mouseover,help,nodead][help,nodead][@player] 하급 저주 해제
```

**Ctrl+2 신비한 지능**, **Ctrl+3 마법 감쇠**, **Ctrl+4 저속 낙하**: 위와 같은 매크로에서 주문 이름만 바꾼다. 마법 감쇠는 받는 치유도 줄이니 캐스터 몹과 싸울 때만 쓴다.

### 6. 탈출의 명수와 유레카 (키 5)

```
#showtooltip
/cast [mod:alt] 유레카; 탈출의 명수
```

### 7. 마나 마노와 환기 (키 G)

마나 마노는 전투 중 시전 없이 마나를 채운다. 가방의 보석 이름이 다르면 매크로 창을 연 채 가방에서 Shift+클릭으로 넣는다.

```
#showtooltip
/cast [mod:shift] 환기
/use [nomod] 마나 마노
```

### 8. 물·음식 창조 (Shift+Q, Shift+E)

전투 밖에서만 쓰는 주문이라 Shift+알파벳에 둔다. 주문서에서 가장 높은 랭크를 끌어다 놓으면 된다. 트레이너에서 새 랭크를 배우면 칸을 다시 끌어다 놓는다.

### 설정 순서

1. ESC → 단축키 설정에서 Shift+1~6(단축바 넘기기)을 지우고, Q·E의 옆걸음을 단축바 키로 바꾼다.
2. ESC → 설정 → 액션바에서 추가 단축바를 하나 켜고 기본 바 바로 위로 옮긴다. 그 바의 버튼 1~4에 Ctrl+1~4를 지정한다.
3. WoW 기본 Ctrl+1~0은 소환수 바용이다. 마법사는 소환수가 없어서 그대로 덮어쓴다.
4. Shift+X·C·V는 같은 추가 바의 다른 칸에 둔다. Alt+숫자는 매크로 안에 들어 있어서 따로 지정하지 않는다.
5. 매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

## 솔플

솔플의 핵심은 **"맞기 전에 잡고, 붙으면 얼리고 물러선다"**이다. 얼음 화살의 감속 덕분에 몹이 내게 오기까지 화살을 2~3번 더 쏠 수 있고, 붙으면 얼음 회오리로 묶은 뒤 거리를 벌려 다시 쏜다. 마나와 체력은 직접 만든 물·음식으로 채우니 돈이 거의 들지 않는다.

### 사냥 전 준비

- 서리 갑옷(30부터 얼음 갑옷)과 신비한 지능을 유지한다.
- 물과 음식을 20개씩 만들어 둔다. 레벨마다 트레이너에서 새 랭크를 배운다.
- 28레벨부터 마나 마노를 하나 만들어 둔다(Shift+T).

### 한 마리 잡는 순서

1. **시작**: 최대 사거리에서 얼음 화살(1). 몹이 다가오는 동안 한두 번 더 쏜다.
2. **얼었을 때**: 동상이 터지거나 서리의 손가락이 켜지면 바로 얼음창(2). 산산조각 3/3 이후에는 얼음창이 거의 치명타로 들어간다.
3. **붙었을 때**: 얼음 회오리(Q) → 몇 걸음 뒤로 → 얼음창 1~2번 → 얼음 화살로 이어간다. 회오리가 재사용 대기면 탈출의 명수는 내가 묶였을 때만 쓰고, 점멸(E)로 거리를 벌린다.
4. **마무리**: 체력이 조금 남은 몹은 마법봉(3) 또는 화염 작렬(Alt+2). 마나를 아낀다.
5. **전투 후**: 마나가 40% 아래면 앉아서 물을 마신다. 정신력이 높을수록 덜 앉는다.

!!! tip "얼음 회오리 뒤 대기"
    얼음 회오리로 언 몹은 피해를 받으면 일찍 풀릴 수 있다. 얼음 화살을 끝까지 쏘는 사이 풀려서 다시 붙는 경우가 많으니, 얼린 뒤에는 거리를 먼저 벌리고 즉시 시전인 얼음창으로 친다.

### 광역 사냥

눈보라 연마 감속이 40%로 줄어 클래식처럼 몹 열 마리를 끌고 다니며 눈보라만 쓰는 사냥은 어렵다. 30레벨 구간에서는 몹 3~5마리를 모아 얼음 회오리 → 냉기 돌풍 → 점멸 → 눈보라 한두 번으로 끝내는 짧은 광역이 현실적이다. 체력이 낮은 몹부터 신비한 폭발로 마무리한다.

## 던전

던전에서 마법사의 가치는 광역 딜, 변이, 물·음식에서 나온다. Forever에는 자동 파티 찾기가 없어서 파티 찾기 목록으로 구한다.

!!! tip "파티 구하기"
    파티 찾기 목록에 "법사, 변이·물 제공"을 적으면 파티가 잘 구해진다.

### 입장 전 준비

- 물을 파티 인원만큼 넉넉히 만든다. 파티원은 거래창으로 주거나 "물 필요하면 거래 걸어주세요"라고 파티 채팅에 적는다.
- 파티원 전원에게 신비한 지능(Ctrl+2, 캐스터 위주)을 건다.
- 탱커가 표시를 안 하면 변이 대상은 달(5)로 정해둔다.

### 전투 순서

1. **변이**: 풀링 전에 달 표시 몹에 변이(4, 마우스오버). 인간형·야수만 걸린다.
2. **진입**: 탱커가 몹을 잡고 2~3초 뒤에 시작한다. 탱커 대상 가져오기는 아래 따라 때리기 키를 쓴다.
3. **딜**: 해골 몹에 얼음 화살, 얼었을 때 얼음창. 몹이 많고 탱커가 모두 잡았으면 눈보라(R).
4. **차단**: 치유·공포를 시전하는 캐스터 몹은 마법 차단(Alt+4).
5. **해제**: 파티원에게 걸린 저주는 하급 저주 해제(Ctrl+1).
6. **위협**: 몹이 나에게 오면 딜을 멈추고 얼음 회오리로 묶은 뒤 탱커 쪽으로 간다. 얼음 방패를 쓰면 위협이 사라지는 것은 아니니, 끝나기 전에 탱커가 다시 잡게 한다.

### 던전 매크로

**따라 때리기** (숫자 1 왼쪽 키): 던전 입장 후 탱커를 대상으로 잡고 채팅창에 `/focus`를 한 번 입력한다. 그 뒤로는 이 키를 누르면 탱커의 대상을 내 대상으로 가져온다.

```
/assist [@focus,exists]
```

**변이 대상 다시 걸기**: 변이 대상을 `/focus`로 잡아 둔 경우, 아래 매크로로 대상을 바꾸지 않고 다시 건다.

```
#showtooltip
/cast [@focus,harm,nodead] 변이
```

**표시** (Shift+X / Shift+C): 탱커가 표시를 안 하면 대신 해골(8)과 X(7)를 찍는다. Shift+C에는 숫자만 7로, Shift+V(변이 대상, 달)에는 5로 바꾼 같은 매크로를 넣는다.

```
/tm [@mouseover,exists][] 8
```

### 육성 팁

- 물·음식을 사지 않는다. 남는 물은 파티원에게 주면 파티가 잘 구해진다.
- 순간이동: 아이언포지(20)를 배우면 귀환석을 다른 곳(레이크샤이어, 다크샤이어 등)에 맞춰둘 수 있다. 순간이동은 룬(Rune of Teleportation)이 필요하니 몇 개 사 둔다.
- 트레이너에게 자주 간다. 짝수 레벨마다 새 랭크가 나오고, 물·음식 랭크가 오르면 회복량이 크게 늘어난다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 던전은 퀘스트를 다 받은 상태로 한 번 도는 게 핵심이다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

## 장비

- **스탯 우선순위(레벨업)**: 지능 > 정신력 > 체력. 지능은 마나와 주문 치명타, 정신력은 전투 밖 회복이다. 주문력·치명타가 붙은 장비를 만나면 지능보다 먼저 본다. 냉기는 얼음 파편·산산조각 때문에 치명타 가치가 높다.
- **던전 위주가 되면**: 적중 > 주문력 > 치명타 > 정신력 > 지능 > 체력.
- **무기**: 지팡이가 기본. 노움 마법사는 지팡이·단검·한손 도검을 들 수 있다.
- **방어구**: 천. Forever는 전문기술 제작 장비 상당수가 획득 시 귀속이라 재봉술 장비는 경매장에서 살 수 없다.

| 힘·민첩 무기 | 차비 |
| 기계공학 설계도 | 바로 배울 수 있으면 시작 전에 말하고 입찰, 아니면 차비 |
- 포에버 재봉술 장비 상당수는 획득 시 귀속이라 남이 만든 걸 살 수 없다. 던전 천 장비를 놓치지 말고 입찰한다.
- 광석은 채광으로 각자 캔다. 던전에서 고급 보석이 나오면 차비다.

!!! info "포에버 주사위 규칙"
    - 그룹 획득에서 고급(초록) 이상이 나오면 주사위 창이 뜬다. 입찰한 사람이 한 명이라도 있으면 차비한 사람은 가져갈 수 없다.
    - 입찰은 **지금 이 특성으로 바로 입는 업그레이드**일 때만 누른다. 부캐용·판매용·마력 추출용은 차비, 필요 없으면 포기.
    - 던전에서 나온 고급·희귀 획득 시 귀속 장비의 외형은 주울 자격이 있던 파티원 모두에게 등록된다. 외형 때문에 입찰하지 않는다.
    - 적중·치명타는 근접·주문 구분 없이 한 스탯이다. 적중·치명타만 보고 판단하지 말고 주 능력치(힘·민첩·지능)로 누구 템인지 정한다.
    - 착용 시 귀속 파란색·보라색은 전원 차비가 기본이다. 바로 입을 업그레이드면 굴리기 전에 채팅으로 물어본다.
    - 툴팁에서 Shift를 누르면 지금 장비와 나란히 비교된다. 이름 아래 줄의 "획득 시 귀속"/"착용 시 귀속"으로 귀속 방식을 본다.

## 전문기술

기본안은 **기계공학 + 채광**이다. 재봉술 + 마법부여는 이미 흑마법사 캐릭터가 맡고 있고, 노움은 기계공학 전문화 레이셜이 있어 장치가 덜 실패한다. 30레벨 장신구 두 개(Minor Recombobulator, Mechanical Dragonling)를 직접 만든다.

| 전문기술 | 이 캐릭터에서의 쓰임 |
| --- | --- |
| 기계공학 | 장신구 2종, 조잡한 다이너마이트 계열 폭탄(광역 피해·기절), 수리 로봇·사냥용 장치 |
| 채광 | 기계공학 재료(구리·주석·청동) 자급. 남는 광석은 드워프 주술사·전사 장비용으로 판다 |

### 올리는 순서

1. **채광 1~65**: 던 모로·모단 호수에서 구리 광석을 캐며 레벨업과 같이 올린다.
2. **기계공학 1~75**: 거친 폭약·구리 볼트로 시작해 조잡한 다이너마이트를 대량으로 만든다. 파티 광역에서도 쓴다.
3. **채광 65~125**: 주석·은 광석. 붉은마루 산맥·그늘숲 동선과 맞는다.
4. **기계공학 75~150**: 청동 부품으로 장신구를 만든다. 30레벨 전후로 Minor Recombobulator와 Mechanical Dragonling을 노린다.

!!! tip "흑마법사를 안 키운다면"
    이 마법사가 유일한 천 캐릭터라면 **재봉술 + 마법부여**로 바꾼다. 재봉술 Forever 신규 희귀(Shining Circlet, Novice Arcanist's Sash)를 직접 입고, 마법부여로 마법봉·Lesser Wizard Oil(주문력 오일)을 만든다. 마력 추출 구조는 [흑마법사 공략의 전문기술 섹션](warlock.md#전문기술)과 같다.

### 보조 전문기술

- 요리·응급치료·낚시는 다른 캐릭터와 똑같이 올린다. 마법사는 물·음식을 직접 만들어서 요리는 "음식 버프(Well Fed)"용으로만 올리면 된다.
- 전문기술 150·225·300 달성은 레거시 포인트를 준다. 레거시의 Talented 특전이 특성 섹션의 추가 특성 포인트다.

## 종족 특성

Forever 노움은 레이셜이 아래 네 가지로 바뀌었다. 마나가 늘고 필요할 때 주문 3개를 싸고 강하게 쓰는 구성이라 마법사와 잘 맞는다.

| 특성 | 효과 (Forever) | 마법사 활용 |
| --- | --- | --- |
| 영리함 (Expansive Mind) | 최대 마나 +5%. 클래식에서는 지능 +5%였다 | 물 마시기 전에 몹을 더 잡는다 |
| 유레카 (Eureka!, 신규) | 다음 주문·기술 3개의 비용 감소, 피해 +10% | Alt+5. 정예나 보스 시작, 광역(얼음 회오리 → 냉기 돌풍 → 눈보라) 직전에 켠다 |
| 탈출의 명수 (Escape Artist) | 묶기·감속 해제. 짧은 시간 면역, 재사용 2분 | 키 5. 얼음 회오리·점멸 둘 다 재사용 대기일 때 남은 탈출기 |
| 기계공학 전문화 | 기계공학 장치가 덜 실패한다 | 이 캐릭터는 기계공학을 하니 바로 쓸모 있다 |

- 인간과 비교: 인간은 정신력 +5%와 기절 해제를 갖는다. 마나 총량·순간 폭딜·탈출은 노움, 레벨업 중 회복과 PvP 기절 대응은 인간이 조금 낫다.

!!! warning "게임에서 확인 필요"
    유레카의 정확한 감소량·재사용 대기와 탈출의 명수 수치는 게임 툴팁으로 확인한다.

## 게임에서 확인할 것

주문 이름은 한글 클래식 클라이언트 기준이다. 매크로가 안 먹으면 주문서나 가방에서 Shift+클릭으로 이름을 넣는다.

- [ ] 신규 주문 한글 이름: 얼음창(Ice Lance), 서리의 손가락(Fingers of Frost), 냉기불꽃 화살(Frostfire Bolt). 다르면 키 1·2 매크로 이름을 고친다.
- [ ] 냉기불꽃 화살을 몇 레벨에 배우는지, 얼음 화살보다 나은지.
- [ ] 얼음창이 특성으로만 배우는지(25레벨 전에 트레이너 목록에 있는지).
- [ ] 특성 단 조건: 동상·얼음창·산산조각·얼음 방패·서리의 손가락의 단 위치와 앞 단 필요 점수. 위 레벨 순서대로 찍히는지.
- [ ] 물·음식 창조, 마나 마노 창조, 순간이동: 아이언포지의 레벨(현재 클래식 기준).
- [ ] 눈보라 연마 40% 감속으로 3~5마리 광역 사냥이 되는지.
- [ ] 장비: Shining Circlet·Novice Arcanist's Sash 재봉술 스킬 요구치, Minor Recombobulator·Mechanical Dragonling 기계공학 스킬 요구치.
- [ ] 던전: 기존 던전의 레벨과 몹 특징(현재 클래식 기준).
- [ ] 주사위 창 버튼 이름(입찰·차비·포기)과 던전 장비 외형이 파티원 모두에게 등록되는지
