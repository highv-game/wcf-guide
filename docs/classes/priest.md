# 노움 암흑 사제 1\~30 가이드 (WoW 포에버)

> 최종 수정: 2026-10-04

## 한눈에 보기

노움 암흑 사제는 "어둠의 권능: 고통을 걸고, 보호막을 쓰고, 마법봉으로 마무리하는" 자급자족형 캐스터다. 레벨업은 암흑 특성, 파티에서는 딜과 흡혈의 선물(파티 치유), 해제, 버프를 맡는다.

**대상 레벨**: 베타 현재 만렙인 1\~30. 기술 레벨은 ForeverChanges 주문서 기준이다.

**종족을 노움으로 고른 이유**: Forever에서 새로 생긴 조합이다. 최대 마나 +5%(영리함)와 다음 주문 3개를 싸고 강하게 만드는 유레카(Eureka!)가 암사와 잘 맞고, Mobalytics 암사 가이드가 얼라이언스 1순위로 꼽는다. 노움 전용 사제 주문은 Confounding Flash(10)와 Contingency Plan(20)이다.

**전환점**: 10레벨(정신 분열, 노움 Confounding Flash, 특성 시작), 14레벨(영혼의 절규), 20레벨(파멸의 역병, 공포의 수호물, 순간 치유, Contingency Plan, 정신의 채찍 특성 위치), 24레벨(마나 연소), 30레벨(천상의 정신, 정신 지배, 흡혈의 선물 특성).

**Forever 핵심 변경**

- 어둠의 형상: 암흑 피해 +10%(클래식 15%), 암흑 주문 마나 -50%, 암흑 주문 치명타 피해 +100%. 레이드 마나 문제를 고치는 방향이다. 7단 특성이라 30레벨에는 닿지 않는다.
- 파멸의 역병과 공포의 수호물이 모든 사제 기본 주문이 됐다(20레벨). 파멸의 역병 재사용 대기는 3분에서 1분으로 줄었다.
- 정신력 누출은 "몹을 잡으면 20% 확률"로 바뀌었고, 흡혈의 선물이 걸린 몹이 죽어도 터진다.
- 어둠의 매듭은 대상 약화가 아니라 내 암흑 피해 +2% 버프(5중첩)로 바뀌었다.
- 마법봉류 전문화는 2랭크로 줄고 2랭크에 마법봉 피해 +25%다.
- 신규 주문 어둠의 권능: 죽음은 32레벨이라 30레벨 구간에는 없다.

단축키 배치는 기존 주술사·드루이드·흑마법사 가이드와 같은 틀(1 주력, 4 마우스오버 군중 제어, Q·E 보조 공격, Z 버프, T 부활 계열)이다. 사제는 힐이 있으니 Ctrl+1\~4에는 마우스오버 치유·보호막·해제를 모았다. Shift+숫자는 쓰지 않는다.

## 특성 빌드 (1\~30레벨)

30레벨까지 21포인트를 수양 2 + 암흑 19로 나누는 2/0/19 빌드를 추천한다(Mobalytics). 먼저 마법봉을 강하게 만들고, 정신력 누출로 쉬는 시간을 줄인 뒤, 정신의 채찍과 흡혈의 선물까지 간다. 특성 포인트는 10레벨부터 레벨당 1개씩 받고, 5포인트마다 다음 단이 열린다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10\~11 | 마법봉류 전문화 2/2 (수양 1단) | 마법봉 피해 +25%. Forever에서 5랭크→10% 대신 2랭크로 줄고 강해졌다 |
| 12\~16 | 정신력 누출 5/5 (암흑 1단) | 몹을 잡으면 20% 확률로 15초 동안 정신력 +100%, 시전 중에도 마나 회복 |
| 17\~18 | 어둠의 권능: 고통 연마 2/2 (2단) | 고통 지속시간 +3초(랭크당) |
| 19\~20 | Shadow Reach 2/2 (2단) | 암흑 공격 주문 사거리 +10%(랭크당). 36미터에서 몹을 끌어오기 좋다 |
| 21 | 암흑 마법 집중 1/5 (1단) | 암흑 주문 적중 +1%. Forever에서 위협 감소가 아니라 적중으로 바뀌었다. 3단을 열기 위한 10번째 점수 |
| 22 | 정신의 채찍 1/1 (3단) | 3초 동안 암흑 피해를 주는 채널링. 레벨업 주력기 |
| 23\~24 | Improved Mind Flay 2/2 (3단, 신규) | 정신의 채찍 피해 +10%, 사거리 +5미터, 대상 이동 속도 -35%. 근접 몹이 다가오기 전에 죽는다 |
| 25\~26 | 암흑 마법 집중 3/5 | 적중 +3% 합계. 암흑 15점으로 4단이 열린다 |
| 27 | 흡혈의 선물 1/1 (4단) | 내 암흑 피해의 20%만큼 파티 전체 치유. Forever에서 지속 30초로 줄었다. 이 디버프가 걸린 몹이 죽으면 정신력 누출이 반드시 터진다 |
| 28\~30 | 어둠의 매듭 3/3 (4단) | 암흑 주문이 33% 확률로 내 암흑 피해 +2%(15초, 5중첩) |

특성 목록은 Mobalytics 암사 가이드의 30레벨 빌드이고, 레벨 순서는 그 목록을 단 조건(5점당 1단)에 맞게 내가 배열했다. Mobalytics는 정신의 채찍을 21레벨로 적었는데, 마법봉류 전문화를 먼저 찍으면 계산상 22레벨이다.

레거시의 Talented 특전을 찍으면 9레벨부터 특성을 받아 최대 3점을 더 쓴다. 그러면 정신의 채찍이 앞당겨지고, 남는 점수는 암흑 마법 집중 5/5에 넣는다.

대안: 마법봉을 10레벨까지 못 구했으면 정신력 누출을 먼저 찍고 마법봉류 전문화를 21\~22로 미룬다. 이 경우 정신의 채찍은 20레벨에 찍힌다.

**나중에 찍을 특성**: 침묵(5단), Devouring Contagion(5단, 신규: 파멸의 역병 마나 -25%, 5미터 안 다른 적에게 전염), 어둠(6단, 암흑 피해 +2%씩), Early Demise(6단, 신규: 최대 20% 이하 대상에 어둠의 권능: 죽음 치명타 +15%), 어둠의 형상(7단).

**다른 특성을 고를 때**: 수양에는 신규 Twin Disciplines(즉시 주문 피해·치유 +1%씩)와 강화된 신의 권능: 보호막 연마(+7%씩), 내면의 집중력(다음 주문 마나 0, 치명타 +25%)가 있다. 30레벨에 열리는 회개(Penance)도 수양 특성이다. 힐러로 던전을 돌 생각이면 수양이 맞다.

영문으로 두었던 특성은 Forever 신규라 한글 이름을 확인하지 못한 것이다.

## 공통 단축키와 기본 매크로

솔플·던전 모두 이 배치를 그대로 쓴다. 수정키 규칙은 주술사·드루이드·흑마법사 가이드와 같다.

- **Ctrl + 1\~4** (손바닥 새끼 쪽으로 누름): 마우스오버 치유·보호막·해제. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다.
- **Alt + 숫자**: 같은 키의 변형. 매크로 안에 \[mod:alt\]로 넣어 칸을 따로 쓰지 않는다.
- **Shift + 알파벳** (새끼손가락): 가끔 쓰는 기술과 표시.
- Shift + 숫자는 쓰지 않는다. WoW 기본 단축바 넘기기(Shift+1\~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

| 키 | 역할 | 기본 | 수정키 |
| --- | --- | --- | --- |
| 1 | 선공·주력 | 정신 분열(10) | Alt: 성스러운 일격 / Ctrl: 마우스오버 순간 치유(20, 그전에는 하급 치유) |
| 2 | 마무리 | 마법봉 발사 | Alt: 파멸의 역병(20) / Ctrl: 마우스오버 신의 권능: 보호막 |
| 3 | 지속 피해 | 마우스오버 어둠의 권능: 고통(4) | Alt: 흡혈의 선물(27) / Ctrl: 마우스오버 소생(8) |
| 4 | 군중 제어 | 영혼의 절규(14) | Alt: 마우스오버 언데드 속박(20) / Ctrl: 마우스오버 마법 무효화(18) |
| 5 | 종족 | 탈출의 명수(노움) | Alt: 유레카(Eureka!) |
| Q | 채널링 | 정신의 채찍(22) | Shift: 신성한 불꽃(20) |
| E | 보호막 | 내게 신의 권능: 보호막(6) | Shift: 마나 연소(24) |
| R | 위협 | 소실(8) | Shift: 평정(20) |
| F | 노움 사제 주문 | Confounding Flash(10) | Shift: 마우스오버 Contingency Plan(20) |
| G | 해제·수호 | 마우스오버 질병 치료(14) | Shift: 마우스오버 공포의 수호물(20) |
| Z | 버프 | 내면의 열정(12) | Shift: 마우스오버 신의 권능: 인내 |
| T | 부활 | 마우스오버 부활(10) | Shift: 정신 지배(30) |
| X / C / V | 표시 | - | Shift: 해골 / X / 달 |

괄호 숫자는 배우는 레벨(ForeverChanges 주문서). 아직 안 배운 칸은 비워 두면 된다. 30레벨 천상의 정신·어둠의 보호는 전투 밖에서만 쓰니 추가 바에 두고 마우스로 누른다.

### 1. 선공 (키 1)

그냥 누르면 정신 분열, Alt를 누른 채면 성스러운 일격이다. 10레벨 전에는 성스러운 일격을 그냥 누른다.

```
#showtooltip
/cast [mod:alt] 성스러운 일격; 정신 분열
```

### 2. 마법봉과 파멸의 역병 (키 2)

그냥 누르면 마법봉 자동 사격을 켠다. 느낌표(!) 덕분에 연타해도 꺼지지 않는다. Alt는 정예나 오래 사는 몹에 거는 파멸의 역병이다. 마나가 비싸서 솔플 잡몹에는 쓰지 않는다.

```
#showtooltip
/cast [mod:alt] 파멸의 역병; !마법봉 발사
```

### 3. 마우스오버 고통 (키 3)

대상은 그대로 두고 마우스를 올린 두 번째 몹에 고통을 건다. 마우스오버가 없으면 내 대상에 건다. Alt는 흡혈의 선물이다.

```
#showtooltip
/cast [mod:alt] 흡혈의 선물; [@mouseover,harm,nodead][] 어둠의 권능: 고통
```

### 4. 영혼의 절규와 언데드 속박 (키 4)

영혼의 절규는 주변 몹을 모두 도망치게 하는 범위 공포라 대상이 필요 없다. Alt는 마우스를 올린 언데드에게 언데드 속박을 건다.

```
#showtooltip
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 언데드 속박; 영혼의 절규
```

### 5. 종족 특성 (키 5)

```
#showtooltip
/cast [mod:alt] 유레카; 탈출의 명수
```

유레카의 한글 이름이 다르면 주문서에서 Shift+클릭으로 바꾼다.

### 6. 마우스오버 치유·보호막·해제 (Ctrl+1\~4)

마우스를 올린 파티원 프레임, 없으면 우호적인 대상, 둘 다 아니면 나에게 건다. 두 번째 줄만 주문 이름을 바꿔 네 개를 만든다(순간 치유 / 신의 권능: 보호막 / 소생 / 마법 무효화).

```
#showtooltip
/cast [@mouseover,help,nodead][@target,help,nodead][@player] 순간 치유
```

마법 무효화는 적의 버프도 지울 수 있어서 조건을 help 대신 exists로 둔다.

```
#showtooltip
/cast [@mouseover,exists,nodead][] 마법 무효화
```

배치: 기본 단축바 바로 위 추가 단축바의 1\~4번 칸에 둔다. "같은 숫자의 한 칸 위 = Ctrl"로 눈에 바로 들어온다.

### 7. 내게 보호막과 마나 연소 (키 E)

```
#showtooltip
/cast [mod:shift] 마나 연소; [@player] 신의 권능: 보호막
```

### 8. 노움 사제 주문 (키 F)

Confounding Flash는 8미터 안 적 최대 5명을 3초 동안 혼란시킨다. 피해를 입으면 풀린다. Shift는 마우스를 올린 파티원(없으면 나)에게 Contingency Plan을 건다.

```
#showtooltip
/cast [mod:shift,@mouseover,help,nodead][mod:shift,@player] Contingency Plan; Confounding Flash
```

### 9. 부활 (키 T)

```
#showtooltip
/cast [mod:shift] 정신 지배; [@mouseover,help,dead][] 부활
```

### 설정 순서

1. ESC → 단축키 설정에서 Shift+1\~6(단축바 넘기기)을 지우고, Q·E의 옆걸음을 단축바 키로 바꾼다.
2. ESC → 설정 → 액션바에서 추가 단축바를 하나 켜고 기본 바 바로 위로 옮긴다. 그 바의 버튼 1\~4에 Ctrl+1\~4를 지정한다.
3. 사제는 소환수가 없어서 기본 Ctrl+1\~0(소환수 바)을 덮어써도 잊는 게 없다.
4. Shift+X·C·V는 같은 추가 바의 다른 칸에 둔다. Alt+숫자는 매크로 안에 들어 있어서 따로 지정하지 않는다.

매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다. 문법은 포에버 매크로 교본과 같다.

## 솔플

솔플의 핵심은 "보호막을 쓰고 맞지 않으면서, 마나는 마법봉으로 아끼는 것"이다. 몹이 다가오는 동안 주문을 쏟고, 붙으면 보호막이 맞아주는 동안 마법봉으로 끝낸다. 정신력 누출이 터지면 마나가 빨리 차서 물을 거의 마시지 않고 연속 사냥한다.

### 사냥 전 준비

- 신의 권능: 인내와 내면의 열정(12)을 유지한다. Forever 내면의 열정은 방어도 보너스 15%, 충전 +4회로 강해졌다.
- 마법봉을 최대한 빨리 구한다. 10레벨 마법봉류 전문화와 같이 레벨업 속도가 크게 달라진다. 장비 선택 섹션 참고.

### 한 마리 잡는 순서 (Mobalytics)

1. **보호막**: 당기기 전에 내게 신의 권능: 보호막(E). 보호막이 있으면 맞아도 주문이 밀리지 않는다.
2. **선공**: 정신 분열(1)로 큰 피해를 먼저 넣는다. 10레벨 전에는 성스러운 일격.
3. **지속 피해**: 바로 어둠의 권능: 고통(3). 즉시 시전이라 몹이 다가오는 동안 걸 수 있다.
4. **채널링**: 22레벨부터 몹이 다가오는 동안 정신의 채찍(Q). Improved Mind Flay를 찍으면 몹이 35% 느려져 더 오래 때릴 수 있다.
5. **마무리**: 몹 체력이 20% 정도 남으면 마법봉(2). 마나를 쓰지 않고 잡아야 정신력 누출 동안 마나가 찬다.
6. **전투 후**: 마나가 반 이상이면 바로 다음 몹. 체력이 모자라면 소생(Ctrl+3)을 걸고 다음 몹으로 간다. 둘 다 낮을 때만 앉아서 먹고 마신다.

마나 절약을 원하면 정신 분열을 빼고 "보호막 → 고통 → 마법봉"만으로 잡는다. 마법봉류 전문화 2/2와 좋은 마법봉이 있으면 이 방식도 충분히 빠르다.

## 던전

던전에서 암사의 가치는 딜에 더해 흡혈의 선물(파티 치유), 보호막, 해제, 버프에서 나온다. 힐러 마나가 바닥나면 급한 불을 대신 끄는 것도 암사 몫이다. Forever에는 자동 파티 찾기가 없으니 파티 찾기 목록에 "암사, 흡선·보조힐 가능"을 적으면 파티가 잘 구해진다.

### 입장 전 준비

- 파티 전원에게 신의 권능: 인내(Shift+Z 마우스오버), 30레벨부터 천상의 정신까지 건다. Forever 천상의 정신은 특성이 아니라 훈련 주문이고 지속 1시간이다.
- 힐러가 따로 있으면 나는 딜, 힐러가 쓰러지면 보호막·순간 치유로 버틴다는 것을 미리 말해둔다.
- 공포를 쓰는 보스가 있으면 탱커에게 공포의 수호물(Shift+G)을 건다. Forever에서는 모든 사제가 배우고 지속·재사용 대기는 3분이다.
- 힐러에게 Contingency Plan(Shift+F)을 걸어두면 체력이 35% 아래로 떨어질 때 보호막과 치유가 자동으로 들어간다(하위 랭크는 수치가 낮다).

### 전투 순서

1. **진입**: 탱커가 몹을 잡고 2\~3초 뒤에 시작한다. 탱커 대상 가져오기는 아래 따라 때리기 키를 쓴다.
2. **지속 피해**: 오래 사는 몹마다 키 3(마우스오버 고통)을 건다(Mobalytics). 금방 죽을 몹에는 걸지 않는다.
3. **흡혈의 선물**: 27레벨부터 해골 몹에 Alt+3. 이후 내 암흑 피해의 20%가 파티 전체를 치유한다. Forever에서 지속이 30초라 긴 전투에서는 다시 건다.
4. **채우기**: 정신 분열(1) 재사용 대기마다, 나머지는 정신의 채찍(Q). 마나가 모자라면 마법봉.
5. **보조**: 탱커가 아닌 파티원이 맞으면 보호막(Ctrl+2), 저주나 마법 디버프는 마법 무효화(Ctrl+4), 질병은 질병 치료(G).
6. **위협**: 정신 분열은 위협이 크다. 몹이 내게 오면 소실(R)로 위협을 줄이고 탱커 쪽으로 간다.
7. **군중 제어**: 영혼의 절규와 Confounding Flash는 몹이 다른 무리를 끌고 올 수 있어서 위급할 때만 쓴다. 언데드는 언데드 속박(Alt+4)으로 빼둔다.

### 던전에서 바꾸는 매크로

**따라 때리기 (숫자 1 왼쪽 키)**: 던전 입장 후 탱커를 대상으로 잡고 채팅창에 /focus를 한 번 입력한다. 그 뒤로는 이 키를 누르면 탱커의 대상을 내 대상으로 가져온다.

```
/assist focus
```

**표시 (Shift+X / Shift+C / Shift+V)**: 탱커가 표시를 안 하면 대신 해골(8)과 X(7)를 찍는다. Shift+C에는 숫자만 7로, Shift+V(언데드 속박 대상, 달)에는 5로 바꾼 같은 매크로를 넣는다.

```
/script SetRaidTarget("target", 8)
```

### 사제 육성 팁

- 초반에는 주문보다 마법봉이 빠르다. 마법부여로 직접 만들거나 흑마법사 부캐에게 부탁한다(장비 선택 참고).
- 트레이너에게 자주 간다. 짝수 레벨마다 새 랭크가 나오고, 특히 어둠의 권능: 고통·신의 권능: 보호막은 랭크를 바로 올린다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 던전은 퀘스트를 다 받은 상태로 한 번 도는 게 핵심이다.
- 재봉술 재료인 리넨·양모는 사람 몹에게서 나온다. 던 모로 트로글·서부 몰락지대 데피아스 퀘스트를 빼먹지 않는다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

사제 직업 퀘스트는 Forever 자료에서 찾지 못했다. ForeverChanges 주문서는 사제 기술을 모두 트레이너 훈련으로 적고 있어서, 흑마법사 소환수처럼 퀘스트로 배우는 주문은 없는 것으로 보인다.

## 추천 전문기술

암사 혼자라면 재봉술 + 마법부여, 노움 흑마법사와 같이 키운다면 재봉술 + 기계공학을 추천한다. 30레벨 BiS 17칸 중 재봉술 5칸, 기계공학 2칸, 마법부여 1칸이 제작품이다.

| 조합 | 어울리는 경우 | 이유 |
| --- | --- | --- |
| 재봉술 + 마법부여 | 암사가 흑마법사 대신 세 번째 부캐일 때 | 흑마법사 가이드와 같은 역할. 자기 천 장비·마법봉·보주를 만들고 드루이드·주술사의 초록 장비를 마력 추출한다 |
| 재봉술 + 기계공학 | 흑마법사와 둘 다 키울 때 | 마법부여는 흑마법사가 맡고, 암사는 BiS 장신구 2개를 기계공학으로 만든다. 노움 기계공학 전문화도 살아난다 |

재봉술 Shadow 세트가 착용 시 귀속이면, 흑마법사가 만들어 보내고 암사는 채광 + 기계공학으로 가도 된다. 현재 부캐 중 채광을 하는 캐릭터가 없어서 기계공학 재료도 스스로 채운다.

### 올리는 순서 (재봉술)

1. 재봉술 1\~75: 리넨 천으로 리넨 천 두루마리와 간단한 장비를 만든다. 75에 Shadow Gloves.
2. 재봉술 100\~125: 양모 천 구간. Shadow Gown(110), Shadow Leggings·Filigreed Shadow Circlet(125).
3. 재봉술 140: Black Slippers. 마법부여를 한다면 140에 Orb of Mystic Insight.

### 보조 전문기술

- 응급치료·요리·낚시는 다른 캐릭터와 똑같이 올린다. 사제는 치유 주문이 있어서 응급치료는 우선순위가 낮다.
- 전문기술 150·225·300 달성은 레거시 포인트를 준다.
- 전문기술 트레이너와 상인 위치는 [wow-professions.com Forever](https://www.wow-professions.com/forever)에서 찾는다.

## 노움 종족 특성

Forever 노움은 마나가 늘고 필요할 때 주문 3개를 싸고 강하게 쓰는 구성이라 암사와 잘 맞는다. Mobalytics는 얼라이언스 암사 종족으로 노움을 추천하고, Icy Veins는 나이트 엘프를 추천한다.

| 특성 | 효과 (Forever) | 암사 활용 |
| --- | --- | --- |
| 영리함 (Expansive Mind) | 최대 마나 +5% | 쉬기 전에 몹을 더 잡는다 |
| 유레카 (Eureka!, 신규) | 다음 주문·기술 3개의 비용 감소, 피해·치유 +10% | Alt+5. 정예나 보스에 정신 분열·고통·파멸의 역병을 넣을 때 켜다. 급힐 3번에 써도 좋다 |
| 탈출의 명수 (Escape Artist) | 짧은 시간 묶기·감속 면역 | 키 5. 묶인 채 맞을 때 빠져나와 거리를 벌린다 |
| 기계공학 전문화 | 기계공학 장치가 덜 실패한다 | 기계공학을 하면 BiS 장신구와 같이 쓴다 |

### 노움 전용 사제 주문

| 주문 | 레벨 | 효과 |
| --- | --- | --- |
| Confounding Flash | 10 | 8미터 안 적 최대 5명을 3초 동안 혼란. 피해를 입으면 풀린다 |
| Contingency Plan | 20 | 아군에게 30초짜리 수호. 체력이 35% 아래로 떨어지면 보호막과 15초 치유가 들어간다. 60레벨 5랭크는 926 흡수 + 670 치유 |

**다른 종족과 비교**: 나이트 엘프는 별조각(공격기)과 치명타 +10% 특성으로 딜이 강하고, 인간은 정신력 +5%로 레벨업 마나 회복이 좋다. 노움은 마나 총량과 순간 폭딜, 광역 군중 제어가 장점이다.

유레카의 정확한 감소량·재사용 대기와 Contingency Plan 하위 랭크 수치는 게임 툴팁으로 확인한다.

## 게임에서 확인할 것과 출처

주문·특성 한글 이름은 Wowhead 한글판(클래식, 어둠의 권능: 죽음은 불타는 성전)에서 대조했다. 아래는 Forever 한글 클라이언트에서 확인하지 못한 부분이다. 매크로가 안 먹으면 주문서에서 Shift+클릭으로 이름을 넣는다.

- **신규 주문·특성 이름**: Confounding Flash, Contingency Plan, Shadow Reach, Improved Mind Flay, Devouring Contagion, Early Demise, Twin Disciplines, 유레카(Eureka!)는 한글 이름을 찾지 못했다.
- **특성 단 조건**: 5점당 1단은 클래식 기준으로 계산했다. Forever 암흑 트리 배치(정신의 채찍 3단, 흡혈의 선물·어둠의 매듭 4단)는 ForeverChanges 특성 페이지 기준이다.
- **정신력 누출**: Forever에서 "몹을 잡으면 20% 확률"로 바뀌었다. 5랭크 기준인지 랭크당인지는 툴팁으로 확인한다.
- **마법봉류 전문화**: ForeverChanges 변경점은 2랭크 25%, 특성 페이지는 13%로 적어 수치가 엇갈린다.
- **사제 직업 퀘스트**: Forever 자료에서 찾지 못했다. 트레이너가 주는 퀘스트 안내를 우선한다.
- **BiS 제작품 귀속**: 재봉술 Shadow 세트와 기계공학 장신구가 착용 시 귀속인지 확인하지 못했다. 전문기술 조합이 여기에 따라 달라진다.
- **던전**: 기존 던전의 레벨과 몹 특징은 클래식 기준이다.
- **베타 패치**: 수치는 2026년 9월\~10월 자료 기준이라 베타 패치로 바뀔 수 있다.
