# 야성 드루이드 1~30 공략 (타우렌)

> 최종 수정: 2026-10-06

!!! abstract "한눈에 보기"
    - **플레이 방식**: 10~19는 곰으로 버티며 사냥, 20부터는 한 마리는 표범·여럿은 곰. 던전에서는 곰 탱커로 가장 빨리 파티를 구한다.
    - **왜 타우렌인가**: 호드 드루이드는 타우렌과 스카이본뿐이다. 타우렌은 생명력 +5%, 적중 +1%, 범위 기절(전투 발구르기)이 있어 곰 탱커에 가장 잘 맞는다. 트롤은 Forever에서도 드루이드를 못 한다.
    - **20대 목표**: 통곡의 동굴에서 송곳니 세트를 모아 뱀 변신 얻기. 호드는 통곡의 동굴이 십자로 바로 옆이라 얼라이언스보다 훨씬 편하다.
    - **대상 레벨**: 베타 현재 만렙인 1~30. 기술 레벨은 Forever 주문서 기준.
    - **전환점**: 10(곰 변신 퀘스트, 달의 숲 순간이동), 12(분노, 되살리기), 14(해독 퀘스트), 16(바다표범 퀘스트), 20(표범 변신 퀘스트, 환생, 야성의 돌진 특성), 22(칼날 발톱), 24(갈퀴 발톱, 맹공격, 저주 해제), 28(도전의 포효, 웅크리기), 30(치타 변신, 무리의 우두머리 특성).
    - **Forever 핵심 변경**: 무기 DPS가 곰·표범 피해에 그대로 들어간다(클래식과 다름). 자연의 손아귀(10)와 청명의 전조(20)는 특성이 아닌 기본 기술. 변신 중에도 물약 사용 가능, 파워시프팅(재변신으로 기력 얻기) 삭제, 야성 요정의 불꽃 없음.
    - **동선**: 멀고어(1~10) → 썬더 블러프 → 불모의 땅·통곡의 동굴(10~22) → 돌발톱 산맥 → 잿빛 골짜기·그림자송곳니 성채 → 버섯구름 봉우리·힐스브래드(25~30).
    - **전문기술**: 무두질 + 가죽세공. 싸움꾼의 가죽 도안 상인과 상자 반납처가 십자로 바로 옆이라 호드가 더 편하다. 약초는 종족 기술 재배로 채집 기술 없이 얻는다.
    - **단축키**: 다른 직업 가이드와 같은 틀. Ctrl+1~4는 변신을 풀고 거는 마우스오버 힐·해제, Alt+숫자는 같은 키의 변형, Shift는 알파벳에만, T는 환생, V는 전투 발구르기.

!!! info "관련 문서"
    같은 야성 빌드의 얼라이언스판: [야성 드루이드 (스카이본)](druid.md). 특성·단축키·매크로는 거의 같고, 종족 키와 동선·퀘스트·장비 얻는 곳이 다르다.

## 특성

30레벨까지 21포인트를 전부 야성에 넣는 **0/21/0** 빌드를 추천한다. 20까지는 분노·기력 비용과 이동을 해결하고, 21부터는 치명타·피해를 올려 30에 무리의 우두머리에 닿는다. 곰과 표범이 같은 트리를 써서 탱커와 딜러를 둘 다 할 수 있다. 특성 포인트는 10레벨부터 레벨당 1개, 5포인트마다 다음 단이 열린다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10~14 | 야수의 본성 5/5 (1단) | 후려치기·휘둘러치기·할퀴기·갈퀴 발톱·Primal Bite 비용 -1(랭크당). 곰 구간 분노 부족을 해결한다 |
| 15~16 | 살쾡이의 기민함 2/2 (2단) | 회피 증가, 표범 이동속도 +30% |
| 17~18 | 야수의 습격 2/2 (2단) | 강타 기절 증가, 재사용 대기 -30초(합계). 시전 목 차단용 |
| 19 | 야생의 본능 1/3 (2단) | 휘둘러치기 피해 증가, 숨기 발각 확률 감소 |
| 20 | 야성의 돌진 1/1 (3단) | 곰으로 돌진해 이동 불가 + 주문 차단 |
| 21~22 | 날카로운 발톱 2/2 (3단) | 곰·표범 치명타 증가 |
| 23~24 | 맹렬한 격노 2/2 (3단) | 할퀴기·갈퀴 발톱·칼날 발톱·후려치기·휘둘러치기 피해 증가 |
| 25 | Primal Bite 1/1 (4단, 신규) | 새 물어뜯기 공격 기술. 주문서 기준으로는 48레벨에 배우는 기술을 25에 얻는다 |
| 26~28 | 야생의 포식자 3/3 (4단) | 곰·표범 전투력 증가 |
| 29 | 야생의 본능 2/3 또는 피의 광기 1/2 | 탱 위주면 야생의 본능, 딜 위주면 피의 광기(치명타 시 분노·연계 점수) |
| 30 | 무리의 우두머리 1/1 (5단) | 파티 전원 치명타 증가 오라. 던전에서 바로 표가 난다 |

- 1~20은 Forever 20레벨 야성 표준 빌드 순서다. 21~30은 아직 검증된 30레벨 빌드가 없어 특성표의 단 구성에 맞춘 추천 순서다.
- Forever에서 트리 배치가 바뀌었다. 야생의 정수(Heart of the Wild)는 1단으로 내려왔고 폼별로 체력(곰)·힘(표범)을 올린다. 날카로운 발톱·맹렬한 격노는 3단, 무리의 우두머리는 5단이다.
- **탱커 위주 변형**: 야수의 습격 2 + 야생의 본능 1 대신 두꺼운 가죽 3(곰 방어도)을 찍어도 된다.
- 레거시의 Talented 특전을 찍으면 9레벨부터 특성을 받아 최대 3점을 더 쓴다. 남는 점수는 야생의 정수나 야생의 본능 3/3에 넣는다.
- **나중에 찍을 특성**(모두 Forever 신규): 5단 Predatory Instincts(치명타 피해)와 King of the Jungle(맹공격 기력), 6단 Rend and Tear(출혈 대상 피해 +2%씩)·Natural Reaction(회피·분노), 7단 Berserk.
- 영문으로 적은 특성은 Forever 신규 특성이다(한글 이름 미확인).

### 힐러(회복) 빌드

힐러를 자주 맡을 거면 레벨업은 야성으로 하고 던전 전에 특성을 초기화한다.

- **20레벨**: Naturalist 5 → 자연의 정신 집중 5 → 묵상 1
- **21~30**: 묵상 3/3 → 자연의 선물 2 → 신속한 치유 1 → 회복 연마 3 → 자연의 선물 3 → 자연의 신속함 1


!!! tip "타우렌 힐러"
    전투 발구르기로 힐러에게 붙은 몹을 2초 묶고 물러설 수 있고, 생명력 +5%로 한두 대 맞아도 버틴다.

## 단축키와 매크로

솔플·던전 모두 이 배치를 그대로 쓴다. 드루이드는 곰이나 표범으로 변신하면 기본 단축바(1~=)가 폼 전용 바로 바뀌어서, 폼마다 같은 키에 같은 역할을 두면 손가락을 옮길 필요가 없다. 수정키 규칙은 [스카이본 드루이드](druid.md)와 같고, 종족 키(V)만 다르다.

- **Ctrl + 1~4** (손바닥 새끼 쪽으로 누름): 변신을 풀고 거는 마우스오버 힐·해제. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다(추가 바는 변신해도 안 바뀐다).
- **Alt + 숫자**: 같은 키의 변형(Alt+4 겨울잠). 매크로 안에 `[mod:alt]`로 넣어 칸을 따로 쓰지 않는다.
- **Shift + 알파벳** (새끼손가락): 가끔 쓰는 기술(도전의 포효, 가시, 도망치기, 치타 변신, 재배)과 표시.
- **Shift + 숫자는 쓰지 않는다.** WoW 기본 단축바 넘기기(Shift+1~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

!!! info "태세 번호"
    드루이드 태세 번호는 배운 변신 순서대로 붙는다. 16레벨 바다표범까지 배우면 1 곰, 2 바다표범, 3 표범, 30레벨에 4 치타다. 바다표범을 건너뛰었다면 아래 매크로의 `stance:3`을 `2`로 바꾼다. 명령어와 조건은 영어, 주문 이름만 한글이다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

### 1. 만능 공격 (키 1)

캐스터면 천벌, 곰이면 후려치기, 표범이면 할퀴기가 나가고, 숨기 중에는 칼날 발톱으로 기습한다.

- 22레벨 전에는 칼날 발톱 대신 할퀴기, 24부터 출혈로 시작하고 싶으면 갈퀴 발톱으로 바꾼다.
- `nostealth` 조건 덕분에 숨기 중에 눌러도 자동 공격으로 은신이 깨지지 않는다.

```
#showtooltip
/startattack [nostealth,stance:1/3]
/cast [stance:1] 후려치기; [stance:3,stealth] 칼날 발톱; [stance:3] 할퀴기; 천벌
```

### 2. 보조 공격 (키 2)

```
#showtooltip
/startattack [stance:1/3]
/cast [stance:1] 휘둘러치기; [stance:3] 도려내기; 달빛 섬광
```

### 3. 약화·출혈 (키 3)

Forever에는 변신 상태용 요정의 불꽃이 없어서, 캐스터일 때만 요정의 불꽃이 나간다.

```
#showtooltip
/cast [stance:1] 위협의 포효; [stance:3] 갈퀴 발톱; 요정의 불꽃
```

### 4. 차단·묶기와 겨울잠 (키 4, Alt+4)

곰이면 강타, 캐스터면 휘감는 뿌리, 마우스오버한 몹이 있으면 그 몹에 쓴다. Alt를 누른 채 누르면 변신을 풀고 겨울잠(야수·용족)을 건다.

```
#showtooltip
/cancelform [mod:alt]
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 겨울잠; [stance:1,@mouseover,harm,nodead][stance:1] 강타; [nostance,@mouseover,harm,nodead][nostance] 휘감는 뿌리
```

### 5. 재사용 대기 기술 (키 5)

```
#showtooltip
/cast [stance:1] 분노; [stance:3] 맹공격; 자연의 손아귀
```

### 6. 변신 풀고 힐·해제 (Ctrl+1~4)

어느 폼에서든 변신을 풀고 바로 시전한다. 대상 우선순위는 마우스를 올린 아군 → 아군 대상 → 나.

- 솔플: 적을 잡은 채 눌러도 나에게 걸린다.
- 던전: 파티 프레임에 마우스를 올리고 누른다.

Ctrl+1 재생:

```
#showtooltip 재생
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 재생
```

Ctrl+2 회복, Ctrl+3 해독(26부터 독 해제), Ctrl+4 저주 해제는 위 매크로에서 주문 이름 두 곳만 바꾼다.

### 7. 도발·위협 조절 (키 Q, Shift+Q)

곰이면 마우스오버한 몹에 포효, Shift를 누르면 도전의 포효다. 표범이면 웅크리기로 위협을 줄인다. 28레벨 전에는 도전의 포효·웅크리기 부분이 비어 있어도 매크로는 동작한다.

```
#showtooltip
/cast [stance:1,mod:shift] 도전의 포효; [stance:1,@mouseover,harm,nodead][stance:1] 포효; [stance:3] 웅크리기
```

### 8. 돌진·이동 (키 E)과 도망치기 (Shift+E)

```
#showtooltip
/cast [stance:1,@mouseover,harm,nodead][stance:1] 야성의 돌진; [stance:3] 질주
```

Shift+E는 표범이 아니면 표범으로, 표범이면 질주다. 두 번 누르면 된다.

```
#showtooltip
/cast [nostance:3] 표범 변신; 질주
```

### 9. 폼 변신 (키 R, F)

같은 변신을 다시 눌러도 풀리지 않게 막는다. 표범 키는 두 번째 누르면 숨기다.

```
#showtooltip 곰 변신
/cast [nostance:1] 곰 변신
```

```
#showtooltip
/cast [nostance:3] 표범 변신; [nostealth,nocombat] 숨기
```

### 10. 전투 부활 (키 T)

죽은 파티원 프레임에 마우스를 올리고 누른다.

```
#showtooltip 환생
/cancelform
/cast [@mouseover,help,dead][] 환생
```

### 11. 버프 (키 Z, Shift+Z)

```
#showtooltip
/cast [mod:shift,@player] 가시; [@player] 야생의 징표
```

### 12. 전투 발구르기 (키 V)와 재배 (Shift+V)

전투 발구르기는 주변 8미터 안의 적 5명까지 2초 기절시킨다. 곰으로 몹을 모은 뒤 누르거나, 시전 몹 두세 마리를 한 번에 끊을 때 쓴다. Shift를 누르면 근처 약초에 재배를 건다.

```
#showtooltip
/cast [mod:shift] 재배; 전투 발구르기
```

### 설정 순서

1. **단축키 정리**: ESC → 단축키 설정에서 Shift+1~6(단축바 넘기기)을 지우고, Q·E의 옆걸음과 숫자 1 왼쪽 키를 단축바 키로 바꾼다. 옆걸음은 A·D + 마우스 오른쪽 버튼으로 대신한다.
2. **추가 단축바**: ESC → 설정 → 액션바에서 추가 단축바를 켜고 하나를 기본 바 바로 위로 옮긴다. 그 바의 버튼 1~4에 Ctrl+1~4를 지정하고 힐·해제 매크로 4개를 세로 줄을 맞춰 놓는다. WoW는 기본으로 Ctrl+1~0을 소환수 바에 쓰지만 드루이드는 소환수가 없어서 덮어써도 된다.
3. **폼 공통 기술**: 환생·표시·버프·종족 기술·따라 때리기처럼 폼과 상관없는 것은 추가 바에 둔다. 한 번만 놓으면 된다.
4. **폼별 기본 바**: 캐스터·곰·표범으로 각각 변신한 상태에서 1~5, Q, E, R, F 매크로를 기본 바 같은 칸에 넣는다. 폼마다 한 번씩 해야 한다.
5. **이름 오류**: 매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다.

- 여러 주문을 한 번에 나가게 하는 매크로는 안 된다(전역 재사용 대기). `/cancelform`은 전역 재사용 대기를 쓰지 않아서 한 줄 위에 넣어도 된다.

!!! warning "게임에서 확인 필요"
    - Forever는 현대 클라이언트라 표범 숨기 상태에서 단축바가 한 번 더 바뀔 수 있다. 숨기를 켰을 때 1번 칸이 비어 있으면 그 상태에서도 만능 공격 매크로를 넣는다.
    - 송곳니 세트로 얻는 뱀 모습이 태세 번호를 하나 차지하는지는 미확인. 세트를 다 모은 뒤 매크로가 이상하게 나가면 stance 번호부터 확인한다.
    - 전투 발구르기를 곰·표범 상태에서 바로 쓸 수 있는지 확인한다. 변신 중에 안 나가면 풀링 직전 캐스터 상태에서만 쓰고, 전투 중에는 곰을 풀지 않는다.
    - 재배와 평원 달리기(Plainsrunning)의 한글 이름은 미확인이다. 매크로가 안 먹으면 주문서에서 Shift+클릭으로 넣는다.

## 솔플

솔플 야성 드루이드의 기본은 **"천벌로 당기고, 안전하면 표범, 위험하면 곰"**이다. 변신은 매번 마나를 쓰니 전투 중 변신은 한 번, 힐은 전투 뒤에 몰아서 한다. Forever에서는 무기 DPS가 곰·표범 피해에 그대로 들어가므로 무기부터 챙긴다.

### 사냥 전 준비

- 야생의 징표(Z)와 가시(Shift+Z)를 유지한다.
- 10레벨부터 자연의 손아귀(캐스터 상태 5)를 켜둔다. 때린 몹이 뿌리에 묶인다.
- 몹 사이를 오갈 때는 멈추지 말고 계속 달린다. 평원 달리기는 오래 달릴수록 이동속도가 최대 30%까지 오르고, 멈추거나 맞으면 초기화된다.

### 1~9레벨: 캐스터

1. 천벌 2번으로 당긴다. 몹이 붙으면 달빛 섬광(2)을 한 번 넣는다.
2. 나머지는 무기 평타로 마무리해 마나를 아낀다. 타우렌은 적중 +1%라 평타가 덜 빗나간다.
3. 8레벨부터는 위험하면 휘감는 뿌리(4)로 묶고 물러서서 천벌을 더 쏜다. 몹 둘이 붙으면 전투 발구르기(V)로 2초 묶고 하나에 뿌리를 건다.
4. 전투 후 회복(Ctrl+2)을 걸고 다음 몹으로 간다.

### 10~19레벨: 곰

1. 천벌 1~2번으로 당기고, 몹이 다가오는 동안 곰(R)으로 변신한다.
2. 12레벨부터 변신 직후 분노(5)로 분노를 채운다.
3. 위협의 포효(3)를 한 번 걸고, 후려치기(1)를 분노가 차는 대로 누른다.
4. 2마리 이상이면 휘둘러치기(2), 도망치거나 주문을 쓰는 몹은 강타(4)로 끊는다.
5. 전투가 끝나면 변신을 풀고 회복 한 번, 마나가 남으면 다음 몹을 천벌로 당긴다.

### 20~30레벨: 표범

1. **접근**: 숨기(F 두 번)로 다가가 몹 뒤로 돈다. 24부터 맹공격(5)을 전투 직전에 켠다. 타우렌은 덩치가 커서 몹 뒤로 도는 데 한 걸음 더 든다.
2. **오프너(1)**: 20~21은 할퀴기, 22부터 칼날 발톱, 24부터는 갈퀴 발톱(3)으로 출혈을 넣어도 된다.
3. **연계 점수 쌓기**: 뒤에 있으면 칼날 발톱, 정면이면 할퀴기.
4. **마무리**: 연계 점수 4~5개에 몹이 6초 이상 버틸 것 같으면 도려내기(2), 아니면 할퀴기를 계속 누른다.
5. **청명의 전조**: 켜지면 다음 기술이 무료다. 가장 비싼 칼날 발톱에 쓴다.
6. **Primal Bite(25)**: 연계 점수 마무리 기술로 보인다. 툴팁을 보고 도려내기 대신 쓸지 정한다.

### 레벨별 변화

| --- | --- | --- |

| 10~19 | 곰 변신·포효·후려치기·위협의 포효·자연의 손아귀·달의 숲 순간이동(10), 재생·분노·되살리기(12), 강타·해독(14), 휘둘러치기·바다표범(16), 요정의 불꽃·겨울잠(18) | 곰으로 맞으면서 사냥 |

## 던전

이 레벨대에서 야성 드루이드가 파티에 가장 쉽게 들어가는 역할은 **곰 탱커**다. Forever에는 자동 파티 찾기가 없고 파티 찾기 목록만 있어서, 목록에 "곰 탱 드루이드, 전투 부활 가능(20+)"을 적으면 파티가 빨리 찬다. 타우렌은 생명력 +5%와 전투 발구르기 덕분에 곰 탱커에 가장 잘 맞는 종족이다. 표범 딜러는 22레벨 칼날 발톱, 24레벨 갈퀴 발톱부터 제 몫을 한다.

| 항목 | 곰 탱커 | 표범 딜러 |
| --- | --- | --- |
| 가능 레벨 | 10부터 | 20(표범 퀘스트)부터 |
| 목표 | 모든 몹이 나만 때리게 한다 | 탱커보다 위협을 낮게 유지하며 딜 |
| 핵심 기술 | 위협의 포효, 휘둘러치기, 후려치기, 포효, 강타 | 할퀴기, 칼날 발톱, 갈퀴 발톱, 도려내기, 웅크리기 |
| 무기 | 무기 DPS가 위협과 피해를 같이 올린다 | 무기 DPS가 가장 중요 |

### 입장 전 준비

- 야생의 징표를 파티 전원에게, 가시를 탱커(또는 나)에게 건다.
- 파티를 짤 때 가죽 주사위 규칙을 먼저 말해둔다. 송곳니 세트는 주술사·도적도 노릴 수 있다.
- 소환은 흑마법사만 할 수 있다. 호드는 통곡의 동굴·성난불길 협곡·그림자송곳니 성채가 가까워 직접 달려가도 된다.
- 던전 입장 후 표범 딜러라면 탱커를 대상으로 잡고 `/focus`를 한 번 입력한다.

### 곰 탱커: 풀링에서 마무리까지

1. **표시부터.** 해골(Shift+X)과 X(Shift+C)를 찍어 둔다.
2. **풀링.** 캐스터 상태에서 천벌로 당기고 몹이 오는 동안 곰으로 변신한다. 시전 몹이 섞여 있으면 모퉁이 뒤로 숨어 몹을 한곳으로 모은다. 20부터는 야성의 돌진(E)으로 들어가도 된다.
3. **첫 3초.** 위협의 포효(3)를 먼저 건다. 범위 안 모든 몹에 위협이 쌓여 힐러에게 가는 몹이 줄어든다.
4. **여러 마리.** 분노가 차는 대로 휘둘러치기(2). 해골 몹은 Tab으로 바꾸지 않고 후려치기(1)로 계속 때린다. 변이·겨울잠 걸린 몹이 있으면 휘둘러치기를 쓰지 않는다.
5. **몹이 떨어져 나감.** 힐러나 딜러에게 간 몹에 마우스를 올리고 Q(포효). 28부터 위급하면 Shift+Q(도전의 포효)로 주변 몹을 모두 끌어온다.
6. **시전 몹.** 강타(4)와 야성의 돌진으로 주문을 끊는다. 시전 몹이 여럿이면 전투 발구르기(V)로 한꺼번에 2초 끊는다.

!!! tip "곰 탱커 팁"
    - 분노(5)는 전투 전에 켜 두면 첫 위협이 빨라지지만 방어도가 내려간다. 큰 무리를 당길 때는 아낀다.
    - 광포한 재생력은 36레벨이라 이 구간 곰에게는 자기 회복이 없다. 체력이 낮아도 변신을 풀지 말고 힐러에게 맡긴다.
    - 후려치기는 다음 평타를 바꾸는 기술이라 연타해도 한 번만 나간다. 평타와 가시가 피해·위협의 대부분이라 무기가 좋을수록 탱도 쉽다.

### 표범 딜러: 위협 넘지 않기

1. 탱커가 위협의 포효와 공격 2~3번을 넣을 때까지 기다린다. 숫자 1 왼쪽 키로 탱커의 대상을 가져온다.
2. 몹 뒤에서 칼날 발톱, 정면이면 할퀴기. 갈퀴 발톱은 오래 사는 정예 몹에만 건다.
3. 연계 점수 4~5개에서 몹이 오래 버틸 것 같으면 도려내기.
4. 몹이 나를 보기 시작하면 28부터 Q(웅크리기), 그 전에는 공격을 잠깐 멈춘다.
5. 요정의 불꽃이 필요하면 변신 전에 캐스터로 건다(야성 요정의 불꽃 없음).
6. 탱커가 죽으면 R로 곰으로 바꿔 대신 버틴다. 드루이드 딜러의 가장 큰 장점이다.

### 던전용 매크로

**따라 때리기 (숫자 1 왼쪽 키)**: 던전 입장 후 탱커를 대상으로 잡고 `/focus`를 한 번 입력하면, 그 뒤로 이 키가 탱커의 대상을 내 대상으로 가져온다.

```
/assist [@focus,exists]
/startattack [nostealth,harm]
```

**표시 (Shift+X / Shift+C)**: 마우스오버한 몹, 없으면 대상에 해골을 찍는다. Shift+C에는 숫자만 7(X)로 바꾼 같은 매크로를 넣는다. 5인 파티에서는 누구나 쓸 수 있다.

```
/tm [@mouseover,exists][] 8
```

### 직업 퀘스트

- **10레벨 곰 변신**: 블러드후프 마을의 Gennia Runetotem에게 Heeding the Call을 받거나 바로 썬더 블러프의 Turak Runetotem `/way 76.5 27.2`에게 간다. 달의 숲 순간이동으로 나이트헤이븐의 Dendrite Starblaze `/way 56.2 30.6`를 만나고, 숲속의 위대한 곰의 정령과 대화한 뒤 썬더 블러프로 돌아온다. 마지막 Body and Heart는 불모의 땅 타우라조 야영지 서쪽, 멀고어로 넘어가는 길 남쪽 나무 뒤의 달빛야수 선돌에 Cenarion Lunardust를 써서 Lunaclaw를 불러 잡는다. 휘감는 뿌리로 묶고 천벌·달빛 섬광으로 싸운다. 보상은 곰 변신·포효·후려치기.
- **14레벨 해독**: Turak의 Lessons Anew. 땅뿌리와 코도 뿔로 연고를 만들어 불모의 땅의 병든 가젤에게 쓴다.
- **16레벨 바다표범 변신**: Turak의 A Lesson to Learn에서 시작한다. 클래식에서는 불모의 땅 북쪽 진흙늪 물속 상자(57, 8)와 은빛소나무 숲 바닷가(27, 30)에서 반쪽 목걸이를 모았다. Forever 단계는 미확인.
- **20레벨 표범 변신**: Turak에게 The Great Cat Spirit를 받아 달의 숲 Dendrite에게 간다. 남쪽 다리가 내려다보이는 언덕의 위대한 표범의 정령을 만나고, 동쪽 스톰레이지 지하굴 `/way 71.2 61.5`에서 송곳니·발톱·고요한 그림자 유물 3개를 모은다. 입구 석상이 잠깐 은신을 걸어 주니 효과를 확인하고 들어간다. 정령에게 돌아가 Blessings of the Great Cat Spirit, 마지막 To Thunder Bluff로 Turak에게 가면 표범 변신을 배운다. 유물은 파티 공유다.
- **30레벨 치타 변신**: 주문서에는 30레벨 훈련 기술로 나온다. 조련사에게 바로 배우는지 퀘스트가 있는지는 미확인.

### 육성 팁

- 무두질은 사냥하며 같이 올린다. 멀고어와 불모의 땅은 야수가 많아 가죽세공 재료가 떨어지지 않는다.
- 사냥 중 분실된 상자(Waylaid Crate)가 나오면 버리지 말고 재료를 채워 반납한다. 반납처가 십자로 바로 밖이라 동선에 끼워 넣기 쉽다. [전문기술](#전문기술) 참고.
- 트레이너에게 자주 간다. 짝수 레벨마다 새 기술이나 랭크가 나온다. 썬더 블러프 비룡 이동과 달의 숲 순간이동을 묶으면 왕복이 짧다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 던전은 퀘스트를 다 받은 상태로 도는 게 핵심이다. 통곡의 동굴은 세트 때문에 여러 번 도니, 첫 번째에 퀘스트를 모두 끝낸다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

## 장비

야성 드루이드의 첫 목표는 **무기**다. Forever에서는 무기 DPS가 곰·표범 피해에 들어간다. 호드는 죽음의 폐광 무기(Smite's Mighty Hammer)를 노리기 어려워서, 20 전후에는 통곡의 동굴 퀘스트 보상 지팡이, 30에는 Viscous Hammer를 목표로 한다. 방어구는 가죽이고, 20대에는 송곳니 세트, 25 이후에는 직접 만든 싸움꾼의 가죽 세트로 채운다.

!!! info "스탯 우선순위"
    무기 DPS > 적중 > 치명타 > 힘 > 민첩 > 체력 > 정신력 > 지능

    Forever는 적중과 치명타가 각각 하나의 스탯으로 합쳐졌다. 타우렌은 지속 효과로 적중 +1%가 있다.

- **무기**: 드루이드는 단검·장착 무기·둔기·지팡이·양손 둔기를 쓴다. 양손 둔기는 썬더 블러프 무기 전문가에게 배운다(클래식 기준). 타우렌 시작 무기는 미확인.
- **초반**: 8레벨쯤 경매장에서 초록 무기를 하나 사면 평타 DPS가 크게 오른다. 새 무기는 숙련도가 낮으면 빗나감이 많으니 필드에서 올리고 던전에 간다.
- **가시**: 걸 때의 주문력을 저장한다. 탱커는 주문력 장비 몇 개를 따로 챙겼다가 가시를 걸 때만 입는다.

## 전문기술

이 드루이드는 **무두질 + 가죽세공**으로 간다. 싸움꾼의 가죽 다리보호대는 착용 시 귀속이라 입을 캐릭터가 직접 만들어야 하고, 호드는 도안 상인과 상자 반납처가 모두 십자로 바로 옆이다. 약초는 종족 기술 재배로 채집 기술 없이 얻을 수 있어서 약초채집을 따로 배우지 않아도 된다.

| (종족) 재배 | 약초 노드에 걸면 채집 기술 없이 캘 수 있는 약초가 하나 더 자란다. 재사용 1시간 | 타우렌 신규. 경매장 판매나 연금술 캐릭터에게 우편 |

!!! tip "약초채집 + 가죽세공을 고르고 싶다면"
    재배는 약초 노드가 눈에 보여야 쓸 수 있다. 약초채집이 있으면 미니맵에 약초가 표시되고 노드 하나에서 두 번 캐는 셈이라 골드 벌이는 좋다. 대신 무두질이 없으면 가죽을 경매장에서 사야 한다. 레벨업 중에는 무두질 + 가죽세공이 낫다.

### 싸움꾼의 가죽 도안

| 도안 | 필요 스킬 | 가격 |
| --- | --- | --- |
| Brawler's Leather Belt | 60 | 상인의 호의 30 |
| Brawler's Leather Gloves | 75 | 상인의 호의 30 |
| Brawler's Leather Boots | 85 | 상인의 호의 30 |
| Brawler's Leather Hood | 100 | 상인의 호의 30 |
| Brawler's Leather Tunic | 110 | 상인의 호의 30 |
| Brawler's Leather Legguards (싸움꾼의 가죽 다리보호대) | 125 | 상인의 호의 30 |

- **상인의 호의(Merchant's Favor)**: 필드에서 나오는 분실된 상자(Waylaid Crate)에 요구 재료(예: 리넨 천, 얇은 가죽)를 채워 반납하면 받는다. 상자 하나에 5, 첫 상자는 보너스로 55를 줘서 도안 하나를 바로 산다.
- **반납처**: 호드는 십자로 바로 밖의 Dokimi `/way 50.1 29.3`(불모의 땅)이고, 옆 캠프의 Pawani가 싸움꾼 도안을 판다.
- Brawler's Leather Helm(30레벨 BiS)은 가죽세공 목록 100~130 구간에 있다. 필요 스킬과 파는 곳은 미확인.

### 올리는 순서

1. **배우기**: 블러드후프 마을이나 썬더 블러프에서 무두질과 가죽세공을 배운다. 썬더 블러프 가죽세공 조련사는 Una(클래식 기준)다.
2. **1~55**: 1~30 찢어진 가죽 조각으로 얇은 가죽, 30~45 얇은 방어구 강화재, 45~55 양각 가죽 장갑.
3. **55~80**: Fine Leather Belt. 60에 싸움꾼 허리를 만들 수 있으니 도안을 산 뒤에는 싸움꾼 도안으로 올리는 것도 방법이다.
4. **80~125**: Dark Leather 계열. 125에 싸움꾼의 가죽 다리보호대.
5. **125~150**: 질긴 가죽(Heavy Leather) → Hillman's Leather Gloves. 150이 되면 썬더 블러프 조련사에게 전문가 단계를 배운다.

### 무두질 운영

- 무두질은 몹 레벨 × 5 정도 스킬이 있어야 가죽을 벗길 수 있다(클래식 기준). 사냥 중 야수를 잡을 때마다 벗기면 레벨과 같이 올라간다.
- 얇은 가죽(1~20대 야수) → 중간 가죽(20대) → 질긴 가죽(30대) 순서다. 남는 가죽은 경매장에 팔아 초반 골드를 모은다.
- 멀고어 평원의 야수, 불모의 땅 얼룩말·사바나 사자, 통곡의 동굴 랩터·뱀이 좋은 무두질 사냥터다.

### 보조 전문기술

- 응급치료·요리·낚시는 다른 캐릭터와 똑같이 올린다. Forever 모닥불 시스템에서 요리로 모닥불을 피우고 옆에 전문기술 설비를 두면 버프를 받는다.
- 전문기술 150·225·300 달성은 레거시 포인트를 준다. 레거시의 Talented 특전이 [특성](#특성) 섹션의 추가 특성 포인트다.
- Forever에서는 변신 중에도 물약을 마실 수 있다. 재배로 얻은 약초를 연금술 캐릭터에게 보내 물약으로 돌려받으면 좋다.

## 종족 특성

타우렌은 **"맞아도 안 죽고, 넓은 들판을 빨리 달리는"** 구성이다. 순간 피해 버프는 없지만 생명력·적중·범위 기절이 모두 곰 탱커와 솔플 생존에 바로 쓰인다.

| 특성 | 효과 | 야성 드루이드 활용 |
| --- | --- | --- |
| 전투 발구르기 | 주변 8미터 안의 적 5명까지 2초 기절. 0.5초 시전, 재사용 2분 | V. 탱커는 시전 몹 여럿 끊기, 솔플은 두 마리가 붙었을 때 시간 벌기. 도망칠 때 첫 2초 |
| 인내 (지속) | 최대 생명력 +5%, 적중 +1% | 곰 생명력이 장비만큼 같이 커진다. 적중 1%는 근접 빗나감을 줄인다 |
| 재배 | 약초 노드에 걸면 채집 기술 없이 캘 수 있는 약초가 하나 더 자란다. 재사용 1시간 | Shift+V. 길에서 약초를 보면 습관처럼 쓴다 |
| 평원 달리기 (Plainsrunning, 지속, 신규) | 계속 움직이면 이동속도가 점점 올라 최대 30%. 멈추거나 피해를 받으면 초기화. 전투 중에도 작동 | 불모의 땅·멀고어처럼 넓은 곳에서 퀘스트 동선이 짧아진다. 치타(+40%)와 겹치는지는 미확인 |

!!! tip "타우렌 곰 탱커"
    풀링 → 위협의 포효 → 휘둘러치기 2~3번으로 위협을 잡은 뒤, 시전 몹이 힐러를 노리면 그 사이에 들어가 전투 발구르기를 쓴다. 기절 2초 동안 강타는 아껴 두었다가 기절이 풀리는 순간 남은 시전 몹에 넣는다.

- **변신 모습**: 타우렌 곰·표범은 다른 종족과 모양이 다르다. 주문 이름과 태세 번호는 나이트 엘프·스카이본과 같다.
- **덩치**: 타우렌은 몸이 커서 근접 사거리 판정이 조금 넉넉하지만, 좁은 던전 통로에서 뒤에 선 파티원의 시야를 가린다.
- **스카이본(호드)과 비교**: 호드 스카이본 드루이드도 가능하다. 스카이본은 바람의 축복(가속 +1%), 공중 걷기, 창공안이 있고, 타우렌은 생명력·적중·기절이 있다. 탱커와 솔플 안정성은 타우렌이 낫다.
- 클래식 타우렌의 자연 저항 +10이 Forever에도 남아 있는지는 미확인. 재배와 평원 달리기의 한글 이름도 미확인이다.
