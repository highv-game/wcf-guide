# 오크 고양 주술사 1~30 공략 (포에버)

> 최종 수정: 2026-10-06

!!! abstract "한눈에 보기"
    번개 화살로 당기고, 토템을 깔고, 느린 양손 무기 평타 사이에 폭풍의 일격과 충격을 섞는 근접 하이브리드다. 호드 주술사 종족 중 고양에는 오크가 가장 잘 맞는다. 피의 격노가 전투력을 올려 주고, 도끼를 들면 치명타가 붙는다.

    - **대상 레벨**: 베타 만렙인 1~30. 기술 레벨은 Forever 주문서 기준이고, 특성·단축키는 [드워프 고양 주술사](shaman.md)와 같은 틀이다.
    - **진영**: 호드. 시련의 골짜기에서 시작해 듀로타 → 불모의 땅으로 올라간다.
    - **무기**: 느린 양손 도끼. 30레벨까지 쌍수는 없고, 오크는 도끼를 들면 치명타 +1%.
    - **전문기술**: 무두질 + 가죽세공. 30레벨 BiS 방어구 4부위와 싸움꾼의 가죽 다리보호대를 직접 만든다. 호드 캐릭터라 얼라이언스 부캐와 우편으로 주고받을 수 없다.
    - **전환점**: 4레벨(대지의 부름), 10레벨(불의 부름, 화염 충격, 대지력 토템, 특성 시작), 20레벨(물의 부름, 늑대 정령, 원소의 부름, 하급 치유의 물결), 25레벨(폭풍의 일격 특성), 30레벨(바람의 부름, 질풍의 무기, 마법정화 토템, 윤회).
    - **Forever 핵심 변경**:
        - 무기 강화 지속 60분.
        - 토템 사거리 30m, 지속 5분.
        - 원소의 부름으로 토템 4개를 한 번에 깔고, 토템의 귀환으로 마나 25%를 돌려받는다.
        - 불꽃 회오리는 깔아 둔 불 토템 주변에 터지는 주문이다(재사용 10초).
        - 오크 피의 격노가 전투력과 주문력을 10%씩 올리는 기술로 바뀌었고, 치유 감소가 없다. 지휘는 사라지고 저주를 지우는 신규 기술이 들어왔다.
    - **단축키**: 1 주력, 4 마우스오버 차단, 5 피의 격노, Ctrl+1~4 마우스오버 힐·해제, Alt+숫자 변형, Shift+알파벳 가끔 쓰는 것, T 부활 계열. Shift+숫자는 쓰지 않는다.

## 특성

드워프 고양 주술사와 같은 **0/21/0** 빌드다. 특성은 종족과 상관이 없고, 오크는 치명타 관련 특성과 도끼 전문화가 잘 겹친다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10~14 | 우레와 같은 일격 5/5 (1단) | 치명타 +1%(랭크당) |
| 15~17 | Mental Dexterity 3/3 (2단, 신규) | 지능의 33%만큼 전투력 증가 |
| 18~19 | 향상된 번개 보호막 2/3 (2단) | 번개 보호막 피해 +5%(랭크당) |
| 20 | Shamanistic Focus 1/1 (3단, 신규) | 충격·번개 보호막 마나 비용 -45%. 솔플 마나 문제를 크게 줄인다 |
| 21~23 | 정령의 무기 3/3 (3단) | 대지의 무기 +7%, 질풍의 무기 +13% |
| 24 | 향상된 번개 보호막 3/3 | 15점을 채워 4단을 연다 |
| 25 | 폭풍의 일격 1/1 (4단) | 무기 피해 즉시 공격 + 다음 번개 화살·연쇄 번개·대지 충격 피해 +20%(12초) |
| 26~29 | 질풍 4/5 (4단) | 치명타 후 3타 공격 속도 증가 |
| 30 | Improved Stormstrike 1/2 (5단, 신규) | 폭풍의 일격 후 50% 확률로 15초간 시전 중 마나 회복. 회피·패리 때 재사용 초기화 확률 |

영문 표기 특성은 Forever 신규 특성이라 한글 이름을 아직 확인하지 못했다.

- **레거시 Talented 특전**: 9레벨부터 특성을 받아 최대 3점을 더 쓴다. 남는 점수는 질풍 5/5와 Improved Stormstrike 2/2에 넣는다.
- **대안**: 이동이 많으면 18~19에 향상된 늑대 정령 2/2(시전 -1초, 실내 사용 가능)를 먼저 찍고 번개 보호막 랭크를 뒤로 미룬다.
- **오크와의 궁합**: 피의 격노의 전투력 10%와 Mental Dexterity의 지능 → 전투력이 곱해지고, 도끼 전문화 치명타 +1%가 질풍 발동을 늘린다.

## 단축키와 매크로

솔플·던전·2인 모두 이 배치를 그대로 쓴다. 드워프 주술사와 다른 곳은 키 5(종족 기술)뿐이다.

- **Ctrl + 1~4** (손바닥 새끼 쪽으로 누름): 마우스오버 힐과 해제. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다.
- **Alt + 숫자**: 같은 키의 변형. 매크로 안에 `[mod:alt]`로 넣어 칸을 따로 쓰지 않는다.
- **Shift + 알파벳** (새끼손가락): 토템·버프의 변형, 전투 밖 기술, 표시.
- **Shift + 숫자**는 쓰지 않는다. 기본 단축바 넘기기(Shift+1~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

| 키 | 역할 | 기본 | 수정키 |
| --- | --- | --- | --- |
| 1 | 주력 공격 | 전투 밖 번개 화살, 전투 중 폭풍의 일격(25) | Alt: 번개 화살 / Ctrl: 하급 치유의 물결(20, 전에는 치유의 물결) |
| 2 | 보조 공격 | 대지 충격(4) | Alt: 냉기 충격(20) / Ctrl: 치유의 물결 |
| 3 | 불 피해 | 화염 충격(10) | Alt: 불꽃 회오리(12) / Ctrl: 해독(16) |
| 4 | 차단 | 마우스오버 대지 충격 | Alt: 마우스오버 정화(12) / Ctrl: 질병 치료(22) |
| 5 | 폭딜 | 피의 격노(오크) | Alt: 저주 해제 종족 기술(Shatter Curse, 한글명 미확인) |
| Q | 군중 제어 토템 | 속박의 토템(6) | Shift: 마법정화 토템(30) |
| E | 이동 | 늑대 정령(20) | Shift: 토템 재배치(22, 커서 위치) |
| R | 토템 깔기 | 원소의 부름(20, 전에는 대지력 토템) | Shift: 토템의 귀환(20) / Alt: 선조의 부름(30) |
| F | 불 토템 | 불타는 토템(10) | Shift: 용암 토템(26) |
| G | 긴급 토템 | 돌발톱 토템(8) | Shift: 진동의 토템(18) |
| Z | 버프 | 번개 보호막(8) | Shift: 무기 강화(대지의 무기 / 질풍의 무기) |
| T | 부활 | 마우스오버 고대의 영혼(12, 전투 밖) | Shift: 수중 호흡(22) |
| X / C / V | 표시 | - | Shift: 해골 / X / 달 |

괄호 숫자는 배우는 레벨이다. 아직 안 배운 칸은 비워 둔다.

### 1. 주력 공격 (키 1)

전투 밖에서는 번개 화살로 당기고, 전투가 시작되면 같은 키가 자동 공격을 켜고 폭풍의 일격을 쓴다. Alt를 누른 채 누르면 전투 중에도 번개 화살이다.

```
#showtooltip
/startattack [combat,harm]
/cast [mod:alt][nocombat] 번개 화살; 폭풍의 일격
```

25레벨 전에는 마지막 줄에서 `; 폭풍의 일격`을 지우고 쓴다.

### 2. 대지·냉기 충격 (키 2)

```
#showtooltip
/startattack [harm]
/cast [mod:alt] 냉기 충격; 대지 충격
```

### 3. 화염 충격과 불꽃 회오리 (키 3)

불꽃 회오리는 깔아 둔 불 토템 주변 10m에 터진다. F로 불타는 토템을 몹 무리 옆에 깔고 Alt+3을 누른다.

```
#showtooltip
/cast [mod:alt] 불꽃 회오리; 화염 충격
```

### 4. 마우스오버 차단과 정화 (키 4)

```
#showtooltip
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 정화; [@mouseover,harm,nodead][] 대지 충격
```

### 5. 피의 격노와 저주 해제 (키 5)

그냥 누르면 피의 격노(15초간 전투력·주문력 +10%), Alt를 누른 채 누르면 Forever 신규 종족 기술로 나에게 걸린 저주를 지운다. 주술사는 저주 해제가 없어서 이 기술이 유일한 저주 대처다.

```
#showtooltip
/cast [mod:alt] Shatter Curse; 피의 격노
```

!!! warning "한글 이름 미확인"
    `Shatter Curse`는 한글 이름을 확인하지 못했다. 매크로 창을 연 채 주문서 종족 탭에서 그 기술을 Shift+클릭해 이름을 바꿔 넣는다.

피의 격노는 정예·보스, 또는 여러 마리가 붙었을 때 폭풍의 일격 직전에 누른다. 장신구가 생기면 아래처럼 한 키에 묶어도 된다.

```
#showtooltip 피의 격노
/use 13
/cast [mod:alt] Shatter Curse; 피의 격노
```

### 6. 아군 힐·해제 (Ctrl+1~4)

마우스를 올린 파티원 → 아군 대상 → 나 순서로 대상을 고른다. 솔플에서는 적을 대상으로 잡은 채 눌러도 나에게 걸린다.

!!! tip "배치"
    기본 단축바 바로 위 추가 단축바의 1~4번 칸에 둔다. 1번 위에 Ctrl+1처럼 세로 줄을 맞추면 "같은 숫자의 한 칸 위 = Ctrl"로 바로 보인다.

Ctrl+1 하급 치유의 물결 (20레벨 전에는 치유의 물결):

```
#showtooltip
/cast [@mouseover,help,nodead][help,nodead][@player] 하급 치유의 물결
```

Ctrl+2 치유의 물결, Ctrl+3 해독, Ctrl+4 질병 치료는 기술 이름만 바꾼다.

### 7. 토템 키 (R, F, G, Q, E)

R은 20레벨에 받는 원소의 부름이다. 토템 바에 지정한 토템을 최대 4개까지 한 번에 깐다. Shift는 토템의 귀환, Alt는 30레벨의 선조의 부름(다른 토템 세트)이다.

```
#showtooltip
/cast [mod:shift] 토템의 귀환; [mod:alt] 선조의 부름; 원소의 부름
```

20레벨 전에는 R에 대지력 토템(10, 그 전에는 돌가죽 토템)만 둔다. F·G·Q는 같은 틀이다.

```
#showtooltip
/cast [mod:shift] 용암 토템; 불타는 토템
```

- G: `진동의 토템; 돌발톱 토템`으로 이름만 바꾼다.
- Q: `마법정화 토템; 속박의 토템`으로 이름만 바꾼다.
- E: 늑대 정령과 토템 재배치(22, 재사용 1분, 30m).

```
#showtooltip
/cast [mod:shift,@cursor] 토템 재배치; 늑대 정령
```

### 8. 버프와 부활 (키 Z, T)

```
#showtooltip
/cast [mod:shift] 대지의 무기; 번개 보호막
```

30레벨에 질풍의 무기를 배우면 `대지의 무기`를 `질풍의 무기`로 바꾼다.

```
#showtooltip
/cast [mod:shift,@mouseover,help][mod:shift] 수중 호흡; [@mouseover,help,dead][] 고대의 영혼
```

### 설정 순서

1. ESC → 단축키 설정에서 Shift+1~6(단축바 넘기기)을 지우고, Q·E의 옆걸음을 단축바 키로 바꾼다.
2. 추가 단축바를 하나 켜고 기본 바 바로 위로 옮긴 뒤 버튼 1~4에 Ctrl+1~4를 지정한다. 주술사는 소환수가 없어서 Ctrl+숫자 소환수 바를 덮어써도 된다.
3. Shift+X·C·V는 같은 추가 바의 다른 칸에 둔다.
4. 파티 프레임을 화면 아래쪽 가운데, 추가 단축바 근처로 옮긴다.
5. 원소의 부름을 배우면 토템 바에서 땅·불·물·바람 칸에 쓸 토템을 고른다.
6. 매크로가 안 먹으면 주문서에서 기술을 Shift+클릭해 이름을 넣는다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

## 솔플

솔플의 핵심은 마나다. 번개 화살 한 번으로 당기고, 나머지는 양손 무기 평타와 번개 보호막으로 잡으며, 충격은 마무리나 차단에만 쓴다.

### 사냥 전 준비

- 대지의 무기를 건다(60분). 30레벨부터는 질풍의 무기.
- 번개 보호막을 항상 유지한다.
- 사냥터에 도착하면 대지력 토템을 미리 깔고 그 근처로 몹을 당긴다.
- 무두질을 하니 사냥 중 짐승 가죽은 모두 벗긴다. 듀로타·불모의 땅은 멧돼지·랩터·사자 같은 짐승 몹이 많다.

### 한 마리 잡는 순서

1. **당기기**: 번개 화살 1번(키 1).
2. **붙으면**: 키 1을 다시 눌러 자동 공격 + 폭풍의 일격(25 이후). 10레벨부터는 불타는 토템(F)도 깐다.
3. **강한 몹만**: 화염 충격(3), 피의 격노(5).
4. **마무리**: 폭풍의 일격 직후 대지 충격(2).
5. **시전하는 몹**: 대지 충격(4)으로 끊는다.
6. **전투 후**: 체력이 낮으면 하급 치유의 물결(Ctrl+1) 한 번. 마나가 반 아래면 앉아서 물을 마신다.

### 레벨별 변화

| 레벨 | 더해지는 것 | 솔플에서의 의미 |
| --- | --- | --- |
| 1~9 | 번개 화살, 치유의 물결, 대지의 무기(1), 대지 충격·돌가죽 토템(4, 대지의 부름), 속박의 토템(6), 번개 보호막·돌발톱 토템(8) | 번개 화살로 당기고 평타. 8레벨부터 번개 보호막 상시 |
| 10~19 | 화염 충격·불타는 토템(불의 부름)·대지력 토템·불꽃의 무기(10), 불꽃 회오리·정화·고대의 영혼(12), 해독(16), 진동의 토템(18) | 토템 2개(대지력 + 불타는) 깔고 사냥 |
| 20~25 | 늑대 정령·냉기 충격·하급 치유의 물결·치유의 토템(물의 부름)·원소의 부름·토템의 귀환(20), 토템 재배치·수중 호흡·질병 치료(22), 폭풍의 일격(25) | R 한 번으로 토템 세팅. 25부터 폭풍의 일격 → 대지 충격 연계 |
| 26~29 | 용암 토템·마나샘 토템(26), 불꽃의 토템(28) | 물 칸을 마나샘 토템으로 바꾼다 |

## 던전

던전에서 고양 주술사의 가치는 토템과 차단이다. 파티 전체에 대지력·마나샘 토템을 깔고, 시전하는 몹을 대지 충격으로 끊고, 힐러가 바쁠 때 하급 치유의 물결로 보조한다.

!!! info "파티 구하기"
    Forever에는 자동 파티 찾기가 없고 파티 찾기 목록만 있다. 소환은 흑마법사만 된다.

### 전투 순서

1. **풀링 전**: R(원소의 부름)으로 토템을 탱커 근처에 깔아 둔다. 풀링은 탱커 몫이다.
2. **진입**: 탱커가 몹을 잡고 2~3초 뒤 따라 때리기 키로 들어간다.
3. **딜**: 피의 격노(5) → 폭풍의 일격 → 대지 충격. 화염 충격은 오래 사는 정예에만.
4. **차단**: 해골 외 몹이 시전하면 마우스를 올리고 4.
5. **여러 마리**: 불타는 토템을 몹 무리 옆에 깔고 불꽃 회오리(Alt+3). 탱커가 위협을 잡은 뒤에만.
6. **힐러 보조**: 탱커 프레임에 마우스를 올리고 Ctrl+1.

### 던전 토템 조합

| 칸 | 기본 | 바꿀 때 |
| --- | --- | --- |
| 땅 | 대지력 토템 | 공포·매혹·수면 몹이면 진동의 토템(Shift+G) |
| 불 | 불타는 토템 | 28부터 불꽃의 토템, 여러 마리면 용암 토템(Shift+F) |
| 물 | 마나샘 토템(26) | 독 몹이 많으면 독 정화 토템(22), 26 전에는 치유의 토템 |
| 바람 | 30부터 마법정화 토템 | - |

!!! tip "30레벨 던전 세트"
    대지력 / 불꽃의 토템 / 마나샘 / 마법정화를 선조의 부름(Alt+R)에, 솔플 세트를 원소의 부름(R)에 넣어둔다.

### 던전 매크로

**따라 때리기 (숫자 1 왼쪽 키)**: 탱커를 대상으로 잡고 채팅창에 `/focus`를 한 번 입력한 뒤 쓴다.

```
/assist [@focus,exists]
/startattack [harm]
```

**표시 (Shift+X / C / V)**: 해골(8), X(7), 달(5). Shift+C·V는 숫자만 바꾼다.

```
/tm [@mouseover,exists][] 8
```

## 마법사와 2인 파티

호드에서는 오크·트롤 마법사와 짝을 짠다. 주술사가 앞에서 맞고 힐하고, 마법사는 뒤에서 딜과 군중 제어, 물·빵을 맡는다.

| 항목 | 오크 주술사 | 마법사 |
| --- | --- | --- |
| 당기기 | 번개 화살로 당기고 붙는다 | 주술사가 몹을 친 뒤 2초 후부터 딜 |
| 여러 마리 | 속박의 토템, 돌발톱 토템, 피의 격노 + 불꽃 회오리 | 얼음 회오리 후 광역 |
| 군중 제어 | 변이 대상에 달 표시(Shift+V) | 변이, 마법 차단 |
| 생존 | 나와 마법사 힐, 해독 | 물·빵, 신비한 지능 |

!!! tip "신비한 지능"
    Mental Dexterity가 지능의 33%를 전투력으로 바꾸니 항상 걸어 달라고 한다. 마법사가 오크면 둘 다 피의 격노를 같은 타이밍에 쓴다.

- 마법사 힐은 따로 만들지 않는다. 마법사 파티 프레임에 마우스를 올리고 Ctrl+1이나 Ctrl+2.
- 변이 몹 근처에는 불타는 토템과 불꽃 회오리를 쓰지 않는다.

마법사 쪽 1번 키 매크로(주술사 대상 따라 쏘기):

```
#showtooltip
/assist [@party1,exists,nodead]
/cast 얼음 화살
```

### 토템 퀘스트

호드 주술사는 원소별 퀘스트로 토템을 받는다. 퀘스트를 미루면 그 원소의 토템을 못 쓰니 레벨이 되면 바로 한다. 아래는 클래식 호드 퀘스트 기준이고, Forever에서 바뀌었는지는 아직 확인하지 못했다. NPC·몹·아이템 이름은 영문 그대로 적었다.

**대지의 부름 (4레벨)**

1. 시련의 골짜기의 Canaga Earthcaller에게 받는다.
2. 골짜기의 Felstalker를 잡아 Felstalker Hoof 2개를 모은다.
3. Canaga에게 받은 대지의 정기를 정기 바위 `/way 듀로타 44.0 76.1` 에서 마시고, 나타난 Minor Manifestation of Earth와 대화한다.
4. 보상: 대지 토템, 돌가죽 토템.

**불의 부름 (10레벨)**

1. 오그리마 주술사 트레이너에게서 시작해, 듀로타 Southfury 강을 따라 숨은 산길로 올라가 정상의 Telf Joolam `/way 듀로타 38.5 58.9` 에게 희미한 불씨의 횃불을 가져간다.
2. 불모의 땅 Razormane 주술사 몹에게서 Fire Tar, 듀로타 Burning Blade Cultist에게서 Reagent Pouch를 모은다.
3. Telf Joolam에게서 불의 정기를 받아 Minor Manifestation of Fire를 잡는다.
4. 불 붙은 횃불을 불모의 땅 Kranal Fiss `/way 불모의 땅 56.0 20.0` 에게 가져간다.
5. 보상: 불 토템, 불타는 토템.

**물의 부름 (20레벨, 뒷단계는 23 정도)**

1. 불모의 땅 동쪽 해안 Islen Waterseer `/way 불모의 땅 65.8 43.8` 에게 받는다.
2. 불모의 땅 남쪽 Brine `/way 불모의 땅 43.0 77.0` 에게서 물주머니를 받아 채운다.
3. 남은 물주머니를 타렌 밀농장 우물 `/way 힐스브래드 구릉지 62.0 20.0`, 잿빛 골짜기 Ruins of Stardust 분수 `/way 잿빛 골짜기 33.0 67.0` 에서 채운다.
4. 은빛소나무 숲 `/way 은빛소나무 숲 38.0 44.0` 에서 Corrupt Minor Manifestation of Water를 잡고 Shard of Water를 가져간다.
5. 보상: 물 토템, 치유의 토템.

**바람의 부름 (30레벨)**

1. 오그리마 주술사 트레이너에게 받는다.
2. 버섯구름 봉우리 Prate Cloudseer `/way 버섯구름 봉우리 53.0 42.0` 에게 간다. 전투가 없다.
3. 보상: 바람 토템, 1시간 이동 속도 버프.

!!! tip "물의 부름 동선"
    불모의 땅·힐스브래드·잿빛 골짜기·은빛소나무 숲을 도는 긴 줄기다. 20레벨에 늑대 정령을 먼저 배우고, 그 지역 퀘스트를 하러 갈 때 물주머니를 같이 채운다. 은빛소나무 숲은 그림자송곳니 성채 갈 때 들른다.

### 육성 팁

- 1~19는 최대 피해가 높은 양손 무기면 된다. 25에 폭풍의 일격을 배운 뒤부터 느린 양손 도끼를 고른다.
- 짝수 레벨마다 트레이너에 간다. 번개 보호막·대지 충격 랭크가 사냥 속도를 크게 바꾼다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 퀘스트를 다 받은 상태로 한 번 도는 게 핵심이다.
- 가죽세공 텐트가 있는 모닥불에서는 휴식 경험치 5%를 준다. 이 캐릭터가 가죽세공이라 직접 켤 수 있다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

## 장비

첫 목표는 느리고 강한 양손 도끼다. 오크는 도끼 치명타 +1%가 있어서, 성능이 비슷하면 둔기보다 도끼를 고른다.

- **스탯 우선순위(레벨업)**: 무기 DPS > 치명타 > 힘 > 지능 > 민첩 > 주문력 > 정신력 > 체력.
- **무기**: 양손 도끼 > 양손 둔기. 30까지 쌍수는 없다.
- **방어구**: 가죽. 사슬은 40레벨부터다(클래식 기준).
- **성물 칸**: 주술사는 성물 칸에 토템을 끼운다.

- 싸움꾼의 가죽 다리보호대는 Forever 신규 가죽세공 125 도안이다. 입을 캐릭터가 직접 만들어야 하고, 25레벨 민첩·힘 다리라 이 캐릭터가 입기 좋다.
- 아이템 이름은 영문 그대로 적었다. 베타 초기 목록이라 바뀔 수 있다.

## 전문기술

이 주술사는 **무두질 + 가죽세공**으로 간다. 호드 캐릭터는 얼라이언스 부캐(드루이드의 가죽세공, 주술사의 연금술, 흑마법사의 마법부여)와 우편을 주고받을 수 없으니, 장비를 직접 만드는 쪽이 낫다.

| 전문기술 | 이 캐릭터에서의 쓰임 |
| --- | --- |
| 무두질 | 가죽세공 재료. 듀로타·불모의 땅 짐승 몹이 많아 사냥하면서 오른다. 남는 가죽은 경매장 |
| 가죽세공 | 30 BiS 4부위, 싸움꾼의 가죽 다리보호대, 모닥불 Camp Tent(휴식 경험치 5%). Forever 신규 Totemic 가죽 세트가 주술사용이다 |

!!! tip "대안: 약초채집 + 연금술"
    호드에 다른 캐릭터가 가죽세공을 맡는다면 드워프 주술사처럼 약초채집 + 연금술로 가서 물약을 만든다. 연금술 모닥불 Mana Well이 주술사에게 잘 맞는다.

### 올리는 순서

1. 시련의 골짜기부터 짐승을 잡을 때마다 가죽을 벗긴다.
2. 가죽세공 1~75는 가벼운 가죽 장비, 무두질 손질 가죽으로 올린다.
3. 불모의 땅에서 보통 가죽을 모아 가죽세공 75~125를 올린다. 125에 싸움꾼의 가죽 다리보호대 도안을 산다. 도안 상인은 십자로 옆 Pawani이고, 화폐 상인의 호의는 필드의 분실된 상자(Waylaid Crate)에 재료를 채워 반납하면 받는다. 자세한 방법은 [야성 드루이드 공략](druid.md#싸움꾼의-가죽-도안)에 있다.
4. 30 BiS 가죽 4부위 도안의 필요 스킬은 아직 확인하지 못했다. 도안을 경매장·상인에서 찾아 둔다.
5. 응급치료·요리·낚시도 같이 올린다. 전문기술 150·225·300 달성은 레거시 포인트를 준다.

## 종족 특성

Forever 오크는 지휘가 빠지고 저주를 지우는 신규 기술이 들어왔다. 피의 격노는 근접·캐스터 모두 쓰는 전투력·주문력 증가로 바뀌었다.

| 특성 | 효과 (Forever) | 고양 주술사 활용 |
| --- | --- | --- |
| 피의 격노 | 15초간 전투력·주문력 +10% | 키 5. 정예·보스, 여러 마리, 폭풍의 일격 직전 |
| 도끼류 전문화 | 도끼를 들면 치명타 +1% | 양손 도끼 우선. 치명타가 늘면 질풍도 자주 터진다 |
| Shatter Curse (신규, 한글명 미확인) | 나에게 걸린 저주·Bane 해제, 8초간 받는 마법 피해 -15% | Alt+5. 주술사는 저주 해제가 없어서 귀하다 |
| 강인함 | 기절 효과 -20% | 자동. 솔플·전장에서 기절이 덜 걸린다 |

!!! info "다른 호드 종족과 비교"
    타우렌은 체력 +5%와 적중 +1%, 전투 발구르기가 있어서 버티기는 더 좋다. 트롤은 광폭화(가속)가 있다. 딜과 무기 궁합은 오크가 가장 낫다.
