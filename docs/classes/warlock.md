# 노움 흑마법사 가이드 (포에버)

> 최종 수정: 2026-10-02

## 한눈에 보기

노움 흑마법사는 "보이드워커에게 맞게 하고, 지속 피해를 걸고, 마법봉으로 마무리하는" 펫 캐스터다. 레벨업은 고통 특성, 소환수는 보이드워커가 기본이고, 파티에서는 저주·생명석·영혼석·소환을 맡는다.

- 대상 레벨: 베타 현재 만렙인 1\~30. 기술 레벨은 ForeverChanges 주문서 기준이다.
- 이 캐릭터의 역할: 세 번째 부캐. 재봉술 + 마법부여로 드루이드·주술사가 얻는 귀속 안 된 초록 장비를 마력 추출한다. Forever에는 자동 파티 찾기가 없고 소환은 흑마법사만 할 수 있어서, 던전 파티에서 흑마법사는 늘 환영받는다.
- 전환점: 10레벨(보이드워커, 영혼 흡수, 생명석), 20레벨(서큐버스/인큐버스, 악마의 갑옷, 소환 의식, 원소의 저주, 불의 비), 28레벨(추방), 30레벨(지옥사냥개, 생명력 착취 특성).
- Forever 핵심 변경: 지속 피해가 치명타로 터지고, 걸 때가 아니라 틱마다 버프를 계산한다. 디버프 칸 제한이 없어졌다. 고통의 저주는 '저주'에서 '파멸(Bane)'으로 이름이 바뀌어 무력화·원소의 저주와 같이 걸 수 있다(Bane of Agony). 생명력 전환은 정신력에 비례한다. 영혼의 가방은 재료 가방 칸에 들어간다.
- 단축키 배치는 기존 주술사·야성 드루이드 가이드와 같은 틀(1 주력, 4 마우스오버 군중 제어, Q·E 보조 공격, Z 버프, T 부활 계열)을 쓰고, Ctrl+1\~4에는 마우스오버 지속 피해와 소환수 치유를 모았다. Shift+숫자는 쓰지 않는다.

출처: [ForeverChanges 흑마법사 변경점](https://foreverchanges.pro/class/warlock), [Warcraft Tavern 흑마법사](https://www.warcrafttavern.com/forever/guides/warlock/)

## 특성 빌드 (1\~30레벨)

30레벨까지 21포인트를 전부 고통에 넣는 21/0/0 빌드를 추천한다. 부패를 즉시 시전으로 만들고, 흡수 주문을 강하게 해서 쉬는 시간을 줄이는 것이 목표다. 특성 포인트는 10레벨부터 레벨당 1개씩 받고, 5포인트마다 다음 단이 열린다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10\~14 | 부패 연마 5/5 (1단) | 부패 시전 시간 -0.4초, 피해 +2%(랭크당). 5/5면 부패가 즉시 시전이 된다 |
| 15\~17 | Improved Drains 3/3 (2단, 신규) | 생명력 흡수·영혼 흡수·마나 흡수 효과 +7%(랭크당). 생명력 흡수로 체력을 채우는 양이 늘어난다 |
| 18\~19 | 억제 2/5 (1단) | 적중 +1%, 위협 -4%(랭크당). Forever에서 효과가 바뀌다 |
| 20\~22 | 마의 정신집중 3/3 (3단) | 흡수 주문 도중 맞아도 끊기지 않을 확률 증가. 솔플에서 생명력 흡수가 안 끊긴다 |
| 23\~24 | Malediction 2/5 (2단, 신규) | 모든 지속 피해 +1%(랭크당) |
| 25\~26 | 일몰 2/2 (4단) | 지속 피해가 들어갈 때 확률적으로 어둠의 무아지경. 다음 어둠의 화살이 즉시 시전이 된다 |
| 27\~29 | Pandemic 3/3 (3단, 신규) | 지속 피해 치명타 피해 +33%(랭크당 합계) |
| 30 | 생명력 착취 1/1 (5단) | 체력을 빼앗는 네 번째 지속 피해 |

- 순서는 Mobalytics·Warcraft Tavern 고통 레벨업 빌드의 특성 목록을 단 조건(5점당 1단)에 맞게 내가 배열한 것이다. 두 가이드 모두 어느 레벨에 무엇을 찍는지는 적지 않았다.
- 레거시의 Talented 특전을 찍으면 9레벨부터 특성을 받아 최대 3점을 더 쓴다. 남는 점수는 억제 4/5(동레벨 적중 보완)나 생명력 전환 연마에 넣는다.
- 대안: 마나가 자주 모자라면 15\~16에 생명력 전환 연마 2/2(생명력 전환 마나 +10%씩)를 먼저 찍고 Improved Drains를 미룬다.
- 나중에 찍을 특성: Malevolence(4단, 암흑 치명타 +1%씩)는 30 이후 Pandemic과 같이 올린다. 7단 Wrack(암흑 지속 피해 + 다른 암흑 지속 피해 +10%)은 41점 특성이다.

### 다른 특성을 고를 때

- 악마: 소환수가 강해지고 생존이 좋다. 30레벨 정도면 서큐버스 연마(Improved Sayaad), Demonic Brand, 영혼의 고리를 목표로 한다(Warcraft Tavern). 악마의 희생은 Forever에서 3단으로 내려오고 지속 2시간이다.
- 파괴: 어둠의 연소(3단), 점화(4단으로 내려옴, 제물 지우며 피해), Bane of Havoc(5단, 다른 대상 피해의 15%를 표시 대상에 전달)을 얻는다. 던전 위주일 때 어울린다.
- 악마 트리에는 Forever 신규 Portal of Summoning(의식으로 파티 여러 명 소환)이 있다. 30레벨까지는 닿지 않는다.

특성 이름은 Wowhead 한글판(클래식) 이름이고, 영문은 Forever 신규라 한글 이름을 확인하지 못한 특성이다.

출처: [ForeverChanges 흑마법사 특성](https://foreverchanges.pro/talents/warlock), [Mobalytics 흑마법사 레벨업](https://mobalytics.gg/wow-forever/classes/warlock-leveling-guide), [Mobalytics 고통 흑마법사](https://mobalytics.gg/wow-forever/classes/affliction-warlock-guide)

## 공통 단축키와 기본 매크로

솔플·던전 모두 이 배치를 그대로 쓴다. 흑마법사는 변신 바가 없어서 한 번 놓으면 끝이다. 수정키 규칙은 주술사·드루이드 가이드와 같다.

- Ctrl + 1\~4 (손바닥 새끼 쪽으로 누름): 마우스오버 지속 피해와 소환수 치유. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다.
- Alt + 숫자: 같은 키의 변형(영혼 흡수, 불타는 고통, 제물, 추방, 유레카). 매크로 안에 \[mod:alt\]로 넣어 칸을 따로 쓰지 않는다.
- Shift + 알파벳 (새끼손가락): 가끔 쓰는 기술(저주 변형, 마나 흡수, 소환수 명령, 버프 변형)과 표시.
- Shift + 숫자는 쓰지 않는다. WoW 기본 단축바 넘기기(Shift+1\~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

| 키 | 역할 | 기본 | 수정키 |
| --- | --- | --- | --- |
| 1 | 주력 공격 | 어둠의 화살 + 소환수 공격 | Alt: 영혼 흡수(10) / Ctrl: 마우스오버 부패 |
| 2 | 마무리·이동 중 | 마법봉 발사 | Alt: 불타는 고통(18) / Ctrl: 마우스오버 고통의 저주 |
| 3 | 지속 피해 | 부패(4) | Alt: 제물 / Ctrl: 마우스오버 제물 |
| 4 | 군중 제어 | 마우스오버 공포(8) | Alt: 마우스오버 추방(28) / Ctrl: 생명력 집중(12, 소환수 치유) |
| 5 | 종족 | 탈출의 명수(노움) | Alt: 유레카(Eureka!) |
| Q | 저주 | 고통의 저주(8) | Shift: 무력화 저주 / 원소의 저주(20) |
| E | 흡수 | 생명력 흡수(14) | Shift: 마나 흡수(24) |
| R | 마나 | 생명력 전환(6) | - |
| F | 소환수 기술 | 소환수 공격 + 고문·유혹·주문 잠금 | Shift: 소환수 복귀(따라오기) |
| G | 긴급 | 생명석 사용 | Shift: 희생(보이드워커) |
| Z | 버프 | 악마의 피부 / 악마의 갑옷(20) | Shift: 영원의 숨결(16) |
| T | 영혼석·소환 | 마우스오버 영혼석 사용 | Shift: 소환 의식(20) |
| X / C / V | 표시 | - | Shift: 해골 / X / 달 |

괄호 숫자는 배우는 레벨(ForeverChanges 주문서). 아직 안 배운 칸은 비워 두면 된다.

### 1. 주력 공격 (키 1)

누르면 소환수가 같은 대상을 공격하고 어둠의 화살을 쏜다. Alt를 누른 채 누르면 영혼 흡수다. 몹 체력이 25% 아래일 때 Alt+1로 마무리하면 영혼의 조각을 얻는다.

```
#showtooltip
/petattack [harm,nodead]
/cast [mod:alt] 영혼 흡수; 어둠의 화살
```

### 2. 마법봉과 불타는 고통 (키 2)

그냥 누르면 마법봉 자동 사격을 켠다. 느낌표(!) 덕분에 연타해도 꺼지지 않는다. Alt는 즉시 피해가 필요한 순간의 불타는 고통이다.

```
#showtooltip
/cast [mod:alt] 불타는 고통; !마법봉 발사
```

### 3. 마우스오버 공포·추방 (키 4)

대상을 바꾸지 않고 마우스를 올린 몹에 공포를 건다. Alt를 누른 채 누르면 추방(정령·악마만)이다. 둘 다 "두 번째 몹 묶기"라 한 키에 모았다.

```
#showtooltip
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 추방; [@mouseover,harm,nodead][] 공포
```

### 4. 마우스오버 지속 피해 (Ctrl+1\~3)

대상은 그대로 두고, 마우스를 올린 두 번째·세 번째 몹에 지속 피해를 건다. 마우스오버가 없으면 내 대상에 건다. Forever는 디버프 칸 제한이 없어서 여러 마리에 다 걸어도 된다.

배치: 기본 단축바 바로 위 추가 단축바의 1\~4번 칸에 둔다. 1번 위에 Ctrl+1처럼 세로 줄을 맞추면 "같은 숫자의 한 칸 위 = Ctrl"로 눈에 바로 들어온다.

Ctrl+1 부패:

```
#showtooltip
/cast [@mouseover,harm,nodead][] 부패
```

Ctrl+2 고통의 저주 (Forever 이름은 Bane of Agony. 한글 이름이 다르면 주문서에서 Shift+클릭으로 바꾼다):

```
#showtooltip
/cast [@mouseover,harm,nodead][] 고통의 저주
```

Ctrl+3 제물: 위와 같은 매크로에서 이름만 제물로 바꾼다.

Ctrl+4 생명력 집중 (소환수 치유, 대상 지정 없음):

```
#showtooltip
/cast 생명력 집중
```

### 5. 소환수 기술 (키 F)

소환수에 따라 같은 키가 다른 기술을 쓴다. 보이드워커는 고문(도발), 서큐버스는 유혹(마우스오버한 몹), 지옥사냥개는 주문 잠금(마우스오버한 몹)이다. Shift는 소환수를 불러들인다.

```
#showtooltip
/petattack [nomod,@mouseover,harm,nodead][nomod]
/petfollow [mod:shift]
/cast [pet:서큐버스,@mouseover,harm,nodead][pet:서큐버스] 유혹; [pet:지옥사냥개,@mouseover,harm,nodead][pet:지옥사냥개] 주문 잠금; [pet:보이드워커] 고문
```

### 6. 생명석과 희생 (키 G)

Forever에서 생명석 창조는 랭크가 하나로 합쳐졌다. 가방의 생명석 이름이 다르면 매크로 창을 연 채 가방에서 Shift+클릭으로 넣는다.

```
#showtooltip
/cast [mod:shift,pet:보이드워커] 희생
/use [nomod] 생명석
```

### 7. 영혼석과 소환 (키 T)

죽기 전에 거는 부활이다. 마우스를 올린 파티원(보통 힐러), 없으면 아군 대상, 둘 다 아니면 나에게 건다. Shift는 소환 의식이다.

```
#showtooltip
/cast [mod:shift] 소환 의식
/use [nomod,@mouseover,help,nodead][nomod,help,nodead][nomod,@player] 영혼석
```

### 8. 버프 (키 Z)

```
#showtooltip
/cast [mod:shift] 영원의 숨결; 악마의 피부
```

20레벨에 악마의 갑옷을 배우면 악마의 피부를 악마의 갑옷으로 바꾼다.

### 설정 순서

- ESC → 단축키 설정에서 Shift+1\~6(단축바 넘기기)을 지우고, Q·E의 옆걸음을 단축바 키로 바꾼다.
- ESC → 설정 → 액션바에서 추가 단축바를 하나 켜고 기본 바 바로 위로 옮긴다. 그 바의 버튼 1\~4에 Ctrl+1\~4를 지정한다.
- WoW는 기본으로 Ctrl+1\~0을 소환수 바에 쓴다. 흑마법사는 소환수가 있지만 F 매크로가 공격·기술·복귀를 대신하니 Ctrl+1\~4는 덮어써도 된다. 소환수 바는 마우스로 누르고, 자동 시전(화염 화살·고문·고통의 채찍)은 소환수 바에서 오른쪽 클릭으로 켠다.
- Shift+X·C·V는 같은 추가 바의 다른 칸에 둔다. Alt+숫자는 매크로 안에 들어 있어서 따로 지정하지 않는다.
- 매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

## 솔플

솔플의 핵심은 "마나를 체력으로, 체력을 다시 마나로" 돌리는 것이다. 보이드워커가 맞는 동안 지속 피해를 걸고 마법봉을 쏜며, 생명력 전환으로 마나를 채우고 생명력 흡수로 체력을 돌려받는다. 잘 돌아가면 물을 거의 마시지 않고 연속 사냥한다.

### 사냥 전 준비

- 악마의 피부(20부터 악마의 갑옷)를 유지한다.
- 영혼의 조각 3\~5개를 들고 다닌다. 소환수가 죽었을 때 다시 부르고 생명석을 만드는 데 쓴다.
- 생명석을 하나 만들어 둔다(G). 위급할 때 시전 없이 체력을 채운다.
- 보이드워커의 고문 자동 시전을 켜둔다.

### 한 마리 잡는 순서

1. 소환수 보내기: F(또는 키 1)로 보이드워커를 먼저 보낸다. 고문으로 위협을 잡을 때까지 1\~2초 기다린다.
2. 지속 피해: 부패(3) → 고통의 저주(Q) → 몹이 오래 살 때만 제물(Alt+3). Mobalytics 순서는 제물 → 고통 → 부패지만, 부패 연마 5/5 이후에는 즉시 시전인 부패부터 거는 게 안전하다.
3. 채우기: 마법봉(2). 마나를 쓰지 않고 지속 피해가 도는 동안 피해를 더한다.
4. 체력이 모자라면: 생명력 흡수(E). Improved Drains와 마의 정신집중을 찍으면 끊기지 않고 많이 채워진다.
5. 마무리: 영혼의 조각이 필요하면 체력 25% 아래에서 영혼 흡수(Alt+1).
6. 전투 후: 마나가 모자라면 생명력 전환(R), 체력은 다음 몹에게 생명력 흡수로 돌려받는다. 둘 다 낮을 때만 앉아서 먹고 마신다.

일몰(25)을 찍은 뒤에는 어둠의 무아지경이 켜지면 바로 키 1을 눌러 즉시 어둠의 화살을 쏜다.

### 소환수 고르기 (솔플)

- 1\~9 임프: 화염 화살 자동 시전. 피의 서약으로 체력이 늘어난다.
- 10\~30 보이드워커: 기본. 몹을 잡아주니 내가 거의 안 맞는다.
- 20 이후 서큐버스: 몹이 약하고 하나씩 있을 때 더 빠르다. 서큐버스는 잘 맞지 못하니 몹이 내게 오면 공포로 떼어낸다.
- 소환수를 바꾸면 영혼의 조각이 하나 든다(임프는 제외). 사냥터에 도착하기 전에 정해둔다.

## 던전

던전에서 흑마법사의 가치는 딜보다 생명석·영혼석·소환과 저주에서 나온다. Forever에는 자동 파티 찾기가 없고 소환도 흑마법사만 할 수 있다. 파티 찾기 목록에 "흑마, 소환 가능(20+), 생명석"을 적으면 파티가 잘 구해진다.

### 입장 전 준비

- 영혼의 조각을 파티 인원 + 3개 정도 챙긴다. 생명석 5개, 영혼석 1개, 소환 몇 번에 쓴다.
- 생명석을 만들어 파티원에게 하나씩 건네고, 영혼석은 힐러에게 건다(T, 힐러 프레임에 마우스오버).
- 소환 의식(20)은 파티원 2명이 더 도와야 하고 영혼의 조각을 쓴다. 던전 입구에 먼저 도착한 3명이 나머지를 부른다.
- 소환수는 임프(화염 화살 자동 시전, 파티 체력 버프)로 바꾼다. Mobalytics는 던전에서 보이드워커 대신 임프를, 딜을 더 원하면 서큐버스를 추천한다. 보이드워커를 데려가면 고문 자동 시전을 꺼서 탱커 어그로를 벌지 않게 한다.

### 전투 순서

1. 진입: 탱커가 몹을 잡고 2\~3초 뒤에 시작한다. 탱커 대상 가져오기는 아래 따라 때리기 키를 쓴다.
2. 저주: 파티에 맞는 저주 하나를 해골 몹에 건다. 보통은 고통의 저주(파멸), 캐스터가 많으면 20레벨부터 원소의 저주(Shift+Q), 물리 피해가 강한 보스에는 무력화 저주.
3. 지속 피해: 해골 몹에 부패·제물, 오래 사는 다른 몹에는 Ctrl+1\~3으로 마우스오버. 금방 죽을 몹에는 걸지 않는다.
4. 채우기: 어둠의 화살(1). 마나가 부족하면 생명력 전환 후 생명력 흡수로 체력을 되찾는다. 힐러 마나를 아끼는 것이 파티 전체에 더 이득이다.
5. 군중 제어: 공포는 몹이 다른 무리를 끌고 올 수 있어서 위급할 때만 쓴다. 정령·악마는 추방(Alt+4, 28)으로 빼둔다.
6. 위협: 지속 피해는 여러 몹에게 위협을 쌓는다. 몹이 나에게 오면 멈추고 탱커 쪽으로 간다. 억제는 위협을 4%씩 줄여준다.

### 던전에서 바꾸는 매크로

따라 때리기 (숫자 1 왼쪽 키): 던전 입장 후 탱커를 대상으로 잡고 채팅창에 /focus를 한 번 입력한다. 그 뒤로는 이 키를 누르면 탱커의 대상을 내 대상으로 가져오고 소환수도 같이 보낸다.

```
/assist [@focus,exists]
/petattack [harm,nodead]
```

생명석 나눠주기: 생명석은 파티원에게 거래로 준다. 파티 채팅에 "생명석 필요하면 거래 걸어주세요"라고 적어두면 된다.

표시 (Shift+X / Shift+C): 탱커가 표시를 안 하면 대신 해골(8)과 X(7)를 찍는다. Shift+C에는 숫자만 7로, Shift+V(추방·공포 대상, 달)에는 5로 바꾼 같은 매크로를 넣는다.

```
/tm [@mouseover,exists][] 8
```

### 흑마법사 소환수 퀘스트

- 임프: 클래식에서 노움·드워프 흑마법사는 콜드릿지 계곡 앤빌마르의 Alamar Grimm에게 Beginnings(4레벨)를 받아 남서쪽 동굴의 Frostmane 몹에게서 Feather Charm 3개를 모아 임프 소환을 배웠다. ForeverChanges 주문서는 임프 소환을 1레벨 기술로 적어서, Forever에서 퀘스트가 빠졌는지는 게임에서 확인한다.
- 보이드워커 (10): 아이언포지 흑마법사 트레이너에게 퀘스트를 받는다. 클래식 얼라이언스 퀘스트는 Surena's Choker를 찾아 가져온 뒤 보이드워커를 불러내 쓰러뜨리는 흐름이다(Icy Veins). 소환한 보이드워커는 꽤 세니 체력과 마나를 채우고 시작한다.
- 서큐버스 (20): 도시 흑마법사 트레이너에게 받는다. 클래식에서는 여러 지역에서 재료를 모아 도시에서 서큐버스를 불러내 쓰러뜨린다. Forever는 주문서에 서큐버스와 인큐버스를 함께 올려둔다.
- 지옥사냥개 (30): 클래식에서는 래치릿의 Strahad Farsan에게서 시작해 아이언포지 Krom Stoutarm, 저습지(Moldy Tome, Rod of Channeling 3개), 버데기 산어덕(Tattered Manuscript)을 거친다(Icy Veins). 30레벨 직후 가장 오래 걸리는 퀘스트다.
- 클래식 퀘스트 상세(NPC·동선)는 Forever에서 바뀌었을 수 있고 한글판 이름도 대조하지 못해 영문으로 적었다. 트레이너가 주는 퀘스트 안내를 우선한다.

### 흑마법사 육성 팁

- 초반에는 어둠의 화살보다 마법봉이 빠르다(Warcraft Tavern). 마법부여 75에 하급 마법봉을 직접 만들 수 있다. 장비 선택 섹션 참고.
- 트레이너에게 자주 간다. 짝수 레벨마다 새 랭크가 나오고, 소환수 기술은 악마 트레이너에게 따로 산다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 던전은 퀘스트를 다 받은 상태로 한 번 도는 게 핵심이다.
- 재봉술 재료인 리넨·양모는 사람 몹에게서 나온다. 던 모로 트로글·서부 몰락지대 데피아스 퀘스트를 빼먹지 않는다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

## 장비 선택

레벨업 흑마법사의 첫 목표는 마법봉이다. 이 캐릭터는 마법부여로 마법봉을, 재봉술로 천 방어구를 직접 만들 수 있어서 장비 대부분을 스스로 채운다.

- 스탯 규칙(레벨업 기준): 주문력 > 정신력 > 지능 > 체력(Mobalytics). Forever의 생명력 전환은 정신력에 비례하니 정신력 장비가 치우기보다 좋다. Mobalytics 고통 가이드는 던전에서 지능·체력을 우선으로 본다.
- 무기: 지팡이나 한손 단검·도검. 노움 흑마법사는 지팡이·단검·한손 도검을 들 수 있다. Forever에서 도검 치명타 보너스는 인간 레이셜이다.
- 방어구: 천. 재봉술 목표는 30레벨 BiS 표를 본다.

## 추천 전문기술

이 흑마법사는 재봉술 + 마법부여로 간다. 재봉술로 자기 천 장비를 만들고, 마법부여로 마법봉을 만들며, 드루이드·주술사가 얻는 귀속 안 된 초록 장비를 마력 추출한다. 세 캐릭터 분담(드루이드 무두질·가죽세공, 주술사 약초채집·연금술)을 정한 스레드의 결론이다.

| 전문기술 | 이 캐릭터에서의 쓰임 | Forever 변경 |
| --- | --- | --- |
| 재봉술 | 천 장비 5부위(30레벨 BiS), 가방, 마법부여 연습용 초록 장비 | 신규 도안 180개. 20에 모닥불 Faction Banner(주변 아군 정신력 +32), 140에 Spinning Wheel |
| 마법부여 | 마법봉 3종, 마력 추출, 자기 장비 마법부여 | 신규 주문서 66개. 20에 모닥불 Enchanted Lute(방어도·능력치·저항), 140에 Arcane Salvager(마력 추출 효율 증가) |

### 올리는 순서

1. 재봉술 1\~75: 리넨 천으로 리넨 천 두루마리와 간단한 장비를 만든다. 초록 등급 장비는 입거나 바로 마력 추출한다.
2. 마법부여는 재봉술로 만든 초록 장비와 다른 캐릭터에게 받은 초록 장비를 추출해 가루를 모으며 올린다. "만든 걸 추출한다"가 두 전문기술의 기본 순환이다(ForeverChanges).
3. 마법부여 75에 하급 마법봉, 110에 상급 마법봉을 만들어 바로 든다.
4. 재봉술 100\~125: 양모 천 구간. Forever 신규 Shadow Circlet(100)·Filigreed Shadow Circlet(125)·Shadow Gown(110)을 만든다.
5. 재봉술 140·마법부여 140에 모닥불 설비를 한 단계씩 올린다.

### 마력 추출 운영

- 마력 추출은 마법부여 스킬에 따라 추출할 수 있는 아이템 레벨이 정해져 있다. 스킬 100이면 아이템 레벨 40까지, 60레벨 장비는 300이 필요하다(클래식 기준).
- 드루이드·주술사가 쓰지 않는 초록 장비(귀속 안 됨)를 우편으로 흑마법사에게 보내 추출한다. 같은 계정 캐릭터는 동시에 접속할 수 없어서, 이미 귀속된 다른 캐릭터 장비에는 마법부여를 해줄 수 없다. 클래식에는 마법부여 스크롤도 없다.
- 희귀(파란) 장비는 추출하면 결정이 나오지만, 경매장 가격과 비교해서 결정한다.

### 보조 전문기술

- 응급치료·요리·낚시는 다른 캐릭터와 똑같이 올린다. 응급치료는 마나 없이 체력을 채우는 수단이라 흑마법사에게 특히 쓸모 있다.
- 전문기술 150·225·300 달성은 레거시 포인트를 준다. 레거시의 Talented 특전이 특성 섹션의 추가 특성 포인트다.
- 영혼의 가방(Soul Pouch)은 재봉술 도안이고, Forever에서는 재료 가방 칸에 들어간다(Warcraft Tavern). 필요한 스킬은 클래식 기준 260이라 30레벨 구간에서는 경매장에서 작은 영혼의 가방을 산다.

전문기술 트레이너와 상인 위치는 [wow-professions.com Forever](https://www.wow-professions.com/forever)에서 찾는다.

## 노움 종족 특성

Forever 노움은 레이셜이 아래 네 가지로 바뀌다. 마나가 늘고 필요할 때 주문 3개를 싼게 강하게 쓰는 구성이라 캐스터인 흑마법사와 잘 맞는다. Mobalytics는 얼라이언스 흑마법사 종족으로 노움을 추천한다.

| 특성 | 효과 (Forever) | 흑마법사 활용 |
| --- | --- | --- |
| 영리함 (Expansive Mind) | 최대 마나(또는 분노·기력) +5%. 클래식에서는 지능 +5%였다 | 마나가 늘어 쉬기 전에 몹을 더 잡는다 |
| 유레카 (Eureka!, 신규) | 다음 주문·기술 3개의 비용 감소, 피해·치유 +10% | Alt+5. 정예나 보스에 지속 피해 3개를 걸 때 켜다 |
| 탈출의 명수 (Escape Artist) | 짧은 시간 묶기·감속 면역. Warcraft Tavern 기준 3초, 재사용 2분 | 키 5. 묶인 채 두들겨 맞을 때 빠져나와 공포 거리를 벌린다 |
| 기계공학 전문화 | 기계공학 장치가 덜 실패한다 | 이 캐릭터는 기계공학을 안 하니 효과 없음 |

- 인간과 비교: 인간은 정신력 +5%(생명력 전환과 궁합이 좋다)와 기절 해제를 갖는다. 마나 총량과 순간 폭딥은 노움, 생존과 PvP는 인간이 조금 낫다.
- 클래식의 비전 저항 레이셜은 위 네 가지에 없다(method.gg 목록 기준).
- 유레카의 정확한 감소량·재사용 대기와 탈출의 명수 수치는 출처마다 달라 게임 툴팁으로 확인한다.

## 게임에서 확인할 것과 출처

주문 이름은 한글 클래식 클라이언트 기준이고, 일부(보이드워커 소환, 마법봉 발사, 무력화 저주, 일몰, 어둠의 무아지경, 마의 정신집중, 어둠의 연소, 영리함)는 Wowhead 한글판(클래식)에서 직접 대조했다. 아래는 Forever 한글 클라이언트에서 확인하지 못한 부분이다. 매크로가 안 먹으면 주문서나 가방에서 Shift+클릭으로 이름을 넣는다.

- 고통의 저주: Forever에서 Bane of Agony로 바뀌다. 한글판은 대격변 이후처럼 '고통의 파멸'일 수 있다. 파멸과 저주를 한 대상에 같이 걸 수 있다는 것은 Warcraft Tavern의 "저주와 파멸이 나뉘었다"는 설명에서 추론한 것이다.
- 소환수 조건 \[pet:서큐버스\] 등: 악마 종류 이름이 한글 클라이언트에서 다르면 조건이 안 먹는다. 안 먹으면 소환수별로 F 매크로를 따로 만든다. 인큐버스는 서큐버스와 같은 기술을 쓰는지 확인하지 못했다.
- 소환수 기술 이름(고문, 유혹, 주문 잠금, 희생)과 아이템 이름(생명석, 영혼석)은 대조하지 않았다. Forever는 생명석·화염석·주문석 랭크를 하나로 합쳤다.
- 소환수 퀘스트: 임프·보이드워커·서큐버스·지옥사냥개 퀘스트는 클래식 기준이고, Forever에서도 퀘스트로 배우는지 확인하지 못했다.
- 특성 단 조건: 5점당 1단은 클래식 기준으로 계산했다. 신규 특성(Improved Drains, Malediction, Pandemic 등)의 한글 이름은 찾지 못했다.
- 마법봉 제작 스킬(75·110·175)은 ForeverChanges 값이고 클래식과 다르다.
- 던전: 기존 던전의 레벨과 몹 특징은 클래식 기준이다.
