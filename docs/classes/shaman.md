# 드워프 고양 주술사 1~30 공략 (포에버)

> 최종 수정: 2026-10-04

!!! abstract "한눈에 보기"
    번개 화살로 당기고, 토템을 깔고, 느린 양손 무기 평타 사이에 폭풍의 일격과 충격을 섞는 근접 하이브리드다. Forever에서 얼라이언스 주술사는 드워프만 할 수 있다. 레벨업은 고양 특성, 파티에서는 토템·차단·보조 힐을 맡는다.

    - **대상 레벨**: 베타 만렙인 1~30. 기술 레벨은 Forever 주문서 기준.
    - **역할**: 두 번째 부캐. 약초채집 + 연금술로 세 캐릭터가 쓸 물약과 영약을 만든다. 드루이드(가죽세공)가 토템 가죽 장비를, 흑마법사(마법부여)가 성물을 만들어 준다.
    - **무기**: 느린 양손 둔기. 30레벨까지 쌍수는 없고, 드워프는 둔기를 들면 치명타 +1%.
    - **전환점**: 4레벨(땅 토템 퀘스트), 10레벨(불 토템 퀘스트, 화염 충격, 대지력 토템, 불꽃의 무기, 특성 시작), 20레벨(물 토템 퀘스트, 늑대 정령, 원소의 부름, 하급 치유의 물결), 25레벨(폭풍의 일격 특성), 30레벨(질풍의 무기, 마법정화 토템, 윤회).
    - **Forever 핵심 변경**:
        - 무기 강화 지속 60분.
        - 토템 사거리 30m, 지속 5분.
        - 원소의 부름으로 토템 4개를 한 번에 깔고, 토템의 귀환으로 마나 25%를 돌려받는다.
        - 불꽃 회오리는 토템이 아니라 깔아 둔 불 토템 주변에 터지는 주문이다(재사용 10초).
        - 신규 특성 Mental Dexterity는 지능의 33%를 전투력으로 바꾸고, 폭풍의 일격은 4단으로 내려와 25레벨에 찍는다.
    - **단축키**: 흑마법사·야성 드루이드와 같은 틀. 1 주력, 4 마우스오버 차단, Ctrl+1~4 마우스오버 힐·해제, Alt+숫자 변형, Shift+알파벳 가끔 쓰는 것, T 부활 계열. Shift+숫자는 쓰지 않는다.

## 특성

30레벨까지 21포인트를 전부 고양에 넣는 **0/21/0** 빌드를 추천한다. 치명타와 전투력을 먼저 올리고, 20에 마나 문제를 줄이고, 25에 폭풍의 일격을 얻는 것이 목표다. 특성 포인트는 10레벨부터 레벨당 1개씩 받고, 5포인트마다 다음 단이 열린다.

| 레벨 | 특성 | 효과 |
| --- | --- | --- |
| 10~14 | 우레와 같은 일격 5/5 (1단) | 치명타 +1%(랭크당) |
| 15~17 | Mental Dexterity 3/3 (2단, 신규) | 지능의 33%만큼 전투력 증가 |
| 18~19 | 향상된 번개 보호막 2/3 (2단) | 번개 보호막 피해 +5%(랭크당) |
| 20 | Shamanistic Focus 1/1 (3단, 신규) | 충격·번개 보호막 마나 비용 -45%. 솔플 마나 문제를 크게 줄인다 |
| 21~23 | 정령의 무기 3/3 (3단) | 대지의 무기 +7%, 질풍의 무기 +13% |
| 24 | 향상된 번개 보호막 3/3 | 15점을 채워 4단을 연다 |
| 25 | 폭풍의 일격 1/1 (4단) | 무기 피해 즉시 공격 + 다음 번개 화살·연쇄 번개·대지 충격 피해 +20%(12초) |
| 26~29 | 질풍 4/5 (4단) | 치명타 후 3타 공격 속도 증가 |
| 30 | Improved Stormstrike 1/2 (5단, 신규) | 폭풍의 일격 후 50% 확률로 15초간 시전 중 마나 회복. 회피·패리 때 재사용 초기화 확률 |

레벨별 순서는 단 조건(5점당 1단)에 맞춘 것이다. Shamanistic Focus는 마나 때문에 20에 일찍 찍는다. 영문 표기 특성은 Forever 신규 특성이다.

- **레거시 Talented 특전**: 9레벨부터 특성을 받아 최대 3점을 더 쓴다. 남는 점수는 질풍 5/5와 Improved Stormstrike 2/2에 넣는다.
- **대안**: 이동이 많으면 18~19에 향상된 늑대 정령 2/2(시전 -1초, 실내 사용 가능)를 먼저 찍는다. 대신 번개 보호막 랭크를 뒤로 미룬다.
- **나중에 찍을 특성**: 5단 Mental Quickness(지능의 15%만큼 주문력·치유량), 6단 Maelstrom Weapon(평타가 다음 번개 화살 시전·마나를 4%씩, 5중첩), 7단 Rage of the Farseer(25초간 공격 속도 +30%, 개인용 피의 욕망).

### 다른 특성

- **정기**: 번개 화살 위주 캐스터. 마나 효율이 낮아 30까지는 레벨업이 느리다.
- **복원**: 던전 힐러용. Forever에는 3단에 물의 보호막(Water Shield)이 신규로 들어왔다. 힐러가 귀한 파티를 자주 구한다면 이차 특성으로 있을 만하다.

## 단축키와 매크로

솔플·던전·법사 2인 모두 이 배치를 그대로 쓴다. 주술사는 변신 바가 없어서(늑대 정령은 바가 안 바뀐다) 한 번 놓으면 끝이다. 수정키 규칙은 흑마법사·드루이드와 같다.

- **Ctrl + 1~4** (손바닥 새끼 쪽으로 누름): 마우스오버 힐과 해제. 기본 바 바로 위 추가 단축바의 같은 줄에 둔다.
- **Alt + 숫자**: 같은 키의 변형(전투 중 번개 화살, 냉기 충격, 불꽃 회오리, 정화). 매크로 안에 `[mod:alt]`로 넣어 칸을 따로 쓰지 않는다.
- **Shift + 알파벳** (새끼손가락): 토템·버프의 변형, 전투 밖 기술, 표시.
- **Shift + 숫자**는 쓰지 않는다. WoW 기본 단축바 넘기기(Shift+1~6)는 단축키 설정에서 지운다. Alt+Shift 조합은 한글 입력 전환과 겹쳐 쓰지 않는다.

| 키 | 역할 | 기본 | 수정키 |
| --- | --- | --- | --- |
| 1 | 주력 공격 | 전투 밖 번개 화살, 전투 중 폭풍의 일격(25) | Alt: 번개 화살 / Ctrl: 하급 치유의 물결(20, 전에는 치유의 물결) |
| 2 | 보조 공격 | 대지 충격(4) | Alt: 냉기 충격(20) / Ctrl: 치유의 물결 |
| 3 | 불 피해 | 화염 충격(10) | Alt: 불꽃 회오리(12) / Ctrl: 해독(16) |
| 4 | 차단 | 마우스오버 대지 충격 | Alt: 마우스오버 정화(12) / Ctrl: 질병 치료(22) |
| 5 | 생존기 | 석화(드워프) | - |
| Q | 군중 제어 토템 | 속박의 토템(6) | Shift: 마법정화 토템(30) |
| E | 이동 | 늑대 정령(20) | Shift: 토템 재배치(22, 커서 위치) |
| R | 토템 깔기 | 원소의 부름(20, 전에는 대지력 토템) | Shift: 토템의 귀환(20) / Alt: 선조의 부름(30, 두 번째 토템 세트) |
| F | 불 토템 | 불타는 토템(10) | Shift: 용암 토템(26) |
| G | 긴급 토템 | 돌발톱 토템(8) | Shift: 진동의 토템(18) |
| Z | 버프 | 번개 보호막(8) | Shift: 무기 강화(대지의 무기 / 질풍의 무기) |
| T | 부활 | 마우스오버 고대의 영혼(12, 전투 밖) | Shift: 수중 호흡(22) |
| X / C / V | 표시 | - | Shift: 해골 / X / 달 |

괄호 숫자는 배우는 레벨이다. 아직 안 배운 칸은 비워 둔다.

!!! tip "배치 포인트"
    - 불꽃 회오리는 Shift+F가 아니라 Alt+3에 둔다. Alt가 Shift보다 편하고 던전에서 자주 쓴다.
    - 토템 재배치(Shift+E)와 수중 호흡(Shift+T)도 잊지 말고 넣는다.

### 1. 주력 공격 (키 1)

전투 밖에서는 번개 화살로 당기고, 전투가 시작되면 같은 키가 자동 공격을 켜고 폭풍의 일격을 쓴다. Alt를 누른 채 누르면 전투 중에도 번개 화살이다(도망치는 몹, 다가오는 두 번째 몹).

```
#showtooltip
/startattack [combat,harm]
/cast [mod:alt][nocombat] 번개 화살; 폭풍의 일격
```

25레벨 전에는 마지막 줄에서 `; 폭풍의 일격`을 지우고 쓴다. 전투 중에 누르면 자동 공격만 켜진다.

### 2. 대지·냉기 충격 (키 2)

그냥 누르면 대지 충격, Alt를 누른 채 누르면 이동 속도를 늦추는 냉기 충격이다.

```
#showtooltip
/startattack [harm]
/cast [mod:alt] 냉기 충격; 대지 충격
```

### 3. 화염 충격과 불꽃 회오리 (키 3)

그냥 누르면 화염 충격, Alt는 불꽃 회오리다. Forever 불꽃 회오리는 깔아 둔 불 토템 주변 10m에 터지니, F로 불타는 토템을 몹 무리 옆에 깔고 Alt+3을 누른다.

```
#showtooltip
/cast [mod:alt] 불꽃 회오리; 화염 충격
```

### 4. 마우스오버 차단과 정화 (키 4)

대상을 바꾸지 않고 마우스를 올린 몹의 주문을 대지 충격으로 끊는다. Alt를 누른 채 누르면 몹의 마법 버프를 지우는 정화다. 둘 다 "적의 마법 처리"라 한 키에 묶었다.

```
#showtooltip
/cast [mod:alt,@mouseover,harm,nodead][mod:alt] 정화; [@mouseover,harm,nodead][] 대지 충격
```

### 5. 아군 힐·해제 (Ctrl+1~4)

네 매크로 모두 같은 순서로 대상을 고른다. 마우스를 올린 파티원 → 아군 대상 → 나. 솔플에서는 적을 대상으로 잡은 채 눌러도 나에게 걸리고, 파티에서는 파티 프레임에 마우스를 올리고 누른다.

!!! tip "배치"
    기본 단축바 바로 위 추가 단축바의 1~4번 칸에 둔다. 1번 위에 Ctrl+1처럼 세로 줄을 맞추면 "같은 숫자의 한 칸 위 = Ctrl"로 눈에 바로 들어오고, 사거리·마나도 아이콘으로 보인다.

Ctrl+1 하급 치유의 물결 (20레벨 전에는 치유의 물결로 쓴다):

```
#showtooltip
/cast [@mouseover,help,nodead][help,nodead][@player] 하급 치유의 물결
```

Ctrl+2 치유의 물결, Ctrl+3 해독, Ctrl+4 질병 치료는 위 매크로에서 기술 이름만 바꾼다.

### 6. 토템 키 (R, F, G, Q, E)

R은 20레벨에 받는 원소의 부름이다. 토템 바에 지정한 토템을 최대 4개까지 한 번에 깐다(시전 3초). Shift는 토템을 거두고 마나 25%를 돌려받는 토템의 귀환, Alt는 30레벨의 선조의 부름(다른 토템 세트)이다. 선조의 부름에 던전용 세트를 넣어두면 솔플·던전 전환이 키 하나다.

```
#showtooltip
/cast [mod:shift] 토템의 귀환; [mod:alt] 선조의 부름; 원소의 부름
```

20레벨 전에는 R에 대지력 토템(10, 그 전에는 돌가죽 토템)만 둔다. F·G·Q는 같은 틀의 Shift 매크로다.

```
#showtooltip
/cast [mod:shift] 용암 토템; 불타는 토템
```

- G: `진동의 토템; 돌발톱 토템`으로 이름만 바꾼다.
- Q: `마법정화 토템; 속박의 토템`으로 이름만 바꾼다.
- E: 늑대 정령과 토템 재배치(22, 재사용 1분, 30m). 토템 재배치는 마우스 커서 자리로 토템을 옮긴다.

```
#showtooltip
/cast [mod:shift,@cursor] 토템 재배치; 늑대 정령
```

### 7. 버프와 부활 (키 Z, T)

```
#showtooltip
/cast [mod:shift] 대지의 무기; 번개 보호막
```

30레벨에 질풍의 무기를 배우면 `대지의 무기`를 `질풍의 무기`로 바꾼다. Forever 무기 강화는 60분이라 사냥 전에 한 번만 건다.

T는 죽은 파티원 프레임에 마우스를 올리고 누르는 부활이다. 주술사는 전투 부활이 없고, 30레벨 윤회는 나만 살린다. Shift는 물속 구간용 수중 호흡이다.

```
#showtooltip
/cast [mod:shift,@mouseover,help][mod:shift] 수중 호흡; [@mouseover,help,dead][] 고대의 영혼
```

### 설정 순서

1. ESC → 단축키 설정에서 Shift+1~6(단축바 넘기기)을 지우고, Q·E의 옆걸음을 단축바 키로 바꾼다.
2. ESC → 설정 → 액션바에서 추가 단축바를 하나 켜고 기본 바 바로 위로 옮긴다. 그 바의 버튼 1~4에 Ctrl+1~4를 지정한다. WoW는 기본으로 Ctrl+1~0을 소환수 바에 쓰지만 주술사는 소환수가 없어서 덮어써도 된다.
3. Shift+X·C·V는 같은 추가 바의 다른 칸에 둔다. Alt+숫자와 Alt+R은 매크로 안에 들어 있어서 따로 지정하지 않는다.
4. 파티 프레임을 화면 아래쪽 가운데, 추가 단축바 근처로 옮긴다. 마우스를 프레임에 올리고 Ctrl+숫자를 누르는 동작이 짧아진다.
5. 원소의 부름을 배우면 토템 바에서 땅·불·물·바람 칸에 쓸 토템을 고른다.
6. 매크로가 안 먹으면 매크로 창을 연 채 주문서에서 기술을 Shift+클릭해 이름을 넣는다. 문법은 [포에버 매크로 교본](../tools/macro-guide.html)과 같다.

## 솔플

솔플의 핵심은 마나다. 번개 화살 한 번으로 당기고, 나머지는 양손 무기 평타와 번개 보호막으로 잡으며, 충격은 마무리나 차단에만 쓴다. 20에 Shamanistic Focus를 찍으면 충격 비용이 거의 반으로 줄고, 30의 Improved Stormstrike부터 전투 중 마나 회복이 생긴다.

### 사냥 전 준비

- 대지의 무기를 무기에 건다(60분). 30레벨부터는 질풍의 무기.
- 번개 보호막을 항상 유지한다. 맞을 때마다 적에게 피해를 주고, Forever에서도 3회다. DPS가 가장 높은 기술 중 하나다.
- 사냥터에 도착하면 대지력 토템을 미리 깔고 그 근처로 몹을 당긴다. Forever 토템은 5분, 30m라 여러 마리를 잡는 동안 유지된다.
- 드워프 보물 찾기와 약초 찾기를 같이 켜둔다.

### 한 마리 잡는 순서

1. **당기기**: 번개 화살 1번(키 1). 마나가 넉넉하면 몹이 오는 동안 Alt+1로 한 번 더.
2. **붙으면**: 키 1을 다시 눌러 자동 공격 + 폭풍의 일격(25 이후). 10레벨부터는 불타는 토템(F)도 깐다.
3. **강한 몹만**: 화염 충격(3). 금방 죽을 몹에는 쓰지 않는다.
4. **마무리**: 폭풍의 일격 직후 대지 충격(2). 폭풍의 일격이 다음 대지 충격 피해를 20% 올려 준다.
5. **시전하는 몹**: 대지 충격(4)으로 끊는다.
6. **전투 후**: 체력이 낮으면 하급 치유의 물결(Ctrl+1) 한 번. 마나가 반 아래면 앉아서 물을 마신다.

!!! tip "30레벨 이후"
    Improved Stormstrike를 찍은 뒤에는 폭풍의 일격 재사용이 초기화되면 바로 키 1을 다시 누른다.

## 던전

던전에서 고양 주술사의 가치는 딜보다 토템과 차단에서 나온다. 파티 전체에 대지력·마나샘 토템을 깔고, 시전하는 몹을 대지 충격으로 끊고, 힐러가 바쁠 때 하급 치유의 물결로 보조한다.

!!! info "파티 구하기"
    Forever에는 자동 파티 찾기가 없다. 파티 찾기 목록에 "대지력/마나샘 토템, 차단 가능"을 적으면 파티가 잘 구해진다. 소환은 흑마법사만 할 수 있어서 던전 입구까지는 직접 가야 한다.

### 전투 순서

1. **풀링 전**: R(원소의 부름)으로 토템을 탱커 근처에 깔아 둔다. 번개 화살로 당기지 않는다. 풀링은 탱커 몫이다.
2. **진입**: 탱커가 몹을 잡고 2~3초 뒤에 따라 때리기 키로 탱커 대상을 받아 들어간다.
3. **딜**: 폭풍의 일격 → 대지 충격(마나 여유가 있을 때), 나머지는 평타. 화염 충격은 오래 사는 정예에만.
4. **차단**: 해골 외 몹이 시전하면 마우스를 올리고 4. 대지 충격을 딜에 다 쓰면 차단할 때 재사용 대기에 걸리니, 차단할 몹이 있는 무리에서는 대지 충격을 아낀다.
5. **여러 마리**: 불타는 토템을 몹 무리 바로 옆에 깔고 불꽃 회오리(Alt+3)를 터뜨린다. 탱커가 위협을 충분히 잡은 뒤에만. 불꽃 회오리는 마나를 엄청나게 먹으니 긴 전투에서는 아낀다.
6. **힐러 보조**: 힐러 마나가 바닥이면 탱커 프레임에 마우스를 올리고 Ctrl+1(하급 치유의 물결).

### 던전 토템 조합

| 칸 | 기본 | 바꿀 때 |
| --- | --- | --- |
| 땅 | 대지력 토템(근접 파티) | 공포·매혹·수면 몹이면 진동의 토템(Shift+G), 캐스터 위주면 돌가죽 토템 |
| 불 | 불타는 토템(해골 몹에) | 28부터 불꽃의 토템(Forever에서 질풍의 무기와 중첩), 여러 마리면 용암 토템(26, Shift+F) |
| 물 | 마나샘 토템(26) | 독 몹이 많으면 독 정화 토템(22), 26 전에는 치유의 토템 |
| 바람 | 30부터 마법정화 토템(시전 몹이 많을 때) | - |

!!! tip "30레벨 던전 세트"
    대지력 / 불꽃의 토템 / 마나샘 / 마법정화. 30에 선조의 부름(Alt+R)에 이 세트를, 원소의 부름(R)에 솔플 세트를 넣어두면 토템 바를 매번 바꾸지 않아도 된다.

토템 사거리는 Forever에서 30m로 늘었지만 파티가 이동하면 따라가야 한다.

- 짧게 이동하면 토템 재배치(Shift+E, 커서 자리)로 옮긴다.
- 장거리 이동 후에는 토템의 귀환(Shift+R)으로 마나 25%를 돌려받고 R로 다시 깐다.

### 던전 매크로

**따라 때리기 (숫자 1 왼쪽 키)**: 던전 입장 후 탱커를 대상으로 잡고 채팅창에 `/focus`를 한 번 입력한다. 그 뒤로는 이 키를 누르면 탱커의 대상을 내 대상으로 가져오고 자동 공격을 켠다.

```
/assist [@focus,exists]
/startattack [harm]
```

**힐·해제**: 공통 Ctrl+1~4가 이미 마우스오버 방식이라 바꿀 것이 없다. 부활은 T(죽은 파티원 프레임에 마우스오버, 전투 밖).

**표시 (Shift+X / Shift+C)**: 탱커가 표시를 안 하면 대신 해골(8)과 X(7)를 찍는다. 한 번 더 누르면 지워진다. Shift+C에는 숫자만 7로, Shift+V(변이 대상, 달)에는 5로 바꾼 같은 매크로를 넣는다.

```
/tm [@mouseover,exists][] 8
```

## 법사와 2인 파티

법사와의 2인에서 주술사는 "앞에서 맞고, 둘 다 살리는" 쪽이다. 주술사가 당기고 몹을 붙잡고, 법사는 뒤에서 딜과 군중 제어를 맡는다. 법사가 물·빵을 만들어 주고 주술사가 힐을 하니 쉬는 시간이 거의 없다.

### 역할 나누기

| 항목 | 드워프 주술사 | 법사 |
| --- | --- | --- |
| 당기기 | 번개 화살로 당기고 붙는다 | 주술사가 몹을 친 뒤 2초 후부터 딜 |
| 여러 마리 | 몹을 모으고 버틴다. 속박의 토템, 돌발톱 토템, 석화 | 얼음 회오리 후 광역(신비한 폭발, 20부터 눈보라) |
| 군중 제어 | 변이 대상에 달 표시 | 변이 하나, 마법 차단 |
| 생존 | 나와 법사 힐, 해독 | 물·빵 만들기, 신비한 지능 |
| 토템 | 땅 대지력, 불 불타는, 물 마나샘(26) | - |

!!! tip "신비한 지능"
    주술사에게 특히 좋다. Mental Dexterity가 지능의 33%를 전투력으로 바꾸기 때문이다. 법사에게 항상 걸어 달라고 한다.

### 한 마리씩 잡을 때

1. 주술사가 번개 화살(1)로 당기고, 몹이 오는 동안 불타는 토템(F).
2. 몹이 붙으면 1을 눌러 평타 + 폭풍의 일격. 폭풍의 일격 뒤 대지 충격으로 위협을 한 번 더 올린다.
3. 법사는 주술사 대상을 따라 얼음 화살. 법사 위협이 주술사보다 높아지면 몹이 법사에게 간다.
4. 몹이 법사에게 가면 법사는 얼음 회오리로 묶고 물러서고, 주술사는 매달려 평타를 계속 친다.

### 광역 사냥 (법사 20레벨 이후)

약한 몹이 모여 있는 사냥터에서 가장 빠르다.

1. 주술사가 R로 토템을 깔고, 속박의 토템(Q)을 법사 앞에 둔다.
2. 주술사가 몹 3~5마리를 번개 화살·충격으로 하나씩 건드려 달고 법사 옆으로 돌아온다.
3. 몹이 모이면 법사가 얼음 회오리 → 눈보라(또는 신비한 폭발).
4. 주술사는 돌발톱 토템(G)을 깔아 몹을 분산시키고, 석화(5)를 켜고, 불꽃 회오리(Alt+3)를 같이 넣는다.
5. 법사 체력이 떨어지면 법사 프레임에 마우스를 올리고 Ctrl+1(하급 치유의 물결).

### 변이가 있는 전투

- 3마리 이상이면 법사가 하나를 변이한다. 주술사는 Shift+V로 그 몹에 달 표시를 찍는다.
- 변이 몹 근처에는 불타는 토템을 깔거나 불꽃 회오리를 쓰지 않는다. 순식간에 풀린다.
- 주문을 쓰는 몹은 주술사가 대지 충격으로 먼저 끊고, 다음 시전을 법사가 마법 차단으로 끊는다.

### 2인용 매크로

**법사 힐**: 따로 만들지 않는다. 법사 파티 프레임에 마우스를 올리고 Ctrl+1이나 Ctrl+2. 법사가 독에 걸리면 같은 자세로 Ctrl+3.

**변이 대상 표시 (Shift+V)**: 마우스오버한 몹, 없으면 대상에 달(5)을 찍는다.

```
/tm [@mouseover,exists][] 5
```

**법사에게 주는 매크로 (법사 쪽 1번 키)**: 주술사 대상을 가져와 얼음 화살을 쏜다. 두 사람이 서로 다른 몹을 때리는 일이 없어진다.

```
#showtooltip
/assist [@party1,exists,nodead]
/cast 얼음 화살
```

나머지 키는 솔플 배치 그대로다. 법사가 딜을 담당하니 마나는 충격보다 힐에 남겨 두는 것이 안전하다.

### 육성 팁

- 1~19는 최대 피해가 높은 양손 무기면 된다. 속도는 크게 상관없다. 25에 폭풍의 일격을 배운 뒤부터 느린 양손 무기를 고른다.
- 트레이너에게 자주 간다. 짝수 레벨마다 새 랭크가 나오고, 번개 보호막·대지 충격 랭크가 사냥 속도를 크게 바꾼다.
- Forever는 던전 몹 경험치가 줄고 던전 퀘스트 경험치가 늘었다. 던전은 퀘스트를 다 받은 상태로 한 번 도는 게 핵심이다.
- 가죽세공 텐트가 있는 모닥불에서는 휴식 경험치 5%를 준다. 드루이드가 가죽세공이니 같이 다닐 때 켜 달라고 한다.
- 베타 만렙(30)에 닿으면 끝낸 퀘스트는 반납하지 말고 쌓아두었다가 다음 개방 직후 한꺼번에 반납한다.

## 장비

레벨업 고양 주술사의 첫 목표는 느리고 강한 양손 둔기다. 30레벨 BiS 방어구 4부위가 가죽세공 제작품이라 드루이드 부캐가 만들어 보낼 수 있고, 성물은 흑마법사의 마법부여 제작품이다.

- **스탯 우선순위(레벨업)**: 무기 DPS > 치명타 > 힘 > 지능 > 민첩 > 주문력 > 정신력 > 체력. 힘은 전투력 2, 지능은 Mental Dexterity로 전투력과 마나를 같이 준다. 주문력은 매우 비효율적이다.
- **무기**: 양손 둔기 > 양손 도끼. 드워프는 둔기 치명타 +1%라 같은 성능이면 둔기다. 30까지 쌍수는 없다.
- **방어구**: 가죽. 사슬은 40레벨부터다(클래식 기준).
- **성물 칸**: 주술사는 성물 칸에 토템을 끼운다.

## 전문기술

이 주술사는 **약초채집 + 연금술**로 간다. 약초를 직접 캐서 물약을 만들고, 세 캐릭터의 치유·마나 물약과 영약을 대준다. 드루이드는 무두질·가죽세공, 흑마법사는 재봉술·마법부여를 맡는다. 연금술의 마나 영약은 초반 고양 주술사에게 특히 좋다.

| 전문기술 | 이 캐릭터에서의 쓰임 | Forever 변경 |
| --- | --- | --- |
| 약초채집 | 연금술 재료, 남는 약초는 경매장 | 20에 모닥불 Incense Candle(주변 아군 지능 +25), 140에 Greenhouse(씨앗을 심어 약초 재배) |
| 연금술 | 치유·마나 물약, 전투력 물약, 마나 영약 | 20에 모닥불 Mana Well(주변 앉은 사람 마나 5초마다 29), 140에 Fermenter. 신규 물약 다수 |

!!! tip "모닥불 설비"
    두 설비가 다 주술사에게 맞는다. Incense Candle의 지능 +25는 Mental Dexterity로 전투력이 되고, Mana Well은 주술사 모닥불 버프 1순위다.

| 30 | Minor Mender's Potion (신규) | 치유. 평온초·마법초 |
| 40 | Minor Frenzy Potion (신규) | 전투력 증가. Bloodfeather Harpy 전리품이 필요하다(호드 지역 몹이라 경매장) |
| 80 | Lesser Mender's Potion (신규) | 치유 |
| 90 | Lesser Frenzy Potion (신규) | 더 큰 전투력 증가. 정예·보스용 |

| 클래식 | 초저레벨·하급 치유 물약, 초저레벨 마나 물약 | 레벨업 버티기 |

### 올리는 순서

1. 콜드릿지 계곡부터 약초 찾기를 켜고 평온초·은엽수 덤불·뱀뿌리를 캔다(약초 1~50).
2. 연금술 1~60은 초저레벨 치유 물약과 신규 Minor Mender's Potion(30)으로 올린다. 20에 Mana Well을 배운다.
3. 모단 호수·서부 몰락지대에서 마법초·찔레가시를 캔다(약초 50~100). 연금술은 Lesser Mender's Potion(80), Lesser Frenzy Potion(90)으로 올린다.
4. 저습지·그늘숲에서 생채기풀·야생 철쭉·왕꽃잎풀·무덤이끼·갈래물풀을 캔다(약초 100~150). 물약 레벨도 따라 올라간다.
5. 약초채집·연금술 140에 Greenhouse와 Fermenter를 한 단계씩 올린다.

약초 위치와 가격은 [약초 지도](../tools/herb-atlas.html)에 있다. 약초 이름은 클래식 번역, 신규 물약·설비 이름은 영문 그대로다.

### 다른 캐릭터와 주고받기

- 드루이드에게 치유 물약·전투력 물약을, 흑마법사에게 마나 물약을 우편으로 보낸다.
- 드루이드에게서 가죽 장비(30 BiS 4부위), 흑마법사에게서 성물을 받는다. 쓰지 않는 초록 장비는 흑마법사에게 보내 마력 추출한다.
- 응급치료·요리·낚시는 다른 캐릭터와 같이 올린다. 전문기술 150·225·300 달성은 레거시 포인트를 준다.
- 레거시 전문기술 특전 Bountiful Harvest는 희귀 재료를 20~100% 더 주고, Working Overtime은 스킬 상승 확률을 4~20% 올린다. 베타에서는 전문기술이 225에서 막힌다.

## 종족 특성

Forever 드워프는 총기류 전문화와 냉기 저항이 빠지고 아래 네 가지가 됐다. 고양 주술사가 전부 쓸 수 있고, 특히 둔기류 전문화·석화·Big Game Hunter가 고양에 잘 맞는다. 얼라이언스 주술사는 드워프뿐이라 고를 것도 없다.

| 특성 | 효과 (Forever) | 고양 주술사 활용 |
| --- | --- | --- |
| 석화 | 8초 동안 출혈·독·질병 면역, 받는 물리 피해 10% 감소. 재사용 3분 | 키 5. 체력이 떨어질 때, 독·출혈이 걸렸을 때, 광역 사냥에서 몹을 모을 때 |
| 둔기류 전문화 | 둔기(한손·양손)를 들면 치명타 +1% | 양손 둔기 우선. 치명타가 늘면 질풍도 자주 터진다. 20·30 BiS 무기가 둘 다 망치다 |
| Big Game Hunter | 야수에게 주는 피해 +5% | 늑대·멧돼지·거미·곰 퀘스트가 많은 던 모로·모단 호수에서 이득 |
| 보물 찾기 | 보물 상자 추적. Forever에서는 다른 추적과 같이 켜진다. 죽으면 다시 켜야 한다 | 약초 찾기와 같이 켜 둔다 |

석화는 물리 피해만 줄이니 캐스터 몹에게는 효과가 적다. 마법 피해는 마법정화 토템(30)과 차단으로 막는다.

## 게임에서 확인할 것

주문 이름은 한글 클래식 클라이언트 기준이다. 매크로가 안 먹으면 주문서에서 Shift+클릭으로 이름을 넣는다.

- [ ] Forever 신규 기술 한글 이름: 원소의 부름, 선조의 부름, 토템의 귀환, 토템 재배치(확장팩 한글판 이름), 불꽃 회오리(클래식 불꽃 회오리 토템에서 추정), 용암 토템, 서리의 무기, 수중 호흡, 멀리 보기, 귀환
- [ ] 토템 재배치가 지면 지정 기술인지. 대상 지정 방식이면 매크로에서 `@cursor`를 지운다
- [ ] 특성 한글 이름: 우레와 같은 일격, 향상된 번개 보호막, 정령의 무기, 질풍(추정 표기), Mental Dexterity·Shamanistic Focus·Improved Stormstrike·Big Game Hunter(미확인)
- [ ] 특성 단 조건이 5점당 1단인지(클래식 기준. 이 기준이면 폭풍의 일격 25, Improved Stormstrike 30)
- [ ] 충격 재사용 대기(6초)를 충격끼리 공유하는지. 공유하지 않으면 던전에서 대지 충격을 아낄 필요가 줄고, 화염 충격과 대지 충격을 연달아 쓸 수 있다
- [ ] 토템 아이템을 가방에 들고 있어야 하는지, 성물 칸에 끼우는 것으로 대신하는지. 그 전까지 퀘스트 보상 토템은 버리지 않는다
- [ ] 바람 토템 퀘스트(30) 내용, 바람 토템(마법정화 등)을 퀘스트 없이 쓸 수 있는지
- [ ] 가죽세공 BiS 4부위가 착용 시 귀속인지
- [ ] 기존 던전의 레벨과 몹 특징(클래식 기준)
