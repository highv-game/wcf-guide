# 직업 공략

모든 직업 문서는 같은 순서로 되어 있습니다: 한눈에 보기 → 특성 → 단축키·매크로 → 솔로 → 던전 → 레벨링 루트 → 장비 → 전문기술 → 종족 특성 → 게임에서 확인할 것.

키 배치는 모든 직업이 [공통 단축키 규칙](../settings/keybinds.md)을 따릅니다.
