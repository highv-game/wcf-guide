## 공통 단축키 규칙

모든 직업 공략은 같은 키 배치를 씁니다.

- **Shift+숫자는 쓰지 않습니다.** 기본 단축키의 Shift+1~6(행동 단축바 넘기기)은 해제합니다.
- **Ctrl+1~4**: 마우스오버 치유·해제 (기본 바 바로 위 추가 단축바, 1~4와 같은 줄)
- **Alt+숫자**: 같은 숫자 매크로 안의 변형 기술 (`[mod:alt]`)
- **Shift+알파벳**: 비전투·변형 기술, 공격대 징표(Shift+X/C/V)
- **T**: 전투 부활 / 던전 부활
- Alt+Shift 조합은 한글 입력 전환과 겹쳐서 쓰지 않습니다.
